# /portfolio

更新期限の確認、資産の追加、ファイリングの記録、台帳の監査を実行する。

## 手順

1. `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/portfolio.yaml` を読み込む。
2. **デフォルト（引数なし）:** `--report` と同等 — 今後90日間の期限をグループ別に表示。
3. **`--report [--days N]`:** 期間を変更可能（30 / 60 / 90 / 180日）。
4. **`--add`:** 新規資産を対話的に追加。
5. **`--update`:** 年金納付や更新手続の記録。
6. **`--audit`:** 包括的な健全性チェック。

## 日本の知財権の存続期間と更新

### 特許権

- **存続期間:** 出願日から20年（医薬品・農薬は最大5年延長可能）
- **年金（特許料）:** 第1年〜第3年分は設定登録時に一括納付。第4年以降は毎年納付
- **追納期間:** 納付期限経過後6ヶ月以内（割増特許料が必要）
- **出願審査請求期限:** 出願日から**3年以内**（この期限を逃すと出願が取り下げられたものとみなされる）

### 商標権

- **存続期間:** 設定登録日から**10年**（更新可能、回数制限なし）
- **更新:** 存続期間満了前6ヶ月から満了日までに更新登録申請。満了後6ヶ月の追納期間あり（倍額）
- **使用宣言:** 不要（米国と異なり、日本では更新時に使用宣言は不要）
- **不使用取消審判:** 継続して3年以上使用していない場合、第三者が不使用取消審判を請求可能（商標法第50条）

### 意匠権

- **存続期間:** 出願日から**25年**（2020年改正で20年→25年に延長）
- **年金:** 第1年〜第3年分は設定登録時に一括納付。第4年以降は毎年納付

### 実用新案権

- **存続期間:** 出願日から**10年**
- **年金:** 第1年〜第3年分は設定登録時に一括納付。第4年以降は毎年納付
- **注意:** 無審査登録制度のため、権利行使時には技術評価書が必要
