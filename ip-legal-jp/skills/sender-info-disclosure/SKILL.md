# /sender-info-disclosure

**これは手続のガイダンスであり、法的助言ではありません。** 発信者情報開示請求は裁判手続を伴うため、必ず弁護士に依頼してください。

## 手順

1. `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` を読み込む。
2. 事実関係を確認する。
3. 適切な手続の選択を支援する。
4. 必要な準備事項を整理する。

## 発信者情報開示制度の概要

### 2022年改正の新手続（発信者情報開示命令事件）

2022年10月施行の改正プロバイダ責任制限法により、従来の二段階手続に加えて、新たな非訟事件手続が導入された。

**新手続のメリット:**
- 一つの裁判手続で、コンテンツプロバイダとアクセスプロバイダの両方に対する開示命令を取得可能
- 提供命令により、コンテンツプロバイダからアクセスプロバイダへの情報提供を命じることができる
- ログ保全のための消去禁止命令が利用可能
- 従来手続より迅速

**新手続の流れ:**
1. **発信者情報開示命令の申立て**（コンテンツプロバイダに対して）
2. **提供命令の申立て**（コンテンツプロバイダに対し、アクセスプロバイダへの情報提供を命じる）
3. **消去禁止命令の申立て**（アクセスプロバイダに対し、ログの消去禁止を命じる）
4. **発信者情報開示命令の申立て**（アクセスプロバイダに対して）

### 従来の手続（仮処分＋本案訴訟）

**従来の二段階手続:**
1. **第一段階:** コンテンツプロバイダ（サイト運営者）に対する発信者情報開示仮処分
   - IPアドレス・タイムスタンプの開示を求める
   - 被保全権利: 発信者情報開示請求権（プロバイダ責任制限法第5条）
   - 保全の必要性: ログの保存期間が限られている（通常3〜6ヶ月）
2. **第二段階:** アクセスプロバイダ（ISP）に対する発信者情報開示訴訟
   - IPアドレスから特定されたISPに対し、契約者の氏名・住所の開示を求める
   - 本案訴訟として提起

### 手続選択の判断基準

| 考慮要素 | 新手続 | 従来手続 |
|---|---|---|
| 迅速性 | ◎（一つの手続で完結） | △（二段階） |
| ログ保全 | ◎（消去禁止命令あり） | △（別途保全が必要） |
| 海外プロバイダ | △（管轄の問題あり） | ○（仮処分で対応実績あり） |
| 費用 | ○（一手続分） | △（二手続分） |
| 判例の蓄積 | △（新制度のため少ない） | ◎（豊富） |

## 開示請求の要件（プロバイダ責任制限法第5条）

1. **権利侵害の明白性:** 侵害情報の流通によって自己の権利が侵害されたことが明らかであること
2. **正当な理由:** 損害賠償請求の行使のために必要である場合その他発信者情報の開示を受けるべき正当な理由があること

### 対象となる発信者情報

- 発信者の氏名又は名称
- 発信者の住所
- 発信者の電話番号
- 発信者の電子メールアドレス
- IPアドレス・ポート番号
- SIMカード識別番号
- タイムスタンプ（侵害情報が送信された年月日及び時刻）

## タイムライン上の注意点

**ログの消失リスク:** アクセスプロバイダのログ保存期間は通常3〜6ヶ月。侵害を発見したら**速やかに**手続を開始する必要がある。ログが消失すると、発信者の特定が不可能になる。

**実務上の目安:**
- 侵害発見 → 1週間以内に弁護士に相談
- 弁護士選任 → 2週間以内に申立準備
- 新手続の場合: 申立から開示まで数ヶ月
- 従来手続の場合: 仮処分2〜3ヶ月 → 本案訴訟6ヶ月〜1年
