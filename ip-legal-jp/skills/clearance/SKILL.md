# /clearance

**これはスクリーニングであり、クリアランス意見ではありません。** 正式な商標クリアランス意見には、J-PlatPat・外国データベースの包括的検索と、弁護士・弁理士による類似判断が必要です。「明らかな抵触なし」という結果は、このスクリーニングで何も見つからなかったことを意味するにすぎず、商標が使用可能であることを意味しません。

## 手順

1. `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` を読み込む。`[PLACEHOLDER]` が含まれていれば `/ip-legal-jp:cold-start-interview` に誘導する。
2. 以下のワークフローに従う。
3. インテーク（商標、商品・役務、区分、指定国、態様）を実行する。
4. 固有の拒絶理由のノックアウトチェック — 商標法第3条（自他商品識別力）、第4条（不登録事由）。
5. J-PlatPat等の接続されたデータベースで類似商標を検索する。未接続の場合は出力にその旨を記載し、要素分析のみ実行する。
6. JPOの類似判断基準 — 称呼（読み）・観念（意味）・外観（見た目）の三要素で類似性を分析する。
7. トリアージメモを案件フォルダまたはプラクティス出力フォルダに書き込む。

このスキルは商標が使用可能であると結論づけることはない。不確実な場合はフラグを立て、弁護士・弁理士が判断する。

## 使用例

```
/ip-legal-jp:clearance "APEXLEAF アウトドアアパレル、日本＋米国で発売予定"
/ip-legal-jp:clearance
```

## ノックアウトチェック

データベース検索の前に、登録そのものを妨げる固有の問題をチェックする。

### 商標法第3条（自他商品識別力の要件）

| 号 | 拒絶理由 | フラグする場合 |
|---|---|---|
| 第3条第1項第1号 | 普通名称 | 商標がその商品・役務の一般的な名称である |
| 第3条第1項第2号 | 慣用商標 | その商品・役務について慣用的に使用される商標 |
| 第3条第1項第3号 | 記述的商標 | 商品の産地、品質、用途等を普通に用いられる方法で表示する |
| 第3条第1項第4号 | ありふれた氏 | ありふれた氏（例：「田中」「鈴木」）のみからなる |
| 第3条第1項第5号 | 極めて簡単で、かつ、ありふれた標章 | 1文字、数字のみ等 |
| 第3条第1項第6号 | その他識別力なし | 上記以外で識別力がないもの |

**第3条第2項（使用による識別力の獲得）:** 第3条第1項第3号〜第5号に該当しても、使用の結果、需要者が特定の出所を識別できるようになった場合は登録可能。

### 商標法第4条（不登録事由）の主要項目

| 号 | 不登録事由 | フラグする場合 |
|---|---|---|
| 第4条第1項第1号 | 国旗等 | 国旗、菊花紋章、国際機関の標章と同一・類似 |
| 第4条第1項第7号 | 公序良俗違反 | 公の秩序又は善良の風俗を害するおそれ |
| 第4条第1項第8号 | 他人の氏名等 | 他人の肖像、氏名、著名な芸名等を含む |
| 第4条第1項第10号 | 周知商標 | 他人の周知商標と同一・類似（未登録でも保護） |
| 第4条第1項第11号 | 先願登録商標 | 他人の先願に係る登録商標と同一・類似 |
| 第4条第1項第15号 | 混同のおそれ | 他人の業務に係る商品・役務と混同を生ずるおそれ |
| 第4条第1項第19号 | 不正目的 | 不正の目的をもって使用する商標 |

**日本は先願主義。** 米国のようなコモンロー上の権利（使用に基づく権利）は原則としてない。ただし、不正競争防止法第2条第1項第1号・第2号による周知・著名表示の保護、および商標法第4条第1項第10号による未登録周知商標の保護がある。

## 類似商標チェック

### 接続状況の確認

- **J-PlatPatが接続されている場合:** 関連する区分・指定国で検索を実行。結果にソースを帰属。検索日時と範囲を記録。
- **未接続の場合:** 以下を出力に記載:

> **データベース検索は実行されていません。** このスクリーニングではJ-PlatPat、外国特許庁データベース、不正競争防止法上の周知・著名表示のいずれも検索していません。出願可否の結論を出す前に、これらのデータベースでの包括的検索が必要です。

### 類似判断の三要素（JPO基準）

日本の商標類似判断は、以下の三要素を総合的に考慮して行う:

| 要素 | 内容 | 分析方法 |
|---|---|---|
| **称呼（読み）** | 商標から生じる読み・発音 | 音節数、アクセント、母音構成、子音構成の比較 |
| **観念（意味）** | 商標から生じる意味・概念 | 直訳、暗示的意味、造語の場合は観念なし |
| **外観（見た目）** | 商標の視覚的な見た目 | 文字の構成、配列、図形要素の比較 |

**判断基準:** 三要素のいずれか一つでも類似する場合、原則として商標は類似と判断される。ただし、取引の実情等を考慮して総合的に判断する（最判昭和43年2月27日「氷山印事件」）。

**結合商標の場合:** 商標の構成部分の一部が識別力を有する場合、その部分（要部）を抽出して類似判断を行うことがある（要部観察）。ただし、分離観察が許されない一体不可分の商標もある。

### 類似群コードの確認

JPOは商品・役務を類似群コードで管理している。同一の類似群コードに属する商品・役務は、原則として類似と推定される。異なる類似群コードでも類似と判断される場合がある（備考類似）。

### 隣接ファミリーの調査

類似商標のチェックは、完全一致・近似のみでは不十分。カテゴリー内の慣用的な代替語も調査すべき:
