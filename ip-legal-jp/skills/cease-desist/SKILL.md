# /cease-desist

2つのモード:

- `/ip-legal-jp:cease-desist --send` — 権利行使方針に基づいた警告書を起案する。送付前に承認ゲートを実行。
- `/ip-legal-jp:cease-desist --receive` — 受領した警告書をトリアージする。選択肢メモと推奨を生成。

## 手順

1. **プラクティスプロファイルを読み込む。** `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` をロード。`[PLACEHOLDER]` が含まれる場合は停止し、`/ip-legal-jp:cold-start-interview` に誘導する。

2. **案件ワークスペースを確認。**

3. **モード分岐:**
   - `--send`: 送付モード。権利の特定、侵害行為の特定、相手方調査、請求内容の特定、権利行使方針との整合、起案、承認ゲート。
   - `--receive`: 受領モード。受領した警告書の読み込み、評価、リスク分析、選択肢提示、トリアージメモ作成。
   - フラグなし: 「警告書を送付しますか（権利行使）、それとも受領した警告書をトリアージしますか（防御）？」

4. **承認ゲートを遵守。** 送付モードでは、最終稿の出力前に承認ゲートを実行する。

5. **承認マトリクスを遵守。** `## 権利行使方針 → 承認` から承認者を取得する。

## 使用例

```
/ip-legal-jp:cease-desist --send
/ip-legal-jp:cease-desist --receive ~/Downloads/keikokusho-acme.pdf
/ip-legal-jp:cease-desist
```

## 送付モード — 日本の実務

### 相手方調査

- 法人の場合: 商業登記簿謄本（登記事項証明書）で正確な法人名・代表者名・本店所在地を確認
- 個人事業主の場合: 可能な範囲で住所を特定
- ウェブサイト運営者の場合: 特定商取引法に基づく表記、Whois情報

### 警告書の形式

日本の知的財産権侵害の警告書は、通常**内容証明郵便**で送付する。

**内容証明郵便の形式要件:**
- 1行20字以内、1頁26行以内（縦書きの場合は1行26字以内、1頁20行以内）
- 同文の書面3通（相手方送付用、郵便局保管用、差出人控え用）
- 差出人・受取人の住所氏名を記載
- 配達証明を付す

**警告書の構成:**

1. **日付・差出人・受取人の表示**
2. **件名:** 「警告書」「通知書」等
3. **権利の表示:** 商標登録番号、特許番号、著作物の特定等
4. **侵害行為の特定:** 具体的にどの行為が侵害に該当するか
5. **法的根拠:** 商標法第36条、特許法第100条、著作権法第112条等
6. **請求事項:** 使用中止、廃棄、損害賠償等
7. **回答期限:** 通常14日〜30日
8. **不履行の場合の措置:** 「法的措置（仮処分申立を含む）を講じることもあり得ます」

### 仮処分

日本では、仮処分（民事保全法第23条第2項）が主要なエスカレーション手段。本案訴訟に先立ち、侵害行為の差止めを求めることができる。被保全権利と保全の必要性を疎明する必要がある。

## 受領モード

受領した警告書に対する選択肢:

1. **任意交渉:** 相手方の請求に応じる余地がある場合の交渉
2. **反論:** 非侵害の主張、権利の無効の主張、先使用権の主張等
3. **無効審判の請求:** 商標登録無効審判（商標法第46条）、特許無効審判（特許法第123条）
4. **放置:** リスク評価の結果、対応不要と判断する場合（弁護士確認必須）
5. **和解:** ライセンス契約等による解決

---

## 弁護士確認ゲート

**送付モード — 全ロール共通:** 警告書の送付は法的効果を伴うため、必ず弁護士の確認を経てから送付する。弁理士ユーザーの場合、商標法・特許法に関する警告書は弁理士の業務範囲内だが、訴訟提起を示唆する内容は弁護士の確認が必要。

**受領モード:** 対応方針の決定は弁護士の判断事項。トリアージメモは判断材料の整理。

## 免責事項

本スキルの出力は法的助言ではありません。警告書の送付・対応に関する最終判断は、必ず弁護士にご相談ください。
