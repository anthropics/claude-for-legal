## 特許法第35条の構造

### 職務発明の定義（第35条第1項）

従業者等がその性質上使用者等の業務範囲に属し、かつ、その発明をするに至った行為がその使用者等における従業者等の現在又は過去の職務に属する発明。

### 使用者等の通常実施権（第35条第1項）

職務発明について、使用者等は無償の通常実施権を有する。

### 予約承継（第35条第2項・第3項）

- 契約、勤務規則その他の定めにより、職務発明について使用者等に特許を受ける権利を取得させることができる（第2項）
- **2015年改正:** あらかじめ使用者等に特許を受ける権利を取得させることを定めた場合、特許を受ける権利は**初めから使用者等に帰属**する（第3項）— 原始帰属制度

### 相当の利益（第35条第4項・第5項）

従業者等は「相当の利益」を受ける権利を有する。「相当の利益」には、金銭以外の経済上の利益（昇進、留学機会、研究環境の提供等）も含まれる。

**利益の算定で考慮される手続（第35条第5項）:**
1. **協議の状況:** 使用者等と従業者等の協議の有無・内容
2. **基準の開示の状況:** 相当の利益の内容を決定するための基準の策定に際しての開示の有無・内容
3. **従業者等の意見の聴取の状況:** 意見聴取の有無・内容

**重要判例:**
- オリンパス事件（最判平成15年4月22日民集57巻4号477頁）— 勤務規則による対価が「相当の対価」に満たない場合、従業者は不足額を請求できる
- 青色LED事件（東京地判平成16年1月30日）— 職務発明対価として高額が認定された事案（控訴審で和解）

## レビューチェックリスト

### A. 職務発明規程の存在と有効性

- [ ] 職務発明規程が策定されているか
- [ ] 取締役会決議等、適切な手続を経て策定されたか
- [ ] 従業者等に周知されているか
- [ ] 最終改定日はいつか（2015年改正に対応しているか）

### B. 権利帰属の規定

- [ ] 予約承継の規定があるか
- [ ] 原始帰属制度（2015年改正）を採用しているか
- [ ] 出願しない場合の取扱いが定められているか
- [ ] 外国出願の取扱いが定められているか

### C. 相当の利益の規定

- [ ] 相当の利益の算定基準が定められているか
- [ ] 出願時報奨、登録時報奨、実績報奨の区分があるか
- [ ] 金銭以外の利益（昇進、研究環境等）が考慮されているか
- [ ] 利益の算定根拠が明確か

### D. 手続的要件

- [ ] 従業者等との協議の手続が定められているか
- [ ] 基準の策定に際して開示が行われているか
- [ ] 従業者等の意見聴取の機会が確保されているか
- [ ] 異議申立制度があるか

### E. 発明届出フロー

- [ ] 発明届出書の様式が定められているか
- [ ] 発明評価委員会等の評価体制があるか
- [ ] 出願判断の基準が明確か
- [ ] 出願見送りの場合のフィードバックがあるか
