# /design-registration

**これは初期スクリーニングであり、意匠登録の可否判断ではありません。** 正式な意匠登録の可否判断には、J-PlatPatでの先行意匠調査と弁理士による新規性・創作非容易性の評価が必要です。

## 手順

1. `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` を読み込む。
2. インテーク（デザインの説明、物品、出願形態）を実行する。
3. 登録要件のスクリーニングを実行する。
4. 適切な出願形態を提案する。

## 意匠法の基本構造

### 保護対象（意匠法第2条）

意匠とは、物品の形状、模様若しくは色彩若しくはこれらの結合（物品の意匠）、建築物の形状等（建築物の意匠）、又は画像（画像の意匠）であって、視覚を通じて美感を起こさせるもの。

**2020年改正による拡大:**
- **画像デザイン:** 物品に記録されていない画像（クラウド上のUI等）も保護対象に
- **建築物の意匠:** 建築物の外観・内装が保護対象に
- **内装の意匠:** 店舗・オフィス等の内装デザインが一つの意匠として保護可能

### 登録要件

| 要件 | 条文 | 内容 |
|---|---|---|
| 工業上利用可能性 | 第3条第1項柱書 | 工業的に量産可能であること |
| 新規性 | 第3条第1項各号 | 出願前に公知でないこと |
| 創作非容易性 | 第3条第2項 | 当業者が容易に創作できないこと |
| 先願 | 第9条 | 同一・類似の意匠について最先の出願であること |
| 不登録事由なし | 第5条 | 公序良俗違反等に該当しないこと |

### 出願形態の選択肢

| 形態 | 説明 | 適する場合 |
|---|---|---|
| **全体意匠** | 物品全体のデザイン | 製品全体の形状が特徴的 |
| **部分意匠** | 物品の一部のデザイン | 特定の部分のみが独創的 |
| **関連意匠** | 本意匠に類似するバリエーション | デザインバリエーションを保護したい |
| **秘密意匠** | 最大3年間、意匠を非公開 | 発売前に出願し、競合への情報漏洩を防ぎたい |
| **組物の意匠** | 同時に使用されるセットのデザイン | 食器セット、家具セット等 |
| **内装の意匠** | 店舗・オフィス等の内装全体 | 空間デザインを保護したい |

### 関連意匠制度（2020年改正後）

- 本意匠の出願日から**10年以内**に関連意匠を出願可能（改正前は同日出願のみ）
- 関連意匠にさらに類似する意匠も関連意匠として出願可能
- デザインの進化・バリエーション展開に対応

### 新規性喪失の例外（意匠法第4条）

- 適用期間: 公開から**1年以内**（特許の6ヶ月より長い）
- 手続: 出願と同時に例外適用の旨を記載＋出願から30日以内に証明書を提出
