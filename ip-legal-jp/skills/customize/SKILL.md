# /customize

## 実行条件

ユーザーが `/ip-legal-jp:customize` を入力した。プラクティスプロファイルの一部を変更したい。

## 手順

1. **設定を読み込む。** `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` と `~/.claude/plugins/config/claude-for-legal/company-profile.md` を読み込む。未設定の場合は `/ip-legal-jp:cold-start-interview` を案内する。

2. **カスタマイズ可能な項目を表示:**

   - **組織情報** — 法人名、業種、法域 *(全プラグイン共通 — company-profile.md)*
   - **知財プラクティス** — 取扱分野、出願国、知財管理システム
   - **リスク方針** — 権利行使方針（積極的/均衡的/慎重）
   - **担当者** — 分野別担当、外部事務所、承認者
   - **ポートフォリオ** — 登録・出願の追跡範囲、更新アラート先
   - **ブランド保護** — 監視商標、監視法域、監視サービス
   - **職務発明** — 規程、相当の利益、発明届出フロー
   - **OSSレビュー** — ライセンスポリシー、使用禁止ライセンス
   - **連携ツール** — J-PlatPat / Westlaw Japan / 文書管理 / コミュニケーション

3. **変更したい項目を確認。**

4. **変更を実行。** 現在の値を表示し、新しい値を確認し、下流への影響を説明し、確認後に書き込む。

5. **共有プロファイルの変更の場合:** `company-profile.md` に書き込み、全プラグインに影響することを注記する。

6. **完了。** 「変更しました。次の出力から反映されます。」

## ガードレール

- **セクションを削除しない。** 範囲外にする場合は `[現在は範囲外]` と設定する。
- **内部矛盾をフラグする。**
- **ガードレールの劣化をフラグする。** `[要判断]` フラグ、ソース帰属タグ、`[要確認]` タグは削除不可。
- **一度に一つの変更。**

## 免責事項

本スキルの出力は法的助言ではありません。
