# /invention-intake

**これは初期スクリーニングであり、特許性の判断ではありません。** スクリーニングは、発明が初期審査を通過し先行技術調査と弁理士レビューに値するか、追加情報が必要か、または出願要件を満たさないかを判断します。

## 手順

1. `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` を読み込む。特許実務を扱っていない場合は、その旨を伝え他に案内する。
2. インテークを実行する。
3. 6つのスクリーンを実行する。
4. 職務発明（特許法第35条）の確認を必須で実行する。
5. 新規性喪失の例外（特許法第30条）の該当性を確認する。

## インテーク

> 1. **何を発明しましたか？** 技術的な説明
> 2. **解決する課題は？** 従来技術の問題点
> 3. **従来技術との違いは？** 新しい点、工夫した点
> 4. **発明者は？** 全員の氏名。共同発明の場合は各人の貢献
> 5. **公開状況:** 学会発表、論文、展示会、製品販売等、この発明を公開したことはありますか？ある場合はいつ、どこで？
> 6. **開発状況:** 試作品あり / 設計段階 / アイデア段階
> 7. **技術分野:** [分類]

## 6つのスクリーン

### 1. 新規性シグナル（特許法第29条第1項）

- 公知（第1号）: 出願前に日本国内又は外国において公然知られた発明か
- 公用（第2号）: 出願前に日本国内又は外国において公然実施をされた発明か
- 刊行物記載（第3号）: 出願前に頒布された刊行物に記載された発明又は電気通信回線を通じて公衆に利用可能となった発明か

### 2. 進歩性フラグ（特許法第29条第2項）

当業者が容易に発明をすることができたか。動機づけ、阻害要因、予測できない効果を考慮。

### 3. 特許適格性

日本の特許法では、米国のAlice/Mayo判決のような厳格な適格性テストはない。「自然法則を利用した技術的思想の創作のうち高度のもの」（特許法第2条第1項）が特許の対象。ビジネスモデル特許はソフトウェアによる技術的手段を伴えば登録可能。

### 4. 公開バー日 / 新規性喪失の例外（特許法第30条）

**特許法第30条（発明の新規性の喪失の例外）:**
- 適用期間: 公開から**6ヶ月以内**に出願すれば、新規性喪失の例外の適用を受けることが可能
- 適用対象: 発明者の行為に起因する公開（学会発表、論文、展示会等）
- 手続: 出願と同時に例外適用の旨を記載した書面を提出＋出願から30日以内に証明書を提出
- **注意:** この例外は日本出願にのみ適用。外国出願では各国の制度に従う（多くの国には例外規定がないか、期間が異なる）

**フラグ:** 公開がある場合は出力の冒頭に **時間的制約あり** と表示。

### 5. 検出可能性

侵害行為を検出できるか。方法発明で内部プロセスの場合は検出困難。

### 6. 戦略的価値

事業との関連性、ライセンス可能性、防衛的価値。

## 職務発明の確認（特許法第35条）— 必須

**発明者が従業員等の場合、以下を確認する:**

1. **職務発明該当性:** 従業者等がその性質上使用者等の業務範囲に属し、かつ、その発明をするに至った行為がその使用者等における従業者等の現在又は過去の職務に属する発明か（第35条第1項）
2. **権利の帰属:** 職務発明規程による予約承継の有無。2015年改正により、職務発明規程に定めがある場合、特許を受ける権利は初めから使用者等に帰属させることが可能（第35条第3項）
3. **相当の利益:** 職務発明規程に基づく相当の利益の支払い（第35条第4項）。利益の決定には、従業者等との協議、基準の策定における開示、意見聴取が考慮される（第35条第5項）
4. **実用新案の選択肢:** 特許出願に代えて実用新案登録出願（無審査登録、10年保護）を検討する価値があるか
