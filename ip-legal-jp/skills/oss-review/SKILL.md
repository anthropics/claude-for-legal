# /oss-review

OSSライセンスコンプライアンスチェックを `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` のプラクティスプロファイル（およびOSSポリシーがあればそれ）に照らして実行する。

## 手順

1. **プラクティスプロファイルを読み込む。** OSSポリシーがある場合はそれも読み込む。
2. **スコープを確定:** 依存関係リスト / 個別ライブラリ / アウトバウンドコード。
3. **デプロイメントモデルを確認** — SaaS / バイナリ配布 / 内部利用のみ / 組込み。
4. **ライセンス分類を実行。**
5. **メモを出力。**

## 日本法固有の考慮事項

### 著作権法との関係

- OSSライセンスは著作権法上の利用許諾（第63条）として機能する
- 著作権法第2条第1項第11号に定める二次的著作物の定義に基づき、派生物の範囲を判断する
- 日本にはフェアユースの一般条項がないため、制限規定（第30条〜第50条）の限定列挙に依拠する必要がある
- 著作権法第30条の4（著作物に表現された思想又は感情の享受を目的としない利用）がAI学習との関係で議論されている

### 日本のOSS判例の限定性

日本にはOSSライセンスに関する判例がほとんどない。GPLの法的効力、コピーレフトのトリガー条件等について、日本法の下での確定的な解釈は存在しない。この不確実性を出力に明記する。

### ライセンス分類

| カテゴリ | ライセンス例 | リスク |
|---|---|---|
| Permissive | MIT, BSD-2, BSD-3, Apache-2.0, ISC | 🟢 低リスク |
| Weak copyleft | LGPL-2.1, LGPL-3.0, MPL-2.0, EPL-2.0 | 🟡 要確認 |
| Strong copyleft | GPL-2.0, GPL-3.0, AGPL-3.0 | 🟠 重要 |
| Non-OSI | SSPL, BUSL, Commons Clause, Elastic License | 🔴 要注意 |
| Unknown | ライセンス記載なし | 🔴 要確認 |

## 弁護士確認ゲート

Strong copyleftまたはライセンス不明のパッケージは弁護士レビューが必要。

## 免責事項

本スキルの出力は法的助言ではありません。OSSライセンスの解釈・コンプライアンスに関する最終判断は、必ず弁護士にご相談ください。
