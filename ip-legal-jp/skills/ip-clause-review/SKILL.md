# /ip-clause-review

契約書中のIP条項を `~/.claude/plugins/config/claude-for-legal/ip-legal-jp/CLAUDE.md` のプラクティスプロファイルに照らしてレビューする。権利帰属の不備、ライセンス範囲の問題、IP保証・補償の問題をフラグし、リスク優先度順にメモを生成する。

## 手順

1. **プラクティスプロファイルを読み込む。**
2. **契約書を取得:** ファイルパス、Driveリンク、またはテキスト貼り付けから。
3. **契約類型と自社の立場を確認** — 委託者/受託者、ライセンサー/ライセンシー。
4. **日本法固有のチェックを実行。**
5. **条項別の分析結果をリスク順に出力。**

## 日本法固有のチェック項目

### 職務著作（著作権法第15条）

法人著作の成立要件:
1. 法人等の発意に基づくこと
2. 法人等の業務に従事する者が作成すること
3. 職務上作成すること
4. 法人等が自己の著作の名義の下に公表するものであること（プログラムの著作物を除く）
5. 契約、勤務規則その他に別段の定めがないこと

**チェックポイント:**
- 契約で著作権法第15条の適用を排除していないか
- 業務委託契約の場合、受託者の従業員が作成した著作物の帰属はどうなるか
- プログラムの著作物の場合、公表名義要件が不要であることを考慮しているか

### 著作者人格権不行使特約

日本の著作者人格権（同一性保持権・氏名表示権・公表権）は譲渡不可（著作権法第59条）。実務では「著作者人格権を行使しない」旨の不行使特約を契約に規定する。

**チェックポイント:**
- 著作者人格権不行使特約が含まれているか
- 不行使の範囲（同一性保持権のみか、全ての著作者人格権か）
- 契約終了後も不行使義務が存続するか

### 職務発明（特許法第35条）

**チェックポイント:**
- 職務発明の予約承継規定があるか
- 相当の利益の支払いに関する規定があるか
- 2015年改正後の原始帰属制度を採用しているか
- 従業者等との協議・開示・意見聴取の手続が定められているか

### 甲/乙表記

日本の契約書では当事者を「甲」「乙」で表記することが一般的。自社がどちらの立場かを最初に確認する。

### 権利の種類の網羅性

日本法では、以下の権利が別個に規律される:
- 特許権（特許法）
- 実用新案権（実用新案法）
- 意匠権（意匠法）
- 商標権（商標法）
- 著作権・著作者人格権（著作権法）
- 回路配置利用権（半導体集積回路の回路配置に関する法律）
- 育成者権（種苗法）
- 営業秘密（不正競争防止法）
- ノウハウ

契約書のIP条項がこれらを適切にカバーしているか確認する。
