# 規制ギャップ分析

## 目的

新しいAI関連法令・ガイドラインの要件を現在のガバナンス体制と照合し、
ギャップを特定して是正計画を作成する。

## リサーチファースト

各法令・ガイドラインについて、ギャップ分析の前に以下を調査：
- 適用範囲、適用閾値
- 規制の具体的内容・要件
- 執行メカニズム、罰則
- 施行日、経過措置

## ワークフロー

### ステップ1: 適用範囲の確認

- 法域：日本法か、域外適用か
- 業種：特定業種向けか、全業種か
- 閾値：従業員数、売上規模、データ取扱量等
- 役割：AI開発者/AI提供者/AI利用者のいずれに適用か

### ステップ2: 要件の抽出

| # | 要件 | 条文・根拠 | カテゴリ |
|---|------|-----------|---------|
| | | | 透明性/影響評価/人間監視/精度/ガバナンス/ベンダー管理/禁止行為/権利 |

### ステップ3: 現状との差分

| # | 要件 | 規制の要求 | 現在の対応 | ギャップレベル | 不足事項 | 対応工数 | 未対応リスク |
|---|------|-----------|-----------|--------------|----------|----------|-------------|

### ステップ4: 優先順位付け

1. 施行期限（ハードデッドライン）
2. 禁止行為（即時対応要）
3. 対応工数と影響度のバランス
4. ユースケースとの重複度

### ステップ5: 是正計画

| カテゴリ | 内容 |
|----------|------|
| 必須対応 | 期限までに対応が必要な事項 |
| 推奨対応 | 対応が望ましい事項 |
| 対応済み | 既に要件を充足している事項 |
| 受容リスク | 対応しないことを決定し、根拠を文書化した事項 |

出典の信頼度タグ：`[確定]` / `[要確認]` / `[要確認・要出典]`
