# 著作権法第30条の4 AI著作権評価

## 重要性

著作権法第30条の4は、日本のAI開発において極めて重要な規定です。
情報解析の用に供する場合における著作物の利用を、一定の条件のもとで
著作権者の許諾なく認めるものですが、その適用範囲と限界について
正確な理解が不可欠です。

## 評価フロー

### ステップ1: 利用シナリオの整理

以下を確認：

1. **利用の主体**: AI開発者 / AI提供者 / AI利用者
2. **利用の態様**:
   - AIモデルの学習（訓練）データとしての利用
   - ファインチューニング用データとしての利用
   - RAG（検索拡張生成）用データとしての利用
   - AIによる情報解析・分析
   - AIの推論（出力生成）段階での利用
3. **対象著作物**: テキスト / 画像 / 音声 / 動画 / プログラム
4. **著作物の入手経路**: 公開情報 / ライセンス契約 / 社内文書 / 第三者提供

### ステップ2: 第30条の4の適用分析

著作権法第30条の4の要件を順次確認：

#### 2-1. 「著作物に表現された思想又は感情の享受を目的としない」利用か

| 利用パターン | 享受目的の有無 | 判断根拠 |
|-------------|---------------|----------|
| 大量データでの機械学習 | 通常なし | 情報解析目的 [確定] |
| ファインチューニング | 要個別判断 | 目的と態様による [要確認] |
| RAGでの全文引用出力 | 享受目的あり得る | 出力態様による [要確認] |
| AI生成物が元著作物に類似 | 享受目的併存の可能性 | 文化庁考え方参照 [要確認] |

#### 2-2. 享受目的併存の判断（文化庁「AIと著作権に関する考え方」）

享受目的が「併存」する場合、第30条の4は適用されない可能性：

- **併存の典型例**:
  - 特定の作家のスタイルを再現する目的でのファインチューニング
  - 特定の著作物の表現上の本質的特徴を出力させる意図での学習
  - 著作物のデータベースを構築し、そのまま出力するサービス

- **併存しない典型例**:
  - 汎用的な言語モデルの学習における大量コーパスの利用
  - 感情分析等の非生成的な情報解析
  - 技術的検証のためのベンチマークデータとしての利用

> **⚠ [要確認]**: 享受目的の併存判断は事案ごとの個別判断が必要です。
> 弁護士による確認を受けてください。

#### 2-3. 「著作権者の利益を不当に害する」場合の判断

第30条の4ただし書きの該当性を確認：

| 考慮要素 | 確認事項 |
|----------|----------|
| 著作物の種類・性質 | データベースの著作物等、情報解析用に市場提供されているものか |
| 利用の態様 | 大量複製の規模、複製物の管理状況 |
| 市場への影響 | 著作権者の将来的なライセンス市場を害するか |
| 技術的保護手段 | robots.txt等のオプトアウト措置の有無と対応 |
| 契約上の制限 | 利用規約でAI学習を禁止していないか |

### ステップ3: 第47条の5（軽微利用）の検討

AI出力段階で著作物の一部を利用する場合：

- 検索結果の表示における著作物の軽微な利用
- 情報解析結果の提示に伴う著作物の軽微な利用
- 「軽微」の範囲は利用の目的、著作物の種類に照らして判断

### ステップ4: AI生成物の著作権

AI生成物の著作物性：

| 場面 | 著作物性 | 根拠 |
|------|----------|------|
| AIが自律的に生成 | なし（原則） | 人間の創作的関与なし [確定] |
| 人間がAIを道具として利用 | あり得る | 創作的寄与の程度による [要確認] |
| AI生成物を人間が編集 | 編集部分に著作物性 | 創作性の付加 [確定] |

## 失敗モード（避けるべきこと）

- 第30条の4の適用を安易に肯定しない — 享受目的の有無は慎重に判断
- 文化庁の「考え方」を法的拘束力のある基準として扱わない — あくまで解釈指針
- AI生成物に著作物性がないと断定しない — 人間の創作的関与の程度による
- 契約上のAI学習禁止条項を見落とさない — 法律上の権利制限とは別問題
