# マターワークスペース

## デフォルト状態はオフ

インハウス（企業法務）ではこの機能は不要。
法律事務所の場合はコールドスタートで有効化を提案。

## サブコマンド

### `new <slug>` — 新規案件

インテーク情報を収集：
- クライアント名
- 相手方
- 案件種別（ユースケース評価 / ベンダーAIレビュー / AI影響評価 / 規制対応 / ポリシー策定 / その他）
- 秘密保持レベル（標準 / 厳格 / クリーンチーム）
- 重要事実
- 案件固有の設定変更
- 関連案件

### `list` — 一覧表示

全案件のステータス一覧を表示。

### `switch <slug>` — 切替

アクティブ案件を切り替え。

### `close <slug>` — クローズ

案件をクローズし、アーカイブ。

### `none` — デタッチ

アクティブ案件を解除（案件に紐づかない作業に切替）。

## ストレージ構成

```
~/.claude/plugins/config/claude-for-legal/ai-governance-legal-jp/matters/<slug>/
├── matter.md      # 案件情報
├── history.md     # イベントログ（追記のみ、最新が上）
├── notes.md       # メモ
└── outputs/       # 出力ファイル
```

## アクティブ案件

アクティブ案件の唯一の真実は、プラクティスレベルの CLAUDE.md 内の
`アクティブ案件:` 行。

## 案件間コンテキスト

- デフォルト（オフ）: スキルは他の案件フォルダを読み取らない
- オン: ユーザーの明示的な要求がある場合のみ

## してはいけないこと

- コンフリクトチェックを行わない
- リテンション（保存期間）を強制しない
- 出力を自動ルーティングしない
- 案件間の情報共有の適切性を判断しない
