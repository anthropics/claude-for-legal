# AI事業者ガイドライン7原則コンプライアンス

## 目的

AI事業者ガイドライン（総務省・経済産業省）が定める7原則について、
AIシステムまたは組織全体の対応状況を評価し、ギャップを特定し、
改善アクションプランを作成します。

## AI事業者ガイドライン7原則

| # | 原則 | 概要 |
|---|------|------|
| 1 | 人間中心 | AIの利用において人間の尊厳と自律性を尊重し、人間が最終的な判断・制御を行う |
| 2 | 安全性 | AIシステムのリスクを適切に管理し、安全性を確保する |
| 3 | 公平性 | AIの判断においてバイアスや不当な差別を防止する |
| 4 | プライバシー保護 | 個人情報・プライバシーを適切に保護する |
| 5 | セキュリティ確保 | AIシステムのサイバーセキュリティを確保する |
| 6 | 透明性 | AIの利用について適切に開示し、説明可能性を確保する |
| 7 | アカウンタビリティ | AIの利用に関する責任体制を確立し、説明責任を果たす |

## 評価フロー

### ステップ1: 評価対象の特定

- **単一システム評価**: 指定されたAIシステムの7原則対応を評価
- **全体評価**: 組織全体のAIガバナンス体制を7原則で評価
- インベントリ（`/ai-inventory`）からシステム情報を取得

### ステップ2: 役割別の対応要件の確認

AI事業者ガイドラインでは、役割によって求められる対応が異なる：

| 原則 | AI開発者 | AI提供者 | AI利用者 |
|------|---------|---------|---------|
| 人間中心 | 人間の関与を可能にする設計 | 利用者への適切な情報提供 | 人間による最終判断の実施 |
| 安全性 | 安全なモデル開発・テスト | リスク情報の提供・品質管理 | 利用環境でのリスク管理 |
| 公平性 | バイアステスト・軽減措置 | 公平性に関する情報開示 | 運用段階での公平性監視 |
| プライバシー | プライバシーバイデザイン | プライバシーポリシーの提供 | データの適切な取扱い |
| セキュリティ | セキュアな開発プロセス | セキュリティ対策の実装 | セキュリティ運用の実施 |
| 透明性 | モデルの説明可能性確保 | サービスの透明性確保 | AI利用の開示 |
| アカウンタビリティ | 開発プロセスの文書化 | 責任体制の明確化 | 利用に関する説明責任 |

### ステップ3: 原則ごとの評価

各原則について以下を確認：

1. **方針**: 該当原則に関する社内方針・規程があるか
2. **体制**: 担当者・責任者が設定されているか
3. **プロセス**: 具体的な実施手順・プロセスがあるか
4. **実績**: 実際に運用されているか、記録があるか
5. **改善**: 定期的な見直し・改善メカニズムがあるか

評価レベル：

| レベル | 定義 |
|--------|------|
| ● 対応済み | 方針・体制・プロセスが整備され、運用実績あり |
| ◐ 一部対応 | 一部は対応しているが、不十分な領域あり |
| ○ 未対応 | 対応が不十分または未着手 |
| — 該当なし | 当該原則が該当しない（根拠を記録） |

### ステップ4: ギャップ分析

対応が不十分な項目を整理：

| # | 原則 | ギャップ | 重要度 | 推奨アクション | 期限 | 担当 |
|---|------|---------|--------|---------------|------|------|
| | | | 高/中/低 | | | |
