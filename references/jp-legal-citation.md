# 日本の法令・判例引用形式

## 法令引用

### 法律

| 形式 | 例 |
|------|-----|
| 条 | 民法第709条 |
| 条・項 | 会社法第362条第4項 |
| 条・項・号 | 会社法第362条第4項第6号 |
| 但書 | 民法第1条第3項但書 |
| 前段・後段 | 民法第415条第1項前段 |
| 本文 | 民法第466条第2項本文 |

### 政令（施行令）

- 個人情報の保護に関する法律施行令第○条
- 会社法施行令第○条

### 省令（施行規則）

- 会社法施行規則第101条
- 個人情報の保護に関する法律施行規則第○条

### 告示・ガイドライン

- 個人情報保護委員会告示第○号
- 公正取引委員会「流通・取引慣行に関する独占禁止法上の指針」
- 経済産業省「AI・データの利用に関する契約ガイドライン」

## 判例引用

### 最高裁判所

- **大法廷判決**: 最大判平成10年2月24日民集52巻1号113頁
- **小法廷判決**: 最一小判令和○年○月○日民集○巻○号○頁
- **決定**: 最決令和○年○月○日刑集○巻○号○頁

通称がある場合は括弧で付記:
- 最判平成10年2月24日民集52巻1号113頁（ボールスプライン事件）
- 最大判昭和48年12月12日刑集27巻11号1536頁（三菱樹脂事件）

### 高等裁判所

- 大阪高判令和○年○月○日判タ○号○頁
- 知財高判令和○年○月○日判時○号○頁
