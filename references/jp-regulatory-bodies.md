# 日本の主要規制当局一覧

| 規制当局 | 所管法令 | 主要権限 |
|----------|----------|----------|
| 金融庁（FSA） | 金融商品取引法、銀行法、保険業法、資金決済法 | 金融機関の監督・検査、有価証券届出書の審査、課徴金納付命令、業務改善命令 |
| 公正取引委員会（JFTC） | 独占禁止法、下請法、景品表示法（共管） | 排除措置命令、課徴金納付命令、企業結合審査、下請法勧告 |
| 個人情報保護委員会（PPC） | 個人情報保護法 | 報告徴収・立入検査、指導・助言、勧告・命令、外国執行当局との協力 |
| 消費者庁 | 景品表示法、特定商取引法、消費者契約法 | 措置命令、課徴金納付命令、業務停止命令、差止請求関係業務 |
| 経済産業省（METI） | 不正競争防止法、特定商取引法（共管）、外為法（共管） | 営業秘密侵害罪の告発、輸出管理、安全保障貿易管理 |
| 厚生労働省 | 労働基準法、労働安全衛生法、男女雇用機会均等法、育児介護休業法 | 労働基準監督署による臨検監督、是正勧告、送検、助言・指導 |
| 総務省 | 電気通信事業法、放送法、行政手続法 | 電気通信事業者の監督、個人情報保護（旧所管分の執行）、通信の秘密保護 |
| 法務省 | 会社法（登記）、入管法、人権擁護 | 商業登記、法人登記、外国人の在留管理、人権侵犯事件の調査 |
| 特許庁（JPO） | 特許法、実用新案法、意匠法、商標法 | 特許・商標等の審査・登録、審判、国際出願受理 |
| 文化庁 | 著作権法 | 著作権登録、裁定制度、著作権侵害に関する助言 |
| 国税庁 | 所得税法、法人税法、消費税法、印紙税法 | 税務調査、更正・決定、加算税賦課、滞納処分 |
| 証券取引等監視委員会（SESC） | 金融商品取引法 | 犯則事件の調査、課徴金調査、検査、勧告（金融庁への建議） |
| 労働委員会 | 労働組合法 | 不当労働行為の審査、労働争議の調整（あっせん・調停・仲裁） |

## 地方自治体の規制権限

- 都道府県労働局: 個別労働紛争のあっせん、雇用均等室
- 都道府県消費生活センター: 消費者相談、事業者への要望
- 都道府県公安委員会: 反社会的勢力排除条例の執行

## 自主規制機関

| 機関 | 対象 |
|------|------|
| 日本弁護士連合会（日弁連） | 弁護士の懲戒・監督 |
| 日本公認会計士協会 | 公認会計士の品質管理・懲戒 |
| 日本取引所自主規制法人 | 上場会社のコンプライアンス |
| 全国銀行協会 | 銀行取引の自主規制 |
