# 日本の契約書慣行

## 当事者表記

| 略称 | 意味 | 用法 |
|------|------|------|
| 甲 | 第一当事者 | 通常はサービス提供者・売主・委託者 |
| 乙 | 第二当事者 | 通常はサービス受領者・買主・受託者 |
| 丙 | 第三当事者 | 三者間契約の場合 |
| 丁 | 第四当事者 | 四者間契約の場合（稀） |

近年は「甲乙」の代わりに当事者名の略称（例: 「A社」「B社」）を使用する例も増えている。

## 条項構造

```
第○条（見出し）         ← 条（Article）
  第○項                 ← 項（Paragraph） ※第1項は番号を省略することが多い
    第○号               ← 号（Item）
      イ、ロ、ハ...      ← 枝番号
```

- 条番号は通し番号（章ごとにリセットしない）
- 項番号は各条内で1から振り直し
- 号番号は各項内で1から振り直し

## 契約書の構成

1. **表題** — 契約の種類を示す（例: 業務委託契約書、秘密保持契約書）
2. **前文** — 当事者の特定と契約の目的・趣旨
3. **本文** — 各条項
4. **末文** — 契約成立の証明文言
5. **日付** — 契約締結日
6. **署名欄** — 当事者の住所・商号・代表者名・押印

## 前文の典型例

```
○○株式会社（以下「甲」という。）と△△株式会社（以下「乙」という。）は、
○○に関し、以下のとおり契約（以下「本契約」という。）を締結する。
```

## 末文の典型例

```
本契約の成立を証するため、本書2通を作成し、甲乙記名押印のうえ各1通を保有する。
```

電子契約の場合:
```
本契約の成立を証するため、本電磁的記録を作成し、甲乙それぞれ電子署名を行う。
```

## 記名押印・署名

- **記名押印**: 会社名を記載（印字可）し、代表取締役印（丸印）を押印
- **署名捺印**: 代表者が自署し、押印
- **電子署名**: 電子署名法に基づく電子署名（クラウドサイン等の立会人型も実務上広く使用）

## 収入印紙

- 印紙税法別表第一に定める課税文書に該当する場合、所定の収入印紙を貼付
- 主な課税文書: 請負契約書（2号文書）、継続的取引の基本契約書（7号文書）
- 電子契約は課税文書に該当しない（印紙税不要）

## 覚書・変更合意書

- 原契約の一部を変更する場合は「覚書」または「変更合意書」を締結
- 「第○条を以下のとおり変更する」形式が一般的
- 原契約の条項番号を明示し、変更箇所を特定する

## 日付の記載方法

- 和暦: 令和○年○月○日（公的書類・登記で多用）
- 西暦: 2025年○月○日（国際取引・外資系企業で多用）
- いずれも有効だが、一つの契約書内では統一する
