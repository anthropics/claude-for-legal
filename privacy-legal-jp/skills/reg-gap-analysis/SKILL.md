## 目的

個人情報保護に関する法令・ガイドラインの最新の変更と自社の現行体制とのギャップを分析する。APPIは3年ごとの見直しが法定されており、PPC告示・ガイドラインの改定、関連法令の改正が頻繁に行われる。

## 分析フレームワーク

### 各変更事項について

| 分析項目 | 内容 |
|---|---|
| **変更の概要** | 何が変わったか |
| **施行日** | いつから適用されるか |
| **自社への影響** | 自社の規制フットプリントに該当するか |
| **現行体制との差分** | 現行のプロファイル設定と乖離があるか |
| **対応の優先度** | 🔴対応必須/🟠重要/🟡要確認/🟢影響なし |
| **対応期限** | 施行日から逆算した対応スケジュール |
| **必要な対応** | 具体的な対応事項 |

### ギャップの分類

| ギャップ種類 | 説明 | 対応 |
|---|---|---|
| **規程ギャップ** | 社内規程が法改正に未対応 | 規程の改定 |
| **体制ギャップ** | 組織体制が新要件に未対応 | 体制の見直し |
| **ポリシーギャップ** | 公表事項が新要件を未反映 | ポリシーの更新 |
| **契約ギャップ** | 委託契約等が新要件を未反映 | 契約の改定 |
| **技術ギャップ** | 技術的措置が新要件に未対応 | 技術的対応 |

## 意思決定ツリー

> **次のステップは？選んでください：**
> 1. **対応計画の詳細化** — 各ギャップについて具体的な対応手順を作成
> 2. **規程改定ドラフト** — 社内規程の改定案を作成
> 3. **ポリシー更新** — `/privacy-legal-jp:policy-monitor` でポリシーの更新を確認
> 4. **委託契約の見直し** — `/privacy-legal-jp:dpa-review` で既存契約を法改正に照合
> 5. **エスカレーション** — [エスカレーション先]宛の法改正対応レポートを作成
> 6. **その他**

## このスキルが行わないこと

- 法改正の正確な施行日を保証しない — PPC等の公式情報源で確認必要
- パブリックコメント対応のドラフトは行わない
- 外国法の改正動向分析は行わない — GDPR等は `privacy-legal` プラグインを使用
- 法改正に基づく訴訟リスクの評価は行わない
- 規程の最終的な法的レビューは行わない — 弁護士の役割

## 免責事項

本分析は個人情報保護関連法令・ガイドラインの変更と自社体制のギャップを特定する支援であり、法改正の網羅的な解説や公式な法的助言を代替するものではありません。法改正への対応方針は弁護士の確認を得てから決定してください。
