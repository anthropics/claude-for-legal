# /customize

## 目的

プラクティスプロファイルの一部を変更したい場合に使用する。コールドスタートインタビューを再実行することなく、特定のセクションだけを更新できる。

## ワークフロー

### ステップ1: 設定の読み込み

`~/.claude/plugins/config/claude-for-legal/privacy-legal-jp/CLAUDE.md`（および `~/.claude/plugins/config/claude-for-legal/company-profile.md`）を読み込む。プラグイン設定が存在しない、またはすべてが `[PLACEHOLDER]` の場合：

> まだセットアップが完了していません。`/privacy-legal-jp:cold-start-interview` を先に実行してください。カスタマイズは既存のプロファイルを調整するためのスキルです。

### ステップ2: カスタマイズ可能な項目の表示

プロファイルの内容をグループ化し、現在の値を1行で表示：

- **組織情報** — 会社名、業種、規模（全プラグインで共有 — `company-profile.md` 経由で変更）
- **規制フットプリント** — 適用法令・ガイドラインの一覧
- **委託契約プレイブック** — 委託者/受託者の各条項ポジション
- **PIAハウススタイル** — トリガー、フォーマット、承認者
- **開示等請求対応** — 本人確認方法、確認システム、応答目標
- **漏えい等報告体制** — 速報/確報フロー、連携体制
- **越境移転管理** — 移転先、移転根拠、詳細情報提供
- **エスカレーション** — エスカレーションチェーン
- **出力設定** — 秘密保持マーキング、出力言語、保存先
- **連携ツール** — 各MCP接続状態

### ステップ3: 変更の実行

> 何を変更しますか？セクション名を指定するか、変更内容を説明してください。

変更ごとに以下を実行：
1. 現在の値を表示
2. 新しい値を確認
3. 下流への影響を説明（例：「漏えい報告の速報期限を変更すると、`/ppc-report-drafting` のタイムラインチェックリストに反映されます」）
4. 確認を得てから書き込み

### ステップ4: 共有プロファイルの変更

会社名、業種、規模等の変更は `~/.claude/plugins/config/claude-for-legal/company-profile.md` に書き込み、以下を通知：

> この変更は全プラグインに影響します。

### ステップ5: 完了

> 変更を保存しました。次回の出力から反映されます。他に変更がありますか？
> いつでも `/privacy-legal-jp:customize` で変更できます。

## ガードレール

- **セクションの削除は行わない。** 「削除」の場合は `[未設定]` に設定し、影響を説明する。
- **内部矛盾をフラグする。** 例：マイナンバーの取扱いが「あり」なのに安全管理措置に番号法固有の記載がない。
- **ガードレールの無効化を警告する。** `[要判断]` タグの削除、秘密保持マーキングの無効化を要求された場合、そのガードレールが何を保護しているかを説明し、確認を求める。
- **1回に1つの変更。** インタビュー全体の再実行はしない。

## 使用例

```
/privacy-legal-jp:customize
越境移転管理の移転先国リストを更新したい
```

```
/privacy-legal-jp:customize
漏えい報告の速報期限を社内基準で2日以内に変更
```

```
/privacy-legal-jp:customize
PIAの承認者を個人情報保護管理者の田中から鈴木に変更
```

## このスキルが行わないこと

- コールドスタートインタビューの完全な再実行は行わない — `--redo` フラグを使用
- 法的助言を提供しない — 設定変更スキルであり、実体的な分析は行わない
- 他のプラグインの設定を変更しない — 共有プロファイル経由の変更のみ

## 免責事項

プラクティスプロファイルの変更は、本プラグインのすべてのスキルの出力に影響します。重要な設定変更は弁護士のレビューを経てから行ってください。
