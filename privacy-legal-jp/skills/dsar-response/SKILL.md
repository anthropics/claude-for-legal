# /dsar-response

1. `~/.claude/plugins/config/claude-for-legal/privacy-legal-jp/CLAUDE.md` → 開示等請求対応プロセスを読み込む。PLACEHOLDERの場合は停止してセットアップを案内。
2. 請求の種類を判定：開示（第33条）/ 訂正等（第34条）/ 利用停止等（第35条）/ 第三者提供停止（第35条）。
3. 以下のワークフローを実行。
4. 出力：対応手順チェックリスト + 回答書ドラフト。

```
/privacy-legal-jp:dsar-response "顧客から保有個人データの開示請求を受けた"
```

# 開示等請求対応（APPI第33条-第35条）

## 案件コンテキスト

**案件コンテキスト。** プラクティスレベルCLAUDE.mdの `## 案件ワークスペース` を確認。`有効` が `✗` の場合（企業内法務のデフォルト）、スキップ。

---

## 目的

本人からの開示等請求に対し、APPIに基づく適法な対応を支援する。請求の種類に応じた要件確認、本人確認手続き、回答書のドラフト作成、期限管理を行う。

## 請求種類の判定

まず、請求の種類を特定する：

| 請求種類 | 根拠条文 | 概要 |
|---|---|---|
| **開示請求** | 第33条 | 保有個人データの内容の開示（電磁的記録での提供を含む） |
| **訂正等請求** | 第34条 | 内容が事実でない場合の訂正・追加・削除 |
| **利用停止等請求** | 第35条第1-2項 | 利用目的制限違反・不正取得の場合の利用停止・消去 |
| **利用停止等請求（拡大）** | 第35条第5項 | 本人の権利利益が害されるおそれがある場合（2022年改正） |
| **第三者提供停止請求** | 第35条第3-4項 | 第三者提供制限違反の場合の提供停止 |
| **第三者提供停止請求（拡大）** | 第35条第5項 | 本人の権利利益が害されるおそれがある場合（2022年改正） |

不明な場合は確認する。複数の請求が同時に行われることもある。

## ステップ1: 受付・本人確認

### 本人確認チェックリスト

プラクティスプロファイルの `## 開示等請求対応プロセス → 本人確認方法` に従い確認：

- [ ] **本人確認書類の取得**
  - マイナンバーカード（表面のみ — 個人番号が記載された裏面は取得不可）
  - 運転免許証
  - パスポート
  - 健康保険被保険者証（記号・番号等をマスキング）
  - その他（プロファイルに記載の方法）
- [ ] **代理人による請求の場合**
  - 委任状の確認
  - 代理人の本人確認
  - 本人との関係の確認（法定代理人 / 任意代理人）
  - 未成年者の場合：法定代理人（親権者）の確認

### 受付の記録

- 受付日時
- 請求者氏名
- 請求の種類
- 請求の対象（どの保有個人データについてか）
- 本人確認の結果

## ステップ2: 対象データの特定

プラクティスプロファイルの `## 開示等請求対応プロセス → 確認すべきシステム` に記載された全システムを確認：

- [ ] 各システムで対象者のデータを検索
- [ ] 「保有個人データ」に該当するか確認（6ヶ月以内に消去するデータも2022年改正後は対象）
- [ ] 第三者提供記録（第29条・第30条）の確認
- [ ] 委託先に提供したデータの確認

### 保有個人データの判定

以下は「保有個人データ」に該当しない（開示義務なし）：

- 本人または第三者の生命、身体、財産その他の権利利益を害するおそれがあるもの
- 事業者の業務の適正な実施に著しい支障を及ぼすおそれがあるもの
- 他の法令に違反することとなるもの
- 国の安全が害されるおそれがあるもの等

## ステップ3: 対応方針の決定

### 開示請求（第33条）の場合

**全部開示 / 一部開示 / 不開示** の判定：

不開示事由（第33条第2項）：
1. 本人又は第三者の生命、身体、財産その他の権利利益を害するおそれがある場合
2. 事業者の業務の適正な実施に著しい支障を及ぼすおそれがある場合
3. 他の法令に違反することとなる場合

**開示方法（2022年改正）：**
- 本人が指定した方法で開示（電磁的記録の提供を含む）
- 本人が指定した方法による開示が困難な場合は書面で開示し、その旨と理由を通知

### 訂正等請求（第34条）の場合

- 「事実でないこと」の確認
- 利用目的の達成に必要な範囲内での訂正・追加・削除
- 他の法令の規定により特別の手続が定められている場合はその手続に従う

### 利用停止等請求（第35条）の場合

**従来の要件:**
- 利用目的による制限（第18条）違反
- 不正取得（第20条第1項）違反

**2022年改正で追加された拡大要件（第35条第5項）：**
- 利用する必要がなくなった場合
- 漏えい等が生じた場合
- その他本人の権利又は正当な利益が害されるおそれがある場合

## ステップ4: 回答書ドラフトの作成

### 回答書フォーマット（日本語ビジネス書簡形式）

```
                                        令和○年○月○日

[請求者名] 様

                            [会社名]
                            [部署名・担当者名]

        保有個人データの[開示/訂正/利用停止等]に関するご回答

拝啓　時下ますますご清栄のこととお慶び申し上げます。

[日付]付でご請求いただきました保有個人データの[開示/訂正/利用停止等]に
つきまして、以下のとおりご回答申し上げます。

1. ご請求の内容
  [請求内容の要約]

2. 対応結果
  [全部開示/一部開示/不開示/訂正/利用停止等の結果]

[一部開示・不開示の場合]
3. 開示しない部分とその理由
  [不開示事由の説明]

[手数料を徴収する場合]
4. 手数料
  [金額と支払方法]

本件に関するお問い合わせは、下記までご連絡ください。

[問い合わせ先]

                                        敬具
```

### 不開示の場合の通知書

不開示の理由を具体的に記載する。ただし、不開示事由を詳細に説明することで開示できない理由が明らかになる場合は、事由の記載に配慮する。

| 対応項目 | 期限 | 状態 |

## 弁護士確認ゲート

利用者が「法務部員等」または「その他」の場合：

> ⚖️ **弁護士確認ゲート:** 不開示事由の判断、一部開示の範囲、利用停止等の対応方針は法的判断を含みます。顧問弁護士に相談してから回答書を発送してください。

特に以下の場合は弁護士確認を強く推奨：
- 不開示事由を適用する場合
- 利用停止等請求（拡大要件）への対応
- 代理人による請求
- 訴訟提起の可能性がある場合

> 5. **その他** — ご要望をお聞かせください

## このスキルが行わないこと

- 回答書を自動的に送付しない — ドラフト作成と対応ガイドのみ
- 不開示事由の最終判断を行わない — 判断材料を提示し弁護士確認を促す
- 本人確認を代行しない — 本人確認手続きのチェックリストを提供
- 個人データの検索や取得を直接行わない — 確認すべきシステムのリストを提供
- 裁判所への対応（第39条に基づく開示命令）は対象外 — `litigation-legal-jp` を使用

## 免責事項

本スキルはAPPI第33条-第35条に基づく開示等請求への対応をガイドするものであり、個人情報保護委員会の公式見解や裁判所の判断を代替するものではありません。不開示事由の適用や利用停止等の判断は、弁護士の確認を得てから行ってください。
