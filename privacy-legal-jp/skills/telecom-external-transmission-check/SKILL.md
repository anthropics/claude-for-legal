# 外部送信規律チェック（電気通信事業法第27条の12）

## 案件コンテキスト

**案件コンテキスト。** プラクティスレベルCLAUDE.mdの `## 案件ワークスペース` を確認。`有効` が `✗` の場合スキップ。

---

## 目的

2023年6月施行の電気通信事業法改正により導入された外部送信規律（第27条の12）への対応を評価する。ウェブサイトやアプリから利用者の端末に記録された情報を外部に送信する場合（Cookie、JavaScript、SDK等）、通知・公表・同意・オプトアウトのいずれかの措置が必要となる。

## ステップ1: 電気通信事業者該当性の判定

### 電気通信事業法の適用範囲

外部送信規律は「電気通信事業者」及び「第三号事業を営む者」に適用される。

| 事業者類型 | 該当性 | 外部送信規律の適用 |
|---|---|---|
| **電気通信事業の届出・登録事業者** | 明確に該当 | 適用あり |
| **第三号事業を営む者**（他人の通信を媒介するもの以外） | 該当の可能性 | 適用あり |
| **一般的なウェブサイト運営者** | 要判断 | 検索サービス、SNS、ニュース配信等は該当しうる |
| **アプリ提供者** | 要判断 | 通信機能を有する場合は該当しうる |

### 「第三号事業」の典型例

総務省のFAQ及びガイドラインに基づき、以下は外部送信規律の対象：
- 検索サービス
- SNS・コミュニケーションサービス
- ニュース配信・キュレーションサービス
- オンラインショッピングモール
- 動画配信サービス
- 地図サービス
- メールサービス

> ⚠️ 電気通信事業者に該当しない場合でも、個人関連情報規制（APPI第31条）は別途適用される可能性がある。`/privacy-legal-jp:kojin-kanren-joho-check` を参照。

## ステップ2: 外部送信の識別

### 外部送信に該当するもの

利用者の端末に記録された情報を外部に送信させる指令（タグ、Cookie、JavaScript、SDK等）：

| 技術手段 | 典型的な外部送信先 | 送信される情報 |
|---|---|---|
| **Googleアナリティクス（GA4）** | Google | ページURL、閲覧時間、デバイス情報、IPアドレス |
| **Google広告タグ** | Google | Cookie ID、コンバージョン情報 |
| **Meta Pixel** | Meta | Cookie ID、閲覧ページ、イベント |
| **LINE Tag** | LINE | Cookie ID、コンバージョン情報 |
| **各種広告SDK** | 広告事業者 | 広告ID、デバイス情報、利用状況 |
| **アクセス解析ツール** | 解析事業者 | 閲覧情報、デバイス情報 |
| **A/Bテストツール** | テスト事業者 | 利用者の行動データ |
| **チャットボット** | チャット事業者 | 入力テキスト、閲覧ページ |
| **ヒートマップツール** | 解析事業者 | マウス操作、スクロール、クリック |
| **CDN** | CDN事業者 | 要個別判断（情報の送信の有無） |

### 外部送信に該当しないもの

- 利用者が積極的に送信する情報（フォーム入力等）
- 利用者の端末に記録された情報ではないもの（サーバサイドの処理）
- 自社サーバへの送信（外部ではない）

## ステップ3: 対応措置の選択

外部送信規律では、以下の4つの措置のいずれかを講じる必要がある：

### 措置A: 通知又は公表（第27条の12第1項第1号）

最も一般的な対応方法。以下の事項を利用者が容易に知り得る状態に置く：

| 公表事項 | 内容 |
|---|---|
| 送信される情報の内容 | Cookie ID、閲覧履歴、デバイス情報等 |
| 送信先の名称又は氏名 | Google LLC、Meta Platforms, Inc.等 |
| 送信先における利用目的 | アクセス解析、広告配信、広告効果測定等 |

**公表方法の要件:**
- プライバシーポリシーとは別に、外部送信に関する一覧表を作成することが推奨
- 利用者が容易に到達できる場所（ウェブサイトのフッター等）にリンクを配置
- 個々の外部送信について上記3項目を明記

### 措置B: 同意の取得（第27条の12第1項第2号）

CMP（同意管理プラットフォーム）等を使用して事前の同意を取得する方法。

### 措置C: オプトアウト（第27条の12第1項第3号）

利用者が外部送信を停止できる手段を提供する方法。ブラウザの設定による無効化だけでは不十分であり、個別のオプトアウト手段の提供が必要。

### 措置D: 一定の要件に該当する場合の適用除外

以下は外部送信規律の適用除外：
- サービスの提供に必要不可欠な情報の送信（セッション管理Cookie等）
- セキュリティ上の目的

## ステップ4: 通知・公表文書のチェック

既存の公表文書がある場合、以下をチェック：

| # | チェック項目 | 重大度 | 結果 |
|---|---|---|---|
| 4.1 | すべての外部送信が網羅されているか | 🔴 | |
| 4.2 | 送信先の名称が正確か | 🟠 | |
| 4.3 | 送信される情報の内容が具体的か | 🟠 | |
| 4.4 | 送信先における利用目的が明記されているか | 🔴 | |
| 4.5 | 利用者が容易に到達できる場所に配置されているか | 🟠 | |
| 4.6 | 新たに追加されたタグ・SDKが反映されているか | 🟠 | |
| 4.7 | オプトアウト手段へのリンクがあるか | 🟡 | |

## ステップ5: APPI個人関連情報規制との交差確認

外部送信で送信される情報が個人関連情報に該当し、送信先で個人データとして取得されることが想定される場合、APPI第31条の確認義務も別途必要。

→ 該当する場合は `/privacy-legal-jp:kojin-kanren-joho-check` に引き渡し

> ⚖️ **弁護士確認ゲート:** 電気通信事業者該当性の最終判断は法的判断を含みます。該当性に疑義がある場合は、弁護士に相談してください。

## このスキルが行わないこと

- ウェブサイトの実際のタグ・Cookie・SDKのスキャンは行わない — 技術ツールの役割
- CMP（同意管理プラットフォーム）の設定・実装は行わない
- 電気通信事業の届出・登録手続きは対象外
- ePrivacy規則（EU）やCCPA Cookie規制は対象外
- ウェブサイトの技術的な改修は行わない

## 免責事項

本チェックは電気通信事業法の外部送信規律（第27条の12）への対応を評価する支援であり、総務省の公式な判断を代替するものではありません。電気通信事業者該当性の判断は事業の実態に基づく法的判断が必要であり、疑義がある場合は弁護士及び総務省に相談してください。
