# PPC報告書ドラフト作成

## 案件コンテキスト

**案件コンテキスト。** プラクティスレベルCLAUDE.mdの `## 案件ワークスペース` を確認。`有効` が `✗` の場合スキップ。

---

## 目的

個人情報保護委員会（PPC）への報告書のドラフトを作成する。特に漏えい等報告（速報・確報）は期限が法定されており、迅速な対応が求められる。本スキルは報告書のフォーマットと必要記載事項を提供し、漏えい対応の法的側面を支援する。

## 報告種類の判定

### 漏えい等報告（施行規則第7条-第8条）

以下の4類型のいずれかに該当する場合、PPCへの報告と本人への通知が義務：

| 類型 | 報告義務 | 確報期限 |
|---|---|---|
| 1. **要配慮個人情報の漏えい等** | あり（1件でも） | 30日以内 |
| 2. **財産的被害のおそれがある漏えい等** | あり | 30日以内 |
| 3. **不正アクセスによる漏えい等** | あり | 60日以内 |
| 4. **1,000人超の漏えい等** | あり | 30日以内 |

### 報告のタイムライン

```
漏えい等の発覚
  ↓
速報: 速やかに（概ね3-5日以内が目安・暦日）
  ↓
確報: 原則30日以内（不正アクセスの場合は60日以内）
  ↓ （並行して）
本人通知: 速やかに（本人の権利利益保護に必要な範囲で）
```

### その他の報告・届出

- 匿名加工情報の作成に関する公表・届出（第43条第3項）
- オプトアウト届出（第27条第2項）

## 速報ドラフト（概ね3-5日以内）

### 速報の記載事項（施行規則第8条第1項）

PPCの報告フォームに基づき、以下を記載：

```
【個人情報の漏えい等に関する報告（速報）】

■ 報告日: 令和○年○月○日

■ 報告者
  事業者名: [会社名]
  代表者名: [代表者名]
  担当者名: [担当者名]
  連絡先: [電話番号・メールアドレス]

■ 概要
  1. 発覚日時: 令和○年○月○日 ○時○分頃
  2. 事案の概要:
     [何が起きたかの概要 — 現時点で判明している事実]
  3. 漏えい等の態様:
     □ 漏えい  □ 滅失  □ 毀損  □ 漏えい等のおそれ
  4. 報告対象類型:
     □ 要配慮個人情報  □ 財産的被害のおそれ
     □ 不正アクセス    □ 1,000人超
  5. 対象となる個人データの項目:
     [氏名、住所、メールアドレス等]
  6. 対象となる本人の数:
     [判明分○名 / 最大○名のおそれ]

■ 原因
  [現時点で判明している原因 / 調査中]

■ 二次被害の有無・おそれ
  [あり / なし / 調査中]

■ 本人への対応
  [通知済み / 通知予定 / 未定]

■ 再発防止策
  [実施済みの措置 / 検討中]

■ その他参考となる事項
  [認定個人情報保護団体への報告状況等]

※ 速報のため、上記は現時点で把握している情報に基づきます。
  確報において追加・訂正する場合があります。
```

### 速報時の注意事項

- 速報の段階で全事実が判明していなくてよい。「調査中」は適法な記載
- 過小報告よりも過大報告の方がリスクが低い
- 「おそれ」段階でも報告義務がある
- 認定個人情報保護団体に加入している場合、当該団体を経由して報告

## 確報ドラフト（30日/60日以内）

### 確報で追加・確定する事項

速報の記載事項に加え、以下を確定：

```
【個人情報の漏えい等に関する報告（確報）】

■ 報告日: 令和○年○月○日
■ 速報提出日: 令和○年○月○日

[速報の記載事項を更新のうえ記載]

■ 追加確定事項

  7. 対象本人の確定数: [確定数]名
  8. 原因の詳細:
     [根本原因の分析結果]
  9. 時系列:
     - [日時]: [事象]
     - [日時]: [事象]
     ...
  10. 二次被害の状況:
     [確認結果]
  11. 本人への通知状況:
     通知日: 令和○年○月○日
     通知方法: [書面/メール/ウェブ公表]
     通知内容: [概要]
  12. 再発防止策（実施済み・計画中）:
     - [実施済み]: [措置内容]
     - [計画中]: [措置内容、実施予定日]
  13. 外部への公表:
     [公表済み/公表予定/公表しない（理由）]
```

## 弁護士確認ゲート

**漏えい等報告は利用者の役割にかかわらず弁護士確認を強く推奨する。**

> ⚖️ **弁護士確認ゲート（全利用者共通）:** 漏えい等報告はPPCの行政処分（勧告・命令）に直結する可能性があり、報告内容は法的な証拠となりえます。本ドラフトは初稿であり、以下の確認を経てから提出してください：
> - 弁護士による法的レビュー
> - 報告対象類型の該当性判断の確認
> - 記載内容の事実関係の検証
> - 広報・IR部門との公表方針の調整（上場企業の場合）

## 意思決定ツリー

> **次のステップは？選んでください：**
> 1. **速報を完成して提出準備** — ドラフトを最終化し、PPC報告フォームへの入力を支援
> 2. **確報のスケジュール管理** — 確報期限のカウントダウンと必要調査事項の整理
> 3. **本人通知の作成** — 本人宛通知書のドラフトを作成
> 4. **エスカレーション** — [エスカレーション先]宛のインシデント報告メモを作成
> 5. **再発防止策の検討** — 技術的・組織的再発防止策のフレームワークを提示
> 6. **その他**

## このスキルが行わないこと

- PPCへの報告を自動的に提出しない — ドラフト作成のみ
- フォレンジック調査は行わない — セキュリティ専門家の役割
- 上場企業の適時開示（TDnet）の判断は行わない — IR部門・弁護士の判断
- 損害賠償額の算定は行わない
- マスコミ対応のアドバイスは行わない — 危機管理広報の専門家の役割
- 刑事告訴の検討は行わない — 弁護士の判断

## 免責事項

本スキルはPPCへの報告書のドラフト作成を支援するものであり、報告義務の有無の最終判断や報告内容の正確性を保証するものではありません。漏えい等報告はPPCの行政処分に直結する可能性があるため、必ず弁護士の確認を得てから報告書を提出してください。報告の遅延は法令違反となる可能性があるため、弁護士確認と並行して期限管理を行ってください。
