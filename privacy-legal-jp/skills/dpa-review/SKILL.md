# /dpa-review

1. `~/.claude/plugins/config/claude-for-legal/privacy-legal-jp/CLAUDE.md` → 委託契約プレイブックを読み込む。PLACEHOLDERの場合は停止してセットアップを案内。
2. 委託契約を取得。方向の判定：自社は委託者か受託者か？曖昧な場合は確認。
3. 以下のワークフローを実行 — 条項ごとにプレイブックと照合。
4. プライバシーポリシーとの整合性チェックを実行。
5. 出力：レビューメモとレッドライン。ハウススタイルに従い保存。

```
/privacy-legal-jp:dpa-review 委託契約書.pdf
```

# 委託契約レビュー（APPI第25条）

## 案件コンテキスト

**案件コンテキスト。** プラクティスレベルCLAUDE.mdの `## 案件ワークスペース` を確認。`有効` が `✗` の場合（企業内法務のデフォルト）、この段落の残りをスキップ。有効で、アクティブ案件がない場合は確認：「どの案件ですか？ `/privacy-legal-jp:matter-workspace switch <slug>` を実行するか、`プラクティスレベル` と言ってください。」

---

## 目的

個人データの取扱いの委託（APPI第25条）に伴う契約をレビューする。委託者として受託者に課す義務と、受託者として委託者から受ける制約では、レビューの視点がほぼ逆転する。

## 方向の判定

最初に確認：

- **自社が委託者** → 受託者に処理を委託 → `委託契約プレイブック` → 「委託者」テーブルを読む
- **自社が受託者** → 委託者から処理を受託 → `委託契約プレイブック` → 「受託者」テーブルを読む

不明な場合は確認する。これを間違えるとすべての推奨が逆転する。

## 先行コンテキストの読み込み

レビュー前に、出力フォルダで同じ相手方・処理活動に関する過去の成果物を確認：

- **過去の `use-case-triage` 結果** — リスク評価と条件をフロアとして使用
- **過去の `pia-generation` 出力** — PIAで特定されたリスク軽減策をDPAが実装しているか確認
- **過去の `dpa-review` 出力** — 過去のレビューとの整合性を確認

## 条項別レビュー

### 必須チェック項目（すべての委託契約）

以下の各条項について、契約書の記載をプレイブックと照合する。

#### 1. 委託の範囲（APPI第25条）

- 委託する個人データの範囲が明確に特定されているか
- 利用目的の範囲内での取扱いに限定されているか
- 取り扱う個人データの種類（要配慮個人情報を含むか）が明記されているか

#### 2. 安全管理措置（APPI第23条準用）

4区分の安全管理措置が具体的に規定されているか：

| 区分 | チェックポイント | 重大度 |
|---|---|---|
| 組織的安全管理措置 | 責任者の選任、規程整備、取扱状況の記録、事故対応体制 | 🔴 欠如は対応必須 |
| 人的安全管理措置 | 従業者への教育・研修、秘密保持義務 | 🟠 重要 |
| 物理的安全管理措置 | 取扱区域の管理、機器・媒体の持出し管理、廃棄 | 🟠 重要 |
| 技術的安全管理措置 | アクセス制御、不正アクセス防止、通信の暗号化 | 🔴 欠如は対応必須 |

#### 3. 再委託の制限

- 再委託の禁止 / 事前承諾制 / 事前通知制のいずれか
- 再委託先に対する安全管理措置の義務付け
- 再委託先の管理責任の所在

#### 4. 漏えい等発生時の報告

- 報告期限（速報・確報）
- 報告内容の範囲
- PPC報告と本人通知への協力義務
- 報告対象4類型への対応

#### 5. 取扱状況の把握

- 定期報告の義務
- 監査権（実地調査権）の有無と範囲
- 是正措置の要求権

#### 6. 契約終了時のデータ返還・消去

- 返還方法と期限
- 消去の方法と証明（消去証明書の発行）
- 残存データの取扱い

#### 7. 従業者の監督

- 秘密保持契約の締結義務
- アクセス権限の最小化
- 退職時の措置

#### 8. 越境移転（APPI第28条）

委託先が外国にある場合、または委託先が外国の再委託先を使用する場合：

- 移転先の国・地域の特定
- 移転根拠の確認（PPC認定国 / 基準適合体制 / 本人同意）
- 2022年改正の詳細情報提供要件への対応
- → 詳細は `/privacy-legal-jp:cross-border-transfer-assessment` に引き渡し可能

#### 9. 損害賠償

- 責任範囲と上限
- 故意・重過失の場合の上限撤廃
- 間接損害・特別損害の取扱い（民法第416条第2項）

### 特別チェック項目

#### マイナンバー（特定個人情報）を含む場合

- 特定個人情報の取扱い範囲の限定
- 番号法第12条に基づく安全管理措置（より厳格な基準）
- 特定個人情報の再委託に関する委託者への通知義務
- 特定個人情報ファイルの管理

#### 要配慮個人情報を含む場合

- 取得に際しての本人同意の取得方法
- 漏えい等の場合のPPC報告義務（1件でも報告対象）
- より厳格な安全管理措置

## プライバシーポリシーとの整合性チェック

プラクティスプロファイルの `## プライバシーポリシー等の公表事項` と照合：

- 委託契約で許可される利用目的がポリシーの利用目的の範囲内か
- ポリシーに記載された安全管理措置と委託契約の安全管理措置に矛盾がないか
- 第三者提供に関する記載の整合性

## 弁護士確認ゲート

利用者が「法務部員等」または「その他」の場合、以下のメッセージを結論の前に表示：

> ⚖️ **弁護士確認ゲート:** この委託契約の最終判断（承認/拒否/条件変更）は弁護士が行う必要があります。本レビューは分析材料であり、最終的な法的判断ではありません。顧問弁護士に相談してください。

## このスキルが行わないこと

- 委託契約を自動的に承認または締結しない — レビューと推奨のみ
- GDPR/CCPA等の外国法に基づくDPAレビューは行わない — `privacy-legal` プラグインを使用
- 業務委託契約全体のレビューは行わない — 個人データ取扱いに関する条項に焦点
- 委託先の実際の安全管理措置の監査は行わない — 契約条項のレビューのみ
- NDAのレビューは行わない — `/commercial-legal-jp:nda-review` を使用

## 免責事項

本レビューはAPPI第25条（委託先の監督）の観点からの契約条項の分析であり、委託先の実際の安全管理措置の監査や、個人情報保護委員会の公式見解を代替するものではありません。最終的な契約判断は弁護士の確認を得てから行ってください。
