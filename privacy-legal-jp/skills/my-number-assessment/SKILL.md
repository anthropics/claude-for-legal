# マイナンバー法コンプライアンス評価

## 案件コンテキスト

**案件コンテキスト。** プラクティスレベルCLAUDE.mdの `## 案件ワークスペース` を確認。`有効` が `✗` の場合スキップ。

---

## 目的

番号利用法（マイナンバー法）に基づく特定個人情報の取扱いについて、民間事業者としてのコンプライアンス状況を評価する。マイナンバー法はAPPIの特別法として位置づけられ、APPIよりも厳格な規制が課される。

## 前提確認

### マイナンバー法の適用範囲

民間事業者がマイナンバーを取り扱う主な場面：
- **源泉徴収票の作成**（所得税法）
- **社会保険の届出**（健康保険法、厚生年金保険法、雇用保険法等）
- **支払調書の作成**（報酬・料金等の支払先のマイナンバー取得）
- **特定口座の開設**（金融機関の場合）

### 特定個人情報保護評価の適用

特定個人情報保護評価（PIA）は**行政機関等**の義務であり、**民間事業者には直接適用されない**。ただし、PPC「特定個人情報の適正な取扱いに関するガイドライン（事業者編）」に基づく安全管理措置は義務である。

## チェック項目

### カテゴリ1: 取得・利用目的（番号法第9条・第29条）

| # | チェック項目 | 重大度 |
|---|---|---|
| 1.1 | マイナンバーの利用目的が法定の範囲（税、社会保障、災害対策）に限定されているか | 🔴 |
| 1.2 | 利用目的を本人に通知又は公表しているか | 🔴 |
| 1.3 | マイナンバーの収集にあたり本人確認（番号確認＋身元確認）を行っているか | 🔴 |
| 1.4 | 本人確認の方法は番号法施行規則に準拠しているか | 🟠 |
| 1.5 | 法定の利用目的以外の利用がないか（目的外利用の禁止は例外なし） | 🔴 |

### カテゴリ2: 安全管理措置（番号法第12条、PPC事業者編ガイドライン）

APPIよりも厳格な安全管理措置が求められる。

| # | チェック項目 | 重大度 |
|---|---|---|
| 2.1 | **基本方針の策定:** 特定個人情報の取扱いに関する基本方針を策定しているか | 🟠 |
| 2.2 | **取扱規程等の策定:** 取得、利用、保存、提供、削除・廃棄の段階ごとに取扱方法等を定めた規程を策定しているか | 🔴 |
| 2.3 | **組織的安全管理措置:** 事務取扱担当者の明確化、責任者の設置、取扱規程に基づく運用、取扱状況の記録・点検、情報漏えい等事案への対応体制 | 🔴 |
| 2.4 | **人的安全管理措置:** 事務取扱担当者への教育・監督、秘密保持義務の周知 | 🟠 |
| 2.5 | **物理的安全管理措置:** 特定個人情報の取扱区域の管理、機器・媒体の持出し管理、個人番号の削除・機器の廃棄 | 🔴 |
| 2.6 | **技術的安全管理措置:** アクセス制御（事務取扱担当者に限定）、アクセス者の識別と認証、外部からの不正アクセス防止、情報漏えい防止 | 🔴 |

**中小規模事業者の特例:**
従業員100人以下の事業者は、一部の安全管理措置について軽減措置が認められる。プラクティスプロファイルの従業員数に基づき、適用される基準を判定する。

### カテゴリ3: 提供の制限（番号法第19条）

| # | チェック項目 | 重大度 |
|---|---|---|
| 3.1 | 特定個人情報の提供が番号法第19条各号の限定列挙に該当するか | 🔴 |
| 3.2 | 提供先が正当な権限を有しているか確認しているか | 🔴 |
| 3.3 | 従業者の退職時等にマイナンバーの提供先を限定しているか | 🟠 |

### カテゴリ4: 収集・保管の制限（番号法第20条）

| # | チェック項目 | 重大度 |
|---|---|---|
| 4.1 | 番号法第19条各号に該当する場合を除き、特定個人情報を収集・保管していないか | 🔴 |
| 4.2 | 法定の保存期間経過後、速やかにマイナンバーを廃棄・削除しているか | 🔴 |
| 4.3 | 廃棄・削除の記録を保存しているか | 🟠 |

### カテゴリ5: 委託先の監督

| # | チェック項目 | 重大度 |
|---|---|---|
| 5.1 | 委託先の選定にあたり安全管理措置の状況を確認しているか | 🔴 |
| 5.2 | 委託契約に必要な安全管理措置を義務付けているか | 🔴 |
| 5.3 | 委託先における取扱状況を把握しているか | 🟠 |
| 5.4 | 再委託について委託者の許諾を得ているか（番号法第10条） | 🔴 |

### カテゴリ6: 漏えい等報告

| # | チェック項目 | 重大度 |
|---|---|---|
| 6.1 | 特定個人情報の漏えい等が発生した場合のPPC報告体制があるか | 🔴 |
| 6.2 | 速報（概ね3-5日以内）の対応フローがあるか | 🔴 |
| 6.3 | 確報（30日以内/不正目的60日以内）の対応フローがあるか | 🔴 |
| 6.4 | 本人通知の体制があるか | 🔴 |
| 6.5 | 特定個人情報の漏えいは1件でもPPC報告義務があることを認識しているか | 🔴 |

### カテゴリ7: 特定個人情報ファイル管理

| # | チェック項目 | 重大度 |
|---|---|---|
| 7.1 | 特定個人情報ファイルの作成が番号法第29条に該当する場合に限定されているか | 🔴 |
| 7.2 | 特定個人情報ファイルの一覧を作成・管理しているか | 🟠 |
| 7.3 | 不要になった特定個人情報ファイルを速やかに廃棄しているか | 🟠 |

## 弁護士確認ゲート

利用者が「法務部員等」または「その他」の場合：

> ⚖️ **弁護士確認ゲート:** マイナンバー法違反には刑事罰（4年以下の懲役または200万円以下の罰金等）が科される可能性があります。🔴項目については速やかに弁護士に相談してください。

> 5. **エスカレーション** — [エスカレーション先]宛の報告メモを作成
> 6. **その他**

## このスキルが行わないこと

- 行政機関等の特定個人情報保護評価（PIA）は行わない — 民間事業者向けの評価のみ
- マイナンバーカードの技術的なセキュリティ評価は行わない
- 税務申告や社会保険手続きの実務ガイダンスは行わない — 税理士・社会保険労務士の業務
- 住民基本台帳法に基づく住民票関連の手続きは対象外
- 個人番号通知カードの管理に関するガイダンスは行わない

## 免責事項

本評価はマイナンバー法（番号利用法）に基づく特定個人情報の取扱いに関するコンプライアンス評価の支援であり、個人情報保護委員会の公式な監査や評価を代替するものではありません。マイナンバー法違反には刑事罰が科される可能性があるため、🔴項目については速やかに弁護士に相談してください。
