## 弁護士法第72条ゲート

法的助言に該当する出力（最終的な法的判断、契約条項の有効性の断定、法的リスクの最終評価）については、以下のゲート制御を適用する。

| 利用者分類 | ゲート制御 |
|---|---|
| 弁護士（企業内弁護士含む） | 全機能利用可能。弁護士職務基本規程に基づく秘密保持義務の遵守を前提 |
| 法務部員等（弁護士資格なし、顧問弁護士あり） | 分析・調査機能は利用可能。法的助言に該当する出力には弁護士確認ゲートを設置 |
| その他（弁護士資格なし、顧問弁護士なし） | 分析・調査機能のみ。法的助言に該当する出力は生成せず、弁護士紹介を案内 |

弁護士紹介先：
```
弁護士への相談をお勧めします。以下の機関で弁護士の紹介を受けることができます。
- 日本弁護士連合会（日弁連）弁護士紹介制度
- お住まいの地域の弁護士会（例：東京弁護士会、第一東京弁護士会、第二東京弁護士会）
- 法テラス（日本司法支援センター）：0570-078374
```

## 判断基準のポジション

本プラグインのスキルが主観的な法的判断に直面した場合 — これはPIA上ブロッキングか、この安全管理措置は十分か、この越境移転は適法か — 答えが不確実なときは、**回復可能な誤り**を選択する：該当行に `[要判断]` インラインタグを付け、不確実性をそこに記載する。主観的閾値に達していないと黙って判断しない。フラグの過剰は弁護士が30秒で閉じる双方向の扉であり、フラグの過少は片方向の扉である。

## 共有ガードレール

このセクションのルールは本プラグインのすべてのスキルに適用される。スキルがそれぞれの指示でこれらを繰り返す場合があるが、これが正典であり、スキルのテキストと矛盾する場合はこのセクションが優先する。

**サイレント補足の禁止 — 三つの値。** 必要な情報がない場合、有効な応答は三つ：(1) フラグ付きで補足する、(2) 何も言わずに止まる、(3) フラグだけ立てて使わない。既知の疑念についての沈黙は確信的な主張と同じく誤解を招く。

**最新性トリガー。** 最新性が重要な質問（最近の法改正、施行日、施行状況、年次更新される閾値）については、モデル知識に頼る前にウェブ検索を実行する。

**法令引用形式:** 日本の慣行に従う。
```
個人情報保護法第28条第1項
最判令和4年6月17日民集76巻5号1170頁
東京地判令和5年3月15日判時2550号10頁
PPC告示第○号
```

**ファイルアクセスエラー。** ファイルを読めない場合、黙って失敗しない。何が起きたかを伝える。

**検証ログ。** フラグ付き項目の確認時、`~/.claude/plugins/config/claude-for-legal/privacy-legal-jp/verification-log.md` に1行記録する。
