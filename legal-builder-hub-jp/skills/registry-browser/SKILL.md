# /registry-browser

1. `~/.claude/plugins/config/claude-for-legal/legal-builder-hub-jp/CLAUDE.md` → 監視レジストリを読み込む。
2. 以下のワークフローに従う。
3. 各レジストリを検索する。マッチしたスキルを説明付きで表示する。
4. 任意のマッチに対して完全な SKILL.md の表示を提供する。

---

## 目的

監視レジストリ全体からスキルを探す。検索、プレビュー、判断。

## 読み込むコンテキスト

- `~/.claude/plugins/config/claude-for-legal/legal-builder-hub-jp/CLAUDE.md` → 監視レジストリ一覧、インストール済みスキル一覧、ユーザー分類
- `~/.claude/plugins/config/claude-for-legal/company-profile.md` → 組織情報

## ワークフロー

### ステップ 1: レジストリインデックスの取得

各監視レジストリについて：

- GitHub リポジトリ：`skills/` ディレクトリ一覧と各 `SKILL.md` フロントマター（name + description）を取得
- マーケットプレイス型レジストリ：インデックスを取得

キャッシュをローカルに保存（`references/registry-cache.json`）し、ブラウジングを高速化する。キャッシュが 7 日以上経過している場合、またはリクエストに応じて更新する。

### ステップ 2: 検索とフィルタリング

クエリをスキル名と説明に対してマッチングする。キーワードマッチで十分 — 小規模なインデックスにファジー検索は過剰。

**日本法カテゴリフィルタ:** 以下のカテゴリでフィルタリング可能：

| カテゴリ | 説明 | 関連法令例 |
|---|---|---|
| 商事 | 商取引、契約、M&A | 会社法、商法、金融商品取引法 |
| 労働 | 雇用、労働条件、ハラスメント | 労働基準法、労働契約法、男女雇用機会均等法 |
| 会社 | 会社設立、機関設計、株主総会 | 会社法、商業登記法 |
| 個人情報保護 | プライバシー、データ保護 | 個人情報保護法、マイナンバー法 |
| 訴訟 | 民事訴訟、仲裁、ADR | 民事訴訟法、仲裁法 |
| 知財 | 特許、商標、著作権 | 特許法、商標法、著作権法、不正競争防止法 |
| 不動産 | 売買、賃貸、登記 | 民法、借地借家法、宅建業法 |
| 規制 | 業界規制、行政法 | 各業法、独占禁止法、下請法 |
| AI・テクノロジー | AI 規制、データガバナンス | 個人情報保護法、著作権法（AI 関連改正） |
| 一般 | カテゴリ横断、汎用 | — |

ユーザーがカテゴリを指定した場合、そのカテゴリに関連するスキルを優先表示する。
カテゴリ指定なしの場合はキーワードマッチのみ。

### ステップ 3: 結果の表示

```markdown
## 検索結果: "[クエリ]"

**[N] 件のスキルが [M] レジストリから見つかりました:**

### [スキル名]
**ソース:** [レジストリ名]
**説明:** [フロントマターから]
**カテゴリ:** [該当するカテゴリ]
**日本法対応:** [対応済み ✅ / 未対応 ⚠️ / 不明 ❓]
**弁護士法72条ゲート:** [実装済み ✅ / 未実装 ⚠️ / N/A]
**日本語:** [対応 ✅ / 未対応]
[SKILL.md を表示] [インストール]

### [スキル名]
[...]
```

**非弁護士ユーザーの場合の追加表示:**
プラクティスプロファイルのユーザー分類が「非弁護士」の場合、弁護士法第72条
ガードレール未実装のスキルには目立つ警告マークを付与する：

> ⚠️ このスキルには弁護士法第72条ガードレールが実装されていません。
> 非弁護士ユーザーが使用する場合、法律事務に該当する出力がブロックされない
> 可能性があります。インストール前に弁護士に相談してください。

**インストール済みスキルの除外:** 既にインストール済みのスキルは結果に表示するが
`[インストール済み]` と明記し、重複インストールを防ぐ。

### ステップ 4: プレビュー

「SKILL.md を表示」選択時：完全なファイルを取得・表示する。ユーザーがインストールを
決定する前に内容を確認できる。

### ステップ 5: レジストリの追加

ユーザーが監視リストにないレジストリの URL を持っている場合：

1. 取得し、スキルリポジトリであることを検証する（`skills/` または `.claude-plugin/` の存在）
2. 含まれるスキルを表示する
3. 確認を得てから `~/.claude/plugins/config/claude-for-legal/legal-builder-hub-jp/CLAUDE.md` の監視レジストリに追加する

## デフォルトレジストリ

- **lpm-skills** — 14 のリーガルプロジェクト管理スキル。実務分野を問わない。出発点として適切。
- エコシステムの成長に応じて追加される。

## 本スキルが行わないこと

- インストールする。本スキルはブラウジングのみ。`/legal-builder-hub-jp:skill-installer` がインストールを行う。
- スキルの評価やレビューを行う。SKILL.md を表示し、ユーザーが判断する。品質評価は `/legal-builder-hub-jp:skills-qa` で行う。
- インターネット全体を検索する。監視レジストリのみ。
- 法的正確性を検証する。日本法対応状況の表示はヒューリスティックな判断であり、実体的検証ではない。
