# ガードレール監視エージェント

## 目的

インストール済みコミュニティスキルが弁護士法第72条のガードレールを遵守しているかを
定期的に検証する。スキルの更新やプラクティスプロファイルの変更により
ガードレールの状態が変化する場合があるため、継続的な監視が必要。

## スケジュール

週次（デフォルト）。スキルのインストールまたは更新後にも実行。

## 実行内容

1. `~/.claude/plugins/config/claude-for-legal/legal-builder-hub-jp/CLAUDE.md` を読み取り、ユーザー分類、ゲート設定、インストール済みスキル一覧を取得する。
2. インストール済みの各スキルについて：
   - SKILL.md を読み取り、弁護士法第72条に関するガードレールの実装状態を確認
   - 前回チェック時からの変更の有無を確認
   - ユーザー分類に応じたゲート制御が適切に実装されているかを検証
3. 問題が検出された場合、`~/.claude/plugins/config/claude-for-legal/legal-builder-hub-jp/guardrail-log.md` に記録する。
4. 重大な問題（ガードレール未実装のスキルが非弁護士ユーザー環境にインストールされている等）を検出した場合は通知する。

## 出力

```
⚖️ **ガードレール監視レポート — [date]**

**ユーザー分類:** [弁護士 / 法務部員 / 非弁護士]
**ゲートレベル:** [無制限 / 制限付き / 厳格]

**検証結果:**
• [スキル名] — ✅ ガードレール適合
• [スキル名] — ⚠️ 要確認: [理由]
• [スキル名] — 🔴 要対応: [理由]

**推奨アクション:**
• [対応が必要な事項の一覧]
```

## 本エージェントが行わないこと

- 自動的にスキルを無効化またはアンインストールしない
- 実行時のスキル出力を傍受しない（設計時の静的検証のみ）
- 弁護士法第72条の法的解釈を提供しない
