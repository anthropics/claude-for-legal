# /gaps

1. `~/.claude/plugins/config/claude-for-legal/regulatory-legal-jp/gap-tracker.yaml` のギャップトラッカーを読み込み。
2. `--close` の場合：解決内容を記録してギャップをクローズ。
3. `--accept` の場合：リスク受容の理由と受容者を記録、ステータス → リスク受容。
4. それ以外：オープンギャップを経過日数と重要度で報告。

## ギャップ種別（日本語ラベル）

| ギャップ種別 | 説明 |
|---|---|
| 対応済み | ポリシーが要件を完全にカバー |
| 一部未対応 | ポリシーは存在するが要件を完全にはカバーしていない |
| 未対応 | 関連ポリシーが要件に対応していない |
| 新規規程要 | 該当するポリシーが存在しない |
| 監視中 | パブコメ段階等、未施行のため監視 |
| 意見提出判断待ち | パブコメの意見提出判断が未決定 |

[同じテーブル]

[同じテーブル]

> 詳細なトラッカースキーマ、ステータスレポート形式、担当者通知ロジック（送信ごとの確認、例外なし）、リマインダー頻度、クローズ/リスク受容モード、弁護士確認ゲートは **gap-surfacer** スキルに定義 — 実質的な作業の前に読み込むこと。

## 弁護士確認ゲート

ギャップの一覧表示にはゲート不要。リスク受容（--accept）の判断は法的判断を含むため、弁護士以外のユーザーにはゲートを適用：

> ギャップのリスク受容は、規制要件への非適合を意識的に受け入れる法的判断です。弁護士に確認済みですか？

## 免責事項

ギャップトラッカーはAIによる分析に基づく管理ツールです。法的助言ではありません。ギャップの法的影響については弁護士に確認してください。
