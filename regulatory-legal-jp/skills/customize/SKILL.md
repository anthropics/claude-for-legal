# /customize

## 実行条件

ユーザーが `/regulatory-legal-jp:customize` を入力。規制法務プロファイルの何かを変更したいが、コールドスタートインタビュー全体を再実行したくない場合。

## 手順

1. **設定を読む。** `~/.claude/plugins/config/claude-for-legal/regulatory-legal-jp/CLAUDE.md`（および `~/.claude/plugins/config/claude-for-legal/company-profile.md`）を読み込み。設定が存在しないか `[PLACEHOLDER]` が残っている場合：

   > セットアップがまだ完了していません。先に `/regulatory-legal-jp:cold-start-interview` を実行してください — カスタマイズは既存のプロファイルを調整するためのものです。

2. **カスタマイズ可能項目を表示。** プロファイルの内容をグループ化して1行サマリーで表示：

   - **会社 / 組織情報** — 会社名、業種、管轄、規模 *(全プラグイン共通 — company-profile.md を変更すると全体に反映)*
   - **監視対象の規制当局** — 監視中の省庁・規制当局のリスト
   - **適用業法** — 事業活動に適用される業法のマッピング
   - **ポリシーライブラリ** — インデックス済みの社内規程、パス、担当者
   - **重要度閾値** — 規制変更がどのレベルで対応必要か
   - **ギャップ対応プロセス** — トリアージ担当、SLA、エスカレーション先
   - **フィード設定** — 省庁RSS、e-Gov、官報、チェック頻度、ダイジェスト配信先
   - **審議会モニタリング** — 監視対象の審議会リスト
   - **連携ツール** — e-Gov / 官報RSS / Slack / 文書管理の接続状態

3. **何を変更するか確認。**

   > 何を調整しますか？セクションを選ぶか、変更したい内容を説明してください。

4. **変更を実施。** 現在の値を表示 → 新しい値を確認 → 下流への影響を説明 → 確認 → 設定に書き込み。

   例：
   - *監視対象に省庁を追加:* 「`/regulatory-legal-jp:reg-feed-watcher` が次回実行時にこの省庁のフィードも取得します。」
   - *重要度閾値の引き上げ:* 「ダイジェストの件数が減ります — 新しい閾値以下のアイテムはダイジェストから外れますが、検索は可能です。」
   - *業法の追加:* 「`/regulatory-legal-jp:gyoho-checker` がこの業法を監視対象に含めます。関連する通達・行政指導も追跡されます。」

5. **共有プロファイルの変更の場合:**

   > この変更は全プラグインに影響します — 管轄権のフットプリントを参照するすべてのプラグインに[新しい値]が反映されます。

6. **完了。**

   > 完了です。次の出力から変更が反映されます。他に調整はありますか？

## ガードレール

- **セクションを削除しない。** 省庁を「削除」したい場合は `[監視のみ]` マークを提案。
- **内部不整合をフラグ。** 監視対象の省庁があるのに管轄にその省庁の所管分野がない場合等。
- **ガードレールの劣化をフラグ。** `[要確認]` タグ、ソース帰属、`[要判断]` フラグは必須 — 削除不可。
- **1回に1つの変更。** インタビュー全体を再実行しない。

## 弁護士確認ゲート

設定変更自体には弁護士確認ゲートは不要です。

## 免責事項

設定変更はプラグインの動作に影響します。重要な監視設定の変更については、法務責任者に確認してください。
