# product-legal-jp — プロダクト法務プラグイン（日本法版）

景品表示法・特定商取引法・薬機法を中心とする日本の消費者保護法制に基づき、プロダクトローンチレビュー、広告表示チェック、景品規制判定、定期購入コンプライアンス、機能リスク評価を行うプロダクト法務プラグインです。

米国版 `product-legal` プラグイン（FTC Act / Lanham Act ベース）の日本法適応版であり、`docs/japan-adaptation-plan.md` セクション3.3に基づいて構築されています。

## 対応する主な法令

- **景品表示法**（不当景品類及び不当表示防止法）
  - 第5条: 不当表示の禁止（優良誤認・有利誤認）
  - 第7条第2項: 不実証広告規制（15日以内の立証責任転換）
  - 第4条: 景品規制（懸賞・総付景品の金額上限）
  - 第7条・第8条: 措置命令・課徴金（売上額3%×3年）
  - 2023年10月1日施行: ステルスマーケティング規制
- **特定商取引法**
  - 第11条: 通信販売の表示義務
  - 第12条の6: 定期購入の最終確認画面要件（2022年改正）
  - 第41条〜第50条: 特定継続的役務提供
- **薬機法**（医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律）
  - 第66条〜第68条: 広告規制
  - 医薬品的効能効果の標ぼう禁止

## セットアップ

```bash
claude plugin install product-legal-jp
```

初回実行時に `/product-legal-jp:cold-start-interview` を実行してリスクキャリブレーションを設定してください。
