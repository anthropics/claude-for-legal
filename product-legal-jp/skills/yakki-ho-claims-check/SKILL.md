# /yakki-ho-claims-check

## 前提条件

1. `~/.claude/plugins/config/claude-for-legal/product-legal-jp/CLAUDE.md` を読み込み。
2. `~/.claude/plugins/config/claude-for-legal/company-profile.md` を読み込み。

## スコープ

医薬品、医療機器等の品質、有効性及び安全性の確保等に関する法律（薬機法）のうち、広告規制に関連する部分:

- **第66条** — 虚偽・誇大広告の禁止
- **第67条** — 特定疾病用医薬品等の広告制限
- **第68条** — 未承認医薬品等の広告禁止

および、健康食品・化粧品・雑品が医薬品的な効能効果を標ぼうすることの禁止。

## 商品カテゴリの判定

まず対象商品のカテゴリを確認:

| カテゴリ | 定義 | 広告の制限 |
|---|---|---|
| **医薬品** | 薬機法第2条第1項に定義。承認・認証が必要 | 承認範囲内の効能効果のみ表示可能 |
| **医薬部外品** | 薬機法第2条第2項。承認が必要 | 承認範囲内の効能効果のみ |
| **化粧品** | 薬機法第2条第3項。届出 | 56の効能効果の範囲内のみ |
| **健康食品** | 法的定義なし。「食品」として扱われる | 医薬品的効能効果の標ぼう禁止 |
| **機能性表示食品** | 食品表示法に基づく届出 | 届出範囲内の機能性表示のみ |
| **特定保健用食品（トクホ）** | 消費者庁の許可 | 許可範囲内の保健の用途表示のみ |
| **医療機器** | 薬機法第2条第4項。承認・認証・届出 | 承認・認証範囲内の効能効果のみ |
| **雑品** | 上記のいずれにも該当しない | 効能効果の表示不可 |

## 医薬品的効能効果の判断基準

厚生労働省通知「医薬品の範囲に関する基準」（昭和46年薬発第476号）に基づき、以下の4要素で判断:

### 1. 成分本質（原材料）

医薬品専用の成分を含む場合、食品として販売不可。

### 2. 効能効果の標ぼう

以下の表現は医薬品的効能効果の標ぼうに該当:

| NG表現（例） | 理由 | OK表現（代替案） |
|---|---|---|
| 「血圧を下げる」 | 身体の構造・機能への具体的効果 | 「健康的な毎日をサポート」 |
| 「がんを予防する」 | 疾病の予防 | 使用不可 |
| 「アトピーが改善する」 | 疾病の治療 | 使用不可 |
| 「肝機能を高める」 | 特定の器官への効果 | 「毎日の健康習慣に」 |
| 「免疫力を上げる」 | 身体の機能の増強 | 「体調管理をサポート」 |
| 「シミを消す」（化粧品で） | 化粧品の効能効果56項目の範囲外 | 「メラニンの生成を抑え、しみ・そばかすを防ぐ」（医薬部外品の場合） |
| 「老化を防ぐ」 | 身体の変化の防止 | 「年齢に応じたお手入れに」 |

### 3. 用法用量の表示

「1日3回、食後に2粒」等、医薬品的な用法用量の記載は医薬品該当性を高める。

### 4. 形状

アンプル形状等、医薬品の形状と紛らわしいものは医薬品該当性を高める（ただし近年は形状のみでは判断しない方向）。

## 化粧品の効能効果56項目

化粧品で表示可能な効能効果は、平成23年厚生労働省告示第393号に定める56項目に限定。主な項目:

- 頭皮・毛髪を清浄にする / フケ・カユミを抑える
- 肌を整える / 肌のキメを整える / 肌を滑らかにする
- 日やけを防ぐ / 日やけによるシミ・ソバカスを防ぐ
- 乾燥による小ジワを目立たなくする（効能評価試験済みの場合のみ）

56項目外の表現（「シワを消す」「アンチエイジング」「細胞を活性化」等）は不可。

## 健康増進法との接続

健康食品の場合、薬機法に加えて健康増進法第65条（誇大表示の禁止）もチェック:
- 健康の保持増進の効果について著しく事実に相違する表示
- 著しく人を誤認させるような表示

## チェックフロー

```
広告コピー入力
  ↓
1. 商品カテゴリの判定
  ↓
2. 効能効果表現の抽出
  ↓
3. 各表現について:
   ├─ 医薬品的効能効果に該当するか？
   ├─ カテゴリ別の許容範囲内か？
   ├─ 体験談で効能効果を暗示していないか？
   └─ ビフォーアフター写真で効能効果を暗示していないか？
  ↓
4. 判定・修正案の出力
```

## 出力

1. **⚠️ レビューアノート**
2. **ワークプロダクトヘッダー**
3. **商品カテゴリ判定** — 対象商品のカテゴリと適用される規制

### 表現チェック結果

| # | 表現 | 判定 | 該当法令 | 理由 | 修正案 |
|---|---|---|---|---|---|
| 1 | 「血行を促進」 | 🔴 NG | 薬機法第68条 | 医薬品的効能効果 | 「めぐりをサポート」 |
| 2 | 「肌を整える」 | ✅ OK | — | 化粧品56項目内 | — |

4. **体験談・口コミのチェック** — 個人の感想であっても効能効果の暗示に該当する場合

| リスク | 内容 |
