# /keihin-hyouji-check

## 前提条件

1. `~/.claude/plugins/config/claude-for-legal/product-legal-jp/CLAUDE.md` を読み込み。
2. `~/.claude/plugins/config/claude-for-legal/company-profile.md` を読み込み。

## スコープ

景品表示法（不当景品類及び不当表示防止法）の2つの柱をカバー:
- **表示規制** — 不当表示の禁止（第5条）
- **景品規制** — 過大な景品類の提供の禁止（第4条）

`/product-legal-jp:marketing-claims-review` が広告コピーの表示面に特化するのに対し、本スキルはキャンペーン・プロモーションの景品規制面も含む包括チェック。

## Part A: 表示規制チェック

### 1. 優良誤認表示（第5条第1号）

商品・サービスの内容（品質・規格等）に関する不当表示。

| チェック項目 | 確認内容 |
|---|---|
| 最上級・No.1表示 | 客観的調査データの有無、調査方法の適切性 |
| 効果・性能表示 | 合理的根拠の有無（不実証広告規制との接続） |
| 原産国表示 | 実際の原産国と表示の一致 |
| 受賞・認証表示 | 事実との一致、関連性 |
| 写真・イラスト | 実際の商品との乖離 |

### 2. 有利誤認表示（第5条第2号）

取引条件（価格等）に関する不当表示。

| チェック項目 | 確認内容 |
|---|---|
| 二重価格表示 | 比較対照価格の根拠（8週間中4週間以上の販売実績等） |
| 「無料」「0円」表示 | 条件の明瞭な表示 |
| 「期間限定」表示 | 実際の期間限定性 |
| おとり広告 | 実際の供給能力 |
| 割引率・割引額 | 算定根拠の正確性 |

### 3. 不実証広告規制（第7条第2項）

| 項目 | 内容 |
|---|---|
| 対象 | 効果・性能に関する表示 |
| 手続 | 消費者庁から合理的根拠の提出要求 |
| 期限 | **15日以内**（正当な事由がある場合を除く） |
| 立証責任 | 事業者に転換（提出できなければ不当表示とみなす） |

チェック:
- 効果・性能を示す表示の特定
- 各表示に対応する合理的根拠の有無
- 根拠の要件充足（①客観的に実証された内容、②表示された効果・性能と根拠の適合性）
- 15日以内に提出可能な状態か

### 4. 指定告示（第5条第3号）

内閣総理大臣が指定する不当表示:
- **ステルスマーケティング**（2023年10月1日施行） — 事業者の表示であることが不明確な表示
- **無果汁表示** — 果汁・果肉を含まない飲料への果実表示
- **原産国表示** — 一般消費者が原産国を判別困難な表示
- 等

## Part B: 景品規制チェック

### 景品類の定義

景品表示法第2条第3項 + 公正取引委員会告示により、以下が「景品類」に該当:
- 顧客を誘引するための手段として
- 事業者が自己の供給する商品・サービスの取引に付随して提供する
- 物品、金銭その他の経済上の利益

### 懸賞景品

| 種類 | 定義 | 景品上限 |
|---|---|---|
| **一般懸賞**（クローズド懸賞） | 商品購入等を条件とするくじ・抽選 | 取引価額5,000円未満 → 最高額: 取引価額の20倍、総額: 売上予定総額の2% |
| | | 取引価額5,000円以上 → 最高額: 10万円、総額: 売上予定総額の2% |
| **共同懸賞** | 商店街・同業者団体等が共同で実施 | 最高額: 30万円、総額: 売上予定総額の3% |
| **オープン懸賞** | 商品購入等を条件としない | 上限なし（2006年告示廃止により） |

### 総付景品（ベタ付け景品）

商品・サービスの購入者全員に提供される景品。

| 取引価額 | 景品上限 |
|---|---|
| 1,000円未満 | 200円 |
| 1,000円以上 | 取引価額の20%（10分の2） |

### チェックフロー

```
キャンペーン・プロモーション企画
  ↓
景品類に該当するか？
  ├─ YES → 懸賞か総付か？
  │   ├─ 懸賞 → 一般/共同/オープンの区分判定 → 上限チェック
  │   └─ 総付 → 取引価額の確認 → 上限チェック
  └─ NO → 値引き・アフターサービスに該当 → 景品規制の対象外
```

### 値引きとの区別

以下は景品類に該当しない:
- 正常な商慣習に照らして値引きと認められる経済上の利益
- 正常な商慣習に照らしてアフターサービスと認められる経済上の利益

ポイント還元・クーポンは態様によって景品類に該当する場合としない場合がある。個別判断が必要。
