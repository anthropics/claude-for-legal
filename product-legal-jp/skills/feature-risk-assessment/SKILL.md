# /feature-risk-assessment

## 前提条件

1. `~/.claude/plugins/config/claude-for-legal/product-legal-jp/CLAUDE.md` を読み込み。
2. `~/.claude/plugins/config/claude-for-legal/company-profile.md` を読み込み。

## いつ使うか

- `/product-legal-jp:launch-review` で新規またはブロッキングの発見があった場合
- 特定の機能について、ローンチレビューのカテゴリ横断的な深掘りが必要な場合
- 新しい事業領域への進出で規制環境の全体像を把握したい場合

## 入力

- 機能名・サービス名
- 機能の説明（PRD、仕様書、またはテキスト）
- ローンチレビューからの発見事項（ある場合）

## 分析構成

### 1. 評価対象

何を評価するか、スコープの明確化。

### 2. リスク特定（2-5件）

各リスクについて:

| 項目 | 内容 |
|---|---|
| **リスク** | リスクの説明 |
| **根拠法令** | 該当する法令・ガイドライン |
| **シナリオ** | このリスクが顕在化した場合に何が起きるか |
| **蓋然性** | 高 / 中 / 低（根拠を含む） |
| **重大性** | 措置命令+課徴金（売上額3%×3年） / 行政指導 / レピュテーションリスク |
| **緩和策** | 実行可能な対策 |
| **緩和策のギャップ** | 緩和策でカバーできない残余リスク |
| **残余リスク** | 緩和策実施後のリスクレベル |

### 3. 規制環境

該当する場合、規制当局の動向:

| 規制当局 | 最近の動向 | 本機能への影響 |
|---|---|---|
| 消費者庁 | [最新の執行事例・ガイドライン改定] | [影響の評価] |
| 公正取引委員会 | [関連する審決・ガイドライン] | [影響の評価] |
| 個人情報保護委員会 | [関連する告示・ガイドライン] | [影響の評価] |
| 経済産業省 | [関連する法改正・ガイドライン] | [影響の評価] |
| 業所管官庁 | [セクター固有の規制動向] | [影響の評価] |

### 4. 先例・類似事例

同業他社や他業界での類似機能に対する:
- 消費者庁の措置命令事例
- 公正取引委員会の審決事例
- 行政指導事例
- 業界の自主規制対応

### 5. 選択肢テーブル

| 選択肢 | 内容 | リスク低減効果 | コスト・トレードオフ |
|---|---|---|---|
| A. [現状維持 + 緩和策] | | | |
| B. [機能修正] | | | |
| C. [段階的ローンチ] | | | |

### 6. 推奨

会社のリスク許容度に照らした推奨。推奨は1つ、理由を明確に。

## 出力

スタンドアロンの2-4ページの意思決定文書:
1. ⚠️ レビューアノート
2. ワークプロダクトヘッダー
3. エグゼクティブサマリー（3文以内）
4. リスク評価（上記構成）
5. 推奨
6. **チェックリストに含まれない観察** — 「これは問題か？」ではなく「6ヶ月後に誰が困るか？」
7. 次のステップ・デシジョンツリー

## ハンドオフ

- AIコンポーネント → `/ai-governance-legal-jp`
- 個人情報保護 → `/privacy-legal-jp`
- ベンダーAI契約 → `/commercial-legal-jp`
- 景品表示法の詳細 → `/product-legal-jp:keihin-hyouji-check`
- 特商法の詳細 → `/product-legal-jp:tokushoho-compliance`

## 引用チェック

「サイレントサプリメント禁止」ルールに従い、法令・判例の引用にソースタグを付与。リサーチコネクタが接続されていない場合、レビューアノートの **ソース** 行に記載。

⚖️ **弁護士確認ゲート:** この分析は弁護士による確認が必要です。弁護士法第72条により、弁護士でない者が法律事務を取り扱うことは禁止されています。最終的な法的判断は必ず弁護士に確認してください。

📋 **免責事項:** この出力はAIによる分析であり、法的助言を構成するものではありません。景品表示法・特商法・薬機法等の解釈・適用については、必ず弁護士にご確認ください。法令・ガイドラインは頻繁に改正されるため、最新の条文・通達・ガイドラインを確認してください。
