# /customize

## 前提条件

`~/.claude/plugins/config/claude-for-legal/product-legal-jp/CLAUDE.md` を読み込み。ファイルが存在しないまたは `[PLACEHOLDER]` が残っている場合は `/product-legal-jp:cold-start-interview` を案内。

## 動作

フルインタビューなしで、プラクティスプロファイルの特定の値を変更。

## カスタマイズマップ

変更可能な項目を表示:

| カテゴリ | 項目 |
|---|---|
| **会社情報** | 会社名、製品、BtoC/BtoB、規制業種、ステージ、リスク許容度 |
| **ローンチレビュープロセス** | 届く経路、リードタイム、出力形式、サインオフ |
| **レビューフレームワーク** | 8カテゴリの重み付け、セクターオーバーレイ |
| **リスクキャリブレーション** | ブロッカーパターン、対応必要パターン、FYIパターン |
| **広告表示・マーケティング** | レビュー担当、比較広告方針、裏付け基準、問題事例 |
| **人・組織** | 役割、顧問弁護士、エスカレーション先 |
| **ワークフロー** | 稟議制度、承認フロー |
| **インテグレーション** | ローンチトラッカー、ドキュメントストレージ、Slack |

## フロー

1. カスタマイズマップを表示
2. ユーザーが変更したい項目を指定（引数で指定された場合はスキップ）
3. 現在の値を表示
4. 新しい値を受け取る
5. 下流への影響を説明:
   - 「リスク許容度を『積極的』に変更すると、ローンチレビューのブロッカー閾値が上がります」
   - 「規制業種を追加すると、ローンチレビューにセクターオーバーレイが追加されます」
6. 確認後、設定ファイルに書き込み

## ガードレール

- セクションを削除しない — 値を空にするのはOK、セクション構造は維持
- 内部矛盾をフラグ — 「リスク許容度を『保守的』に設定しましたが、ブロッカーパターンが空です。キャリブレーションを追加しますか？」
- ガードレール弱体化をフラグ — 弁護士確認ゲートや免責事項の無効化は明示的に警告
- 1回の変更で1項目 — 複数変更はバッチではなく順次

## 共有プロファイル

会社名・業種・法域等の全プラグイン共通項目は `~/.claude/plugins/config/claude-for-legal/company-profile.md` に保存。変更時に通知: 「この項目は全プラグイン共通です。変更すると他のプラグイン（commercial-legal-jp、privacy-legal-jp等）にも反映されます。」
