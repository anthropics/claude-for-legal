# /is-this-a-problem

## 前提条件

1. `~/.claude/plugins/config/claude-for-legal/product-legal-jp/CLAUDE.md` を読み込み。
2. `~/.claude/plugins/config/claude-for-legal/company-profile.md` を読み込み。

## 動作

PMやマーケターからSlackで飛んでくる「これ大丈夫？」「この表現使える？」「このキャンペーンOK？」に対して、高速トリアージを提供。

1. 質問をトラップチェックテーブルに照合
2. リスクキャリブレーションテーブルに照合
3. 3段階で判定

| 判定 | 意味 | 典型的な回答長 |
|---|---|---|
| ✅ 問題なし | キャリブレーション範囲内 | 2-3文 |
| ⚠️ 要確認 | リスクあり、詳細レビューが必要 | 1段落 + 次のスキルへの誘導 |
| 🔴 ストップ | 措置命令・課徴金リスク、即時対応が必要 | 1段落 + エスカレーション提案 |

## トラップチェックテーブル（日本法版）

シンプルに見えるが実は法的リスクが潜む典型的な質問:

| 質問パターン | トラップ | 正しい回答の方向性 |
|---|---|---|
| 「お客様の声をLPに載せたい」 | ステルスマーケティング規制（2023年指定告示）。対価提供・依頼の有無で規制対象に | 対価・依頼の有無を確認。依頼した場合「PR」表示が必要 |
| 「キャンペーンでポイント配りたい」 | 景品規制。総付景品の上限（取引価額の20%、上限200円/2万円の区分）に抵触する可能性 | 取引価額と景品価額を確認 → `/product-legal-jp:keihin-hyouji-check` |
| 「No.1って書きたい」 | 優良誤認リスク。客観的調査データの有無、調査方法の適切性が必須 | 調査データの有無と内容を確認 |
| 「通常価格を表示したい」 | 有利誤認リスク。二重価格表示の根拠（相当期間の販売実績）が必要 | 「通常価格」での販売期間・実績を確認 |
| 「サプリの効果をもっとアピールしたい」 | 薬機法。医薬品的効能効果の標ぼう禁止 | → `/product-legal-jp:yakki-ho-claims-check` |
| 「無料トライアルを始めたい」 | 特商法。定期購入の場合、最終確認画面の表示義務（2022年改正） | → `/product-legal-jp:tokushoho-compliance` |
| 「比較表を作りたい」 | 比較広告ガイドライン。客観的データに基づく公正な比較が必要 | 比較データの客観性を確認 |
| 「インフルエンサーに紹介してもらいたい」 | ステルスマーケティング規制。「PR」「広告」明示が必要 | 投稿ルール・ガイドラインの整備を確認 |
| 「期間限定セールをやりたい」 | 有利誤認リスク。「期間限定」が実質的に常時開催だと問題 | 過去のセール頻度を確認 |
| 「ユーザーデータで効果を証明したい」 | 不実証広告規制。社内データが「合理的根拠」の要件を満たすか | データの客観性・再現性を確認 |
| 「AIが推薦って書きたい」 | 優良誤認リスク + AI事業者ガイドライン。AIの推薦精度の裏付け | 推薦アルゴリズムの説明可能性を確認 |
| 「他社の商品名を広告に使いたい」 | 商標権侵害リスク + 不正競争防止法 | 使用態様を確認。比較広告の枠内か |

## 出力フォーマット

Slack向けの短い回答。トーン: 高速・直接的・有用。

```
[判定アイコン] **[判定]**

[1-3文の回答。根拠法令を含む。]

[トラップがある場合: 「注意: [トラップの説明]」]

[次のアクション: 「詳細は `/product-legal-jp:[該当スキル]` で確認できます」または「[確認すべき事項]を教えてください」]
```

## ルーティング

質問が複雑でトリアージでは不十分な場合:
- 景品・表示 → `/product-legal-jp:keihin-hyouji-check`
- 広告コピー全般 → `/product-legal-jp:marketing-claims-review`
- 薬機法関連 → `/product-legal-jp:yakki-ho-claims-check`
- 通信販売 → `/product-legal-jp:tokushoho-compliance`
- 機能全体のリスク → `/product-legal-jp:feature-risk-assessment`
- ローンチ全体 → `/product-legal-jp:launch-review`

⚖️ **弁護士確認ゲート:** この分析は弁護士による確認が必要です。弁護士法第72条により、弁護士でない者が法律事務を取り扱うことは禁止されています。最終的な法的判断は必ず弁護士に確認してください。

📋 **免責事項:** この出力はAIによる分析であり、法的助言を構成するものではありません。景品表示法・特商法・薬機法等の解釈・適用については、必ず弁護士にご確認ください。法令・ガイドラインは頻繁に改正されるため、最新の条文・通達・ガイドラインを確認してください。
