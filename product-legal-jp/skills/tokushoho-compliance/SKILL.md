# /tokushoho-compliance

## 前提条件

1. `~/.claude/plugins/config/claude-for-legal/product-legal-jp/CLAUDE.md` を読み込み。
2. `~/.claude/plugins/config/claude-for-legal/company-profile.md` を読み込み。

## スコープ

特定商取引法（特商法）のうち、主に以下をカバー:
- **通信販売**（第11条〜第15条の4）— ECサイト・アプリ内販売
- **定期購入規制**（2022年6月1日施行改正）— サブスクリプション・定期購入
- **特定継続的役務提供**（第41条〜第50条）— エステ・語学教室・学習塾・家庭教師・パソコン教室・結婚相手紹介サービス・美容医療（7業種）

## Part A: 通信販売の表示義務（第11条）

ECサイト・アプリで商品・サービスを販売する場合の必須表示事項:

| # | 表示事項 | チェック内容 |
|---|---|---|
| 1 | 販売価格（税込） | 消費税込みの総額表示がされているか |
| 2 | 送料 | 送料の明示（無料の場合も明記） |
| 3 | 代金の支払時期・方法 | クレジットカード、銀行振込等の記載 |
| 4 | 商品の引渡時期 | 注文から発送までの日数等 |
| 5 | 返品・解約の条件 | 返品特約の有無と内容（特約なしの場合は8日間のクーリングオフ類似制度） |
| 6 | 事業者の名称・住所・電話番号 | 法人名（個人事業主の場合は氏名）、所在地、連絡先 |
| 7 | 代表者名または責任者名 | 代表取締役または通信販売業務の責任者 |
| 8 | 申込みの有効期限 | 期限がある場合 |
| 9 | 特別の販売条件 | 数量限定、期間限定等 |
| 10 | ソフトウェアの動作環境 | デジタルコンテンツの場合 |

## Part B: 定期購入規制（2022年改正）

### 最終確認画面の表示義務（第12条の6）

2022年6月1日施行。通信販売における定期購入契約（サブスクリプション含む）の最終確認画面に以下の表示が必要:

| # | 必須表示事項 | 具体的要件 |
|---|---|---|
| 1 | 分量 | 各回の商品数量、定期購入の場合は全回数分 |
| 2 | 販売価格・対価 | 各回の支払金額、全期間の総支払額 |
| 3 | 支払の時期・方法 | 各回の引落し日・課金日 |
| 4 | 引渡し・提供時期 | 各回の発送・提供時期 |
| 5 | 申込みの期間 | 期間の定めがある場合 |
| 6 | 解約・返品に関する事項 | 解約条件、解約手続の方法、解約時の違約金 |

### 禁止行為

| 禁止事項 | 内容 |
|---|---|
| 不実告知（第13条の2） | 定期購入契約に関する重要事項の虚偽説明 |
| 誤認させる表示（第12条の6第2項） | 最終確認画面で消費者を誤認させる表示 |
| 解約妨害 | 電話がつながらない、ウェブでの解約手続が不明確等 |

### チェックポイント

1. **最終確認画面の特定** — 申込みボタンの直前の画面を特定
2. **6項目の表示チェック** — 各項目が明瞭に表示されているか
3. **誤認防止** — 「お試し」「初回無料」等の表示が、定期購入であることを隠していないか
4. **解約手続の容易性** — 解約がウェブで完結するか、電話のみでないか
5. **暗黒パターン（ダークパターン）** — 解約ボタンが見つけにくい、解約に不必要なステップがある等

### 違反時の制裁

| 制裁 | 内容 |
|---|---|
| 取消権 | 消費者は誤認による意思表示を取り消せる（第15条の4） |
| 行政処分 | 指示（第14条）、業務停止命令（第15条） |
| 刑事罰 | 業務停止命令違反: 3年以下の懲役or300万円以下の罰金（法人は1億円以下） |
| 直罰規定 | 最終確認画面の表示義務違反: 100万円以下の罰金（2022年改正で追加） |

## Part C: 特定継続的役務提供（該当する場合）

7業種に該当する場合の追加チェック:

| 業種 | 期間要件 | 金額要件 |
|---|---|---|
| エステティック | 1ヶ月超 | 5万円超 |
| 美容医療 | 1ヶ月超 | 5万円超 |
| 語学教室 | 2ヶ月超 | 5万円超 |
| 家庭教師 | 2ヶ月超 | 5万円超 |
| 学習塾 | 2ヶ月超 | 5万円超 |
| パソコン教室 | 2ヶ月超 | 5万円超 |
| 結婚相手紹介サービス | 2ヶ月超 | 5万円超 |

該当する場合:
- 書面交付義務（概要書面 + 契約書面）
- クーリングオフ（8日間）
- 中途解約権
- 関連商品の返品
