# /build-guide

1. `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/CLAUDE.md` → 役割（指導弁護士であること）、実務分野、管轄を読み込み。
2. 指導弁護士でなければ中止（学生は `/legal-clinic-jp:ramp` を実行）。
3. ウォークスルー：実務分野 → インテーク質問 → 教育指導方針 → レビューゲート → 管轄ルール。
4. `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/guides/<practice-area>.md` に書き込み。
5. テスト実行を提案 — 設定した教育指導方針で `/legal-clinic-jp:draft` を実行し、学生が見るものを確認。

```
/legal-clinic-jp:build-guide
```

# 指導者ガイド作成

## 目的

指導者ガイドは、学生向けスキルを「作業完了ツール」から「教育ツール」に変えるダイヤルです。すべての学生向けスキルは出力前にこのガイドを読みます。

**対象：指導弁護士。** 学生ではありません。

## ガイドが制御する内容

- **インテーク質問:** この実務分野で何を聞くか。レッドフラグ。案件の適否の基準。
- **教育指導方針:** スキルがどれだけ作業するか vs 学生がどれだけ作業するか。
  - `guide`（デフォルト）: 構造を提示 → 学生が記入 → フィードバック
  - `assist`: 成果物を作成 → 学生がレビュー
  - `teach`: 学生が起案 → ソクラテス式質問 → フィードバック
- **レビューゲート:** どの成果物が指導弁護士のレビューを要するか。
- **管轄ルール:** 適用される規則。

## ウォークスルー

### ステップ1: 実務分野の選択

クリニックの実務分野から選択（借地借家、労働、債務整理、離婚・親権、外国人相談）。

### ステップ2: インテーク質問のカスタマイズ

> この実務分野で依頼者に必ず聞くべき質問は何ですか？レッドフラグは？案件として受けるべきかの判断基準は？

### ステップ3: 教育指導方針の設定

> 書面ごとに異なる方針を設定できます。例えば：
> - 内容証明郵便は `assist`（学生がレビュー）
> - 訴状は `guide`（構造を提示、学生が記入）
> - 分析メモは `teach`（学生が起案、フィードバック）

### ステップ4: レビューゲートの設定

> どの成果物は指導弁護士の事前承認が必要ですか？
> 例：裁判所提出書面はすべて、依頼者書簡はすべて、内部メモは不要

### ステップ5: 弁護士法第72条の補足ルール

> この実務分野で特に注意すべき弁護士法第72条の境界線はありますか？
> 例：依頼者への電話連絡は学生のみで行ってよいか、指導弁護士の同席が必要か

## 書き込み

`~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/guides/<practice-area>.md` に書き込み。

## テスト実行の提案

> ガイドを作成しました。学生がどのような体験をするか確認しますか？設定した教育指導方針で `/legal-clinic-jp:draft` を実行して、学生が見るものを体験できます。
