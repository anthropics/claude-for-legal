# 調停申立書生成

## 目的

調停は日本の紛争解決において重要な位置を占めます。特にリーガルクリニックが扱う家事事件（離婚、婚姻費用、面会交流等）では、調停前置主義（家事事件手続法第257条第1項）により、訴訟の前に調停を経ることが必要です。

このスキルは調停申立書のドラフトを裁判所所定様式に準拠して作成します。

## 弁護士法第72条ゲート

調停申立書の作成・提出は法律事務に該当します。学生は指導弁護士の監督下でドラフトを作成し、指導弁護士のレビュー・承認を経て提出します。

## 調停の種類

### 家事調停（家庭裁判所）

| 調停の種類 | 根拠法令 | よくある申立内容 |
|---|---|---|
| 離婚調停（夫婦関係調整） | 家事事件手続法第244条 | 離婚、親権、養育費、財産分与、慰謝料 |
| 婚姻費用分担調停 | 民法第760条 | 別居中の生活費の分担 |
| 面会交流調停 | 民法第766条 | 子との面会交流の取り決め |
| 養育費請求調停 | 民法第766条 | 養育費の支払い請求 |
| 遺産分割調停 | 民法第907条第2項 | 遺産の分割方法 |

### 民事調停（簡易裁判所）

| 調停の種類 | 根拠法令 | よくある申立内容 |
|---|---|---|
| 賃料減額調停 | 借地借家法第32条 | 賃料の減額請求 |
| 近隣紛争調停 | 民事調停法第2条 | 騒音、境界、日照 |
| 金銭債務調停 | 特定調停法 | 債務の返済条件変更 |

## ワークフロー

### ステップ1: 調停の種類と管轄の確認

- 家事調停 → 相手方の住所地を管轄する家庭裁判所（家事事件手続法第245条）
- 民事調停 → 相手方の住所地を管轄する簡易裁判所（民事調停法第3条）

### ステップ2: 申立書のドラフト

**家事調停申立書の基本構成:**

```markdown
家事調停申立書

[日付]

[家庭裁判所名] 御中

申立人代理人弁護士 [指導弁護士名]

申立人 [氏名]（[生年月日]）
    住所 [住所]

相手方 [氏名]（[生年月日]）
    住所 [住所]

[調停の種類]調停申立事件

申立ての趣旨
[要記入 — 求める調停の内容を具体的に記載]

申立ての理由
第1 当事者の関係
[要記入]

第2 申立てに至る経緯
[要記入]

第3 申立ての必要性
[要記入]

附属書類
1. 申立書副本   1通
2. 戸籍謄本     1通
3. [その他必要書類]

[収入印紙額: [金額]円]
[郵便切手: [金額]円分]
```

### ステップ3: 必要書類のチェックリスト

| 書類 | 必要性 | 取得先 |
|---|---|---|
| 戸籍謄本（家事調停の場合） | 必須 | 市区町村役場 |
| 住民票 | 場合による | 市区町村役場 |
| 収入証明書（婚姻費用・養育費の場合） | 必須 | 勤務先 / 税務署 |
| 不動産登記簿謄本（遺産分割の場合） | 必須 | 法務局 |

### ステップ4: 弁護士確認ゲート

> **【指導弁護士確認】** この調停申立書は指導弁護士のレビュー・承認なしに裁判所に提出することはできません。
