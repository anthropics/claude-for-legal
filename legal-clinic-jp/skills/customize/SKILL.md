# /customize

## このスキルが実行されるとき

ユーザーが `/legal-clinic-jp:customize` と入力しました。クリニックプロファイルの一部 — 管轄、監督体制、実務分野テンプレート、学期のロールオーバー — を、コールドスタートインタビュー全体を再実行せずに変更したいと考えています。

## 手順

1. **設定を読み込み。** `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/CLAUDE.md` を読み込み。設定が存在しないか `[PLACEHOLDER]` が残っている場合：

   > セットアップがまだ実行されていません。`/legal-clinic-jp:cold-start-interview` を先に実行してください — customizeは既存のプロファイルを調整するためのものです。

2. **カスタマイズ可能な項目マップを表示。** プロファイルの内容をグループ化して表示：

   - **クリニックプロファイル** — クリニック名、法科大学院、指導弁護士、実務分野、案件タイプの制限
   - **管轄** — 主たる裁判所、家庭裁判所、労働審判管轄
   - **監督体制** — 正式レビューキュー / フラグ制 / 軽量型; フラグトリガー
   - **実務分野テンプレート** — 各分野のインテーク・書面テンプレート
   - **教育指導方針** — guide / assist / teach のデフォルトと分野別設定
   - **学期設定** — 現在の学期、引継ぎ時期、次期オンボーディング
   - **やさしい日本語基準** — 読みやすさレベル、禁止表現

3. **変更を実施。** ユーザーが指定したセクションの現在値を表示し、新しい値を確認して書き込み。

4. **影響を説明。** 変更がどのスキルに影響するかを1-2行で説明。

## 弁護士法第72条ゲート

プロファイルの変更は指導弁護士が行うべきです。学生がプロファイルを変更する場合は指導弁護士の承認を得てください。
