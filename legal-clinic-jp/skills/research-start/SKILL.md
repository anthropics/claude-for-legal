# /research-start

1. `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/CLAUDE.md` → 管轄、実務分野を読み込み。
2. 論点を具体的に構成。ロードマップを構築：法令の出発点（未検証）、判例分野（個別判例ではなく）、二次資料、検索キーワード。
3. 学生が既存のリサーチをアップロードした場合：統合してギャップを特定。
4. 「手がかりであり権威ある引用ではない」ヘッダー付きで出力。すべてが学生が検証する出発点。

```
/legal-clinic-jp:research-start "借地借家法第28条の正当事由の判断基準"
```

# リサーチ開始：ロードマップ（リサーチそのものではない）

## 目的

法的リサーチは臨床教育の核心です。しかし初期段階 — 何を調べるか、正しい条文を見つける、法的枠組みを理解する — が最も時間がかかり、教育効果が低い部分です。

このスキルは出発点を提供します：確認すべき法令、調査すべき判例分野、検索キーワード。**いずれも未検証。いずれも権威ある引用ではない。すべてが学生が追跡する手がかり。**

## 弁護士法第72条ゲート

リサーチ活動自体は弁護士法第72条の「法律事務」には直ちに該当しませんが、リサーチ結果に基づく法的判断は指導弁護士が行います。

```markdown
## 検証プロンプト
- [ ] 法令の条文番号と内容をe-Govで確認したか
- [ ] 判例は裁判所ウェブサイトまたはWestlaw Japanで原文を確認したか
- [ ] 最新の法改正・判例変更がないか確認したか
- [ ] 指導弁護士にリサーチの方向性を相談したか
```

## このスキルが行わないこと

- **権威ある引用の提供。** すべては手がかり。学生が検証する。
- **法的分析の実施。** 分析は `/legal-clinic-jp:memo` で学生が行う。
- **リサーチの完了。** 出発点の提供のみ。
