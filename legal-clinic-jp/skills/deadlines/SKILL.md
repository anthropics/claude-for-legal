# 期限管理

## 目的

クリニックの最大のオペレーショナルリスクは期限の見逃しです。学生は複数案件を持ち、授業と並行し、学期ごとに入れ替わります。個々の学生の頭の中にしかない期限は、引き継ぎ時や試験期間に失われます。

指導弁護士は期限が見逃された場合の責任を負います。このスキルはそのリスクレベルに合わせて設計されています。

## 期間計算の基本原則

日本法の期間計算は民法の規定に従います：

- **民法第140条（初日不算入の原則）:** 日、週、月又は年によって期間を定めたときは、期間の初日は、算入しない。ただし、その期間が午前零時から始まるときは、この限りでない。
- **民法第141条（期間の満了）:** 前条の場合には、期間は、その末日の終了をもって満了する。
- **民法第142条（期間の末日が休日の場合）:** 期間の末日が日曜日、国民の祝日に関する法律（昭和二十三年法律第百七十八号）に規定する休日その他の休日に当たるときは、その日に取引をしない慣習がある場合に限り、期間は、その翌日に満了する。
- **民法第143条（暦による期間の計算）:** 週、月又は年によって期間を定めたときは、その期間は、暦に従って計算する。

**注意:** 民事訴訟法上の期間計算（民事訴訟法第95条）、不変期間（民事訴訟法第96条〜第97条）については別途考慮が必要。

## モード

### `--add` — 新しい期限の登録

**入力項目:**
- 案件ID + 案件名
- 実務分野
- 種類（提出 / 口頭弁論期日 / 出訴期限 / 調停期日 / 消滅時効 / 異議申立期間 / 労働審判期日 / その他）
- 説明 — 何が期限か（1行）
- 期日（および該当する場合は時間）
- 根拠 — 期限の出所（訴状送達日 YYYY-MM-DD、民事訴訟法第○条、等）
- 担当学生

**民法の期間計算に基づくプロアクティブ確認:**
期日入力後、期間計算の基本原則に基づいて妥当性をチェック：
- 初日不算入の原則が正しく適用されているか
- 末日が休日に該当しないか
- 不変期間（控訴期間等）の場合、追完の余地はあるか

通常範囲から大幅に外れる場合は学生に確認を求める。

### `--report` — 全案件レポート

デフォルトモード。全案件の期限を以下の区分で表示：

| 区分 | 表示 |
|---|---|
| 🔴 期限超過 | 未解決の期限超過項目 |
| 🟠 3日以内 | 直近の期限 |
| 🟡 7日以内 | 今週の期限 |
| 🟢 14日以内 | 来週までの期限 |

担当学生別、実務分野別の集計も表示。

### `--update [id]` — 更新

フィールドの変更。変更日と変更理由をメモに記録。

### `--complete [id]` — 完了

完了マーク。学生に「実際に提出/送付済みですか？」と確認。

### `--close [id]` — 閉鎖

完了せずに閉鎖。理由の記載を要求。

## 弁護士法第72条ゲート

期限の計算と管理はリスク管理の一環であり、指導弁護士の監督下で行われます。期限に基づく法的判断（期限の延長申請、時効の援用等）は指導弁護士が行います。

## 免責事項

> **【注意】** 期限計算はツールによる参考情報です。すべての期限は学生が計算し、指導弁護士が確認してください。計算ミスによる不利益について本ツールは責任を負いません。
