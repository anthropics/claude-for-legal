# /status

1. `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/CLAUDE.md` → 監督体制、やさしい日本語基準、管轄を読み込み。
2. 案件ノートを読み込み。
3. 指定された対象者向けに生成：
   - `依頼者` — やさしい日本語、何が起きたか/次は何か/依頼者がすること/連絡方法
   - `内部` — 手続の進行状況、前回確認からの進捗、今後の予定、指導弁護士の判断が必要な事項
   - `裁判所` — 裁判所書式の進行状況報告
4. 対象者に応じた監督ルーティング。

```
/legal-clinic-jp:status 依頼者
```

```
/legal-clinic-jp:status 内部
```

# ステータス：対象者別案件サマリー

## 目的

同じ案件の状況を、対象者に合わせて異なるフレーミングで報告します。依頼者にはやさしい日本語で、指導弁護士には法的分析を含めて、裁判所には書式に従って。

## 弁護士法第72条ゲート

依頼者向けのステータス報告は、法的助言を含む可能性があるため、指導弁護士のレビューを経て送付します。内部向けは学生の分析として位置付けられます。

## 依頼者向け（やさしい日本語）

```markdown
[依頼者名]様

ご相談の件について、お知らせします。

**これまでのこと:**
[何が起きたか — やさしい日本語で]

**これからのこと:**
[次に何があるか]

**[依頼者名]様にしていただきたいこと:**
[依頼者がやるべきこと。なければ「今のところ、していただくことはありません。」]

**ご連絡先:**
[クリニックの電話番号と受付時間]
```

## 内部向け（指導弁護士向け）

```markdown
# 案件ステータス: [案件名/ID]

**担当学生:** [学生名]
**実務分野:** [分野]
**最終更新:** [日付]

## 手続の進行状況
[現在の手続段階]

## 前回確認からの進捗
- [アクション1]
- [アクション2]

## 今後の予定
| 項目 | 期日 | 担当 |
|---|---|---|
| [項目] | [期日] | [学生/指導弁護士] |

## 指導弁護士の判断が必要な事項
- [事項1 — なぜ判断が必要か]

## 学生の評価
[学生による案件の見通し — 指導弁護士のレビュー対象]
```
