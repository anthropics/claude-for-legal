# ドラフト：初稿書面生成

## 目的

学生は書面の初稿作成に多大な時間を費やしますが、教育的価値は分析と戦略にあり、書式の設定にはありません。このスキルは案件ノートと実務分野テンプレートから初稿を作成し、学生の時間を分析に集中させます。

**すべてのドラフトは明示的に出発点です。** 最終成果物ではありません。学生が分析・修正し、指導弁護士がレビューしてから提出されます。

## 弁護士法第72条ゲート

弁護士法第72条により、学生は独立して裁判所への書面を作成・提出することができません。すべてのドラフトは指導弁護士の監督下で作成され、指導弁護士のレビュー・承認を経て提出されます。

## ワークフロー

### ステップ1: 書面の種類

リクエストをクリニックのテンプレートセットに照合：

| 実務分野 | 書面 |
|---|---|
| **借地借家** | 答弁書（建物明渡請求）、内容証明郵便（修繕請求・敷金返還）、反訴状 |
| **労働** | 労働審判申立書、訴状（解雇無効確認・未払賃金）、準備書面 |
| **債務整理** | 過払金返還請求書、任意整理和解案、自己破産申立書 |
| **離婚・親権** | 離婚調停申立書、婚姻費用分担調停申立書、面会交流調停申立書、訴状（離婚） |
| **外国人相談** | 在留資格変更許可申請書、在留期間更新許可申請書、異議申立書 |
| **一般訴訟** | 訴状、答弁書、準備書面、証拠説明書、書証目録 |

### ステップ2: 事実の収集

インテークサマリーまたは案件ノートを読み取り。書面に必要な各事実について：

| 書面に必要 | あり？ | 情報源 |
|---|---|---|
| [事実] | ✓ / ✗ | [インテーク / 依頼者資料 / 要取得] |

不足している事実は `[要記入: ...]` で明示。**推測は絶対にしない。**

### ステップ3: 書式の適用

管轄裁判所の書式に従う。日本の裁判所書面の基本構成：

**訴状の場合:**
```
訴状

[日付]

[裁判所名] 御中

原告訴訟代理人弁護士 [指導弁護士名]
（補助者 法科大学院生 [学生名]）

原告 [氏名]
被告 [氏名]

[事件名]請求事件

訴訟物の価額 金[金額]円
貼用印紙額 金[金額]円

請求の趣旨
1. [要記入]
2. 訴訟費用は被告の負担とする
との判決並びに仮執行の宣言を求める。

請求の原因
第1 当事者
[要記入]

第2 事実関係
[要記入]

第3 法的根拠
[要記入 — 根拠条文を明示]

証拠方法
甲第1号証 [要記入]

附属書類
1. 訴状副本   1通
2. 甲号証写し  各1通
3. 資格証明書  1通
```

### ステップ4: 弁護士確認ゲート

ドラフト完了後、以下を表示：

> **【指導弁護士確認】** このドラフトは指導弁護士のレビュー・承認なしに裁判所に提出することはできません。弁護士法第72条により、学生は独立して法律事務を行えません。

## このスキルが行わないこと

- **最終書面の作成。** すべてのドラフトは学生が分析・修正し、指導弁護士がレビューする。
- **裁判所への提出。** 弁護士法第72条により、学生は独立して提出できない。
- **法的戦略の決定。** 指導弁護士の判断。
