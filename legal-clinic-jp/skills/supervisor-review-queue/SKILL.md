# /supervisor-review-queue

1. `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/CLAUDE.md` → 監督体制を確認。「正式レビューキュー」でない場合：クリニックは[フラグ制/軽量型]で設定されており、正式キューは存在しないと説明。
2. デフォルト：緊急度別、学生別にレビュー待ちを表示。
3. アクション：承認 / 編集後承認 / メモ付き差戻し。すべて記録。

```
/legal-clinic-jp:supervisor-review-queue
```

```
/legal-clinic-jp:supervisor-review-queue --approve Q-003
```

```
/legal-clinic-jp:supervisor-review-queue --return Q-004 "管轄裁判所を再確認してください"
```

# 指導弁護士レビューキュー（任意）

## 目的

一部のクリニックでは正式なゲートを設けます：学生がドラフト → 指導弁護士がレビュー → 成果物がリリース。他のクリニックではケースカンファレンスや個別面談で監督します。

**このスキルは `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/CLAUDE.md` → 監督体制が「正式レビューキュー」の場合のみ有効です。**

## 弁護士法第72条との関係

正式レビューキューは弁護士法第72条のコンプライアンスを強化するメカニズムです。指導弁護士の実質的な監督を記録に残し、学生の成果物が指導弁護士の確認なしに外部に出ることを防ぎます。

## キュー

レビュー待ちの項目を表示：

| ID | 案件 | 書面タイプ | 学生 | 提出日 | 緊急度 | フラグ |
|---|---|---|---|---|---|---|
| Q-001 | [案件名] | [タイプ] | [学生名] | [日付] | [高/中/低] | [フラグ理由] |

## アクション

### 承認 (`--approve ID`)
- 成果物を承認済みとしてマーク
- 承認日時と承認者を記録
- 学生に通知

### 編集後承認 (`--edit ID`)
- 指導弁護士が編集を加えた上で承認
- 編集内容と承認を記録

### 差戻し (`--return ID 'メモ'`)
- メモ付きで学生に差戻し
- 差戻し理由を記録
- 学生に通知と修正指示

## 免責事項

> レビューキューは監督体制の一部です。キューを通過したことは法的正確性の保証ではありません。指導弁護士は各成果物の内容を実質的にレビューする責任があります。
