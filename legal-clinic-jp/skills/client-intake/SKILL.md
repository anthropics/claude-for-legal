# /client-intake

1. `~/.claude/plugins/config/claude-for-legal/legal-clinic-jp/CLAUDE.md` → 実務分野、インテークテンプレート、監督体制、フラグトリガーを読み込み。
2. 以下のワークフローを使用。
3. 実務分野テンプレートに誘導。面談を通じて分野横断的な論点を聴取。
4. 利益相反フラグ。トリアージ分類。
5. AI補助ラベル、検証プロンプト、監督ルーティング付きの書式化された案件サマリーを出力。

```
/legal-clinic-jp:client-intake
```

# 依頼者インテーク

## 目的

インテークはクリニックの最大のボトルネックです。学生が面談に45分、記録作成に1時間、論点整理にさらに時間を費やします。

このスキルは面談を構造化し、記録を作成し、分野横断的な論点を発見し、利益相反をフラグします。学生の時間は分析に集中できます。

**行わないこと:** 案件受任の判断。それは学生の分析と指導弁護士の判断です。

## 弁護士法第72条ゲート

本スキルの出力は指導弁護士の監督下での補助者活動として位置付けられます。インテーク結果に基づく法的判断は指導弁護士が行います。学生は事実の聴取と記録のみを行い、法的助言は行いません。

## ワークフロー

### ステップ1: 実務分野の特定

> 「今日はどのようなご相談ですか？どのようなことでお困りですか？」

回答から適切な実務分野テンプレートに誘導。複数分野にまたがる場合はすべて記録。

### ステップ2: 実務分野別インテーク

**借地借家:**
- 住居の種類（民間賃貸、公営住宅、UR）
- 何が起きたか：立退き要求、修繕問題、敷金返還、賃料値上げ
- 賃貸借契約の内容（普通借家/定期借家）、賃料支払状況
- 修繕の要望（修繕請求の有無、貸主の対応、記録の有無）
- 緊急度：明渡期限、口頭弁論期日

**労働:**
- 雇用形態（正社員、契約社員、派遣、パート・アルバイト）
- 何が起きたか：解雇・雇止め、未払賃金、残業代未払い、ハラスメント
- 就業規則・雇用契約書の有無
- 労基署への相談の有無
- 緊急度：解雇通知日、最終出勤日

**債務整理:**
- 債務の種類と総額（消費者金融、クレジットカード、銀行ローン、奨学金）
- 債権者数と各社の債務額
- 収入と支出の状況
- 過去の借入・返済歴（過払金の可能性）
- 緊急度：督促状、訴訟提起の有無、給与差押え

**離婚・親権:**
- 婚姻期間、別居の有無
- 争点（離婚自体、親権、養育費、財産分与、慰謝料、面会交流）
- 子どもの有無、年齢、現在の監護状況
- DV・虐待の有無（慎重に確認）
- 緊急度：調停期日、保護命令の必要性

**外国人相談:**
- 在留資格の種類と在留期間
- 何が起きたか：在留資格の更新・変更、退去強制、入管収容
- 家族の在留資格状況
- 日本語能力（やさしい日本語の必要性）
- 緊急度：在留期限、出頭日

### ステップ3: 分野横断的な論点発見

| 依頼者の発言 | フラグする分野 |
|---|---|
| 「在留資格が心配です」 | 外国人相談 — 借地借家のインテークでも |
| 「配偶者から暴力を受けています」 | DV / 家事 / 保護命令 |
| 「給料を払ってもらえていません」 | 労働 — 外国人技能実習生の場合は入管法も |
| 「借金の取り立てが止まりません」 | 債務整理 — 違法な取立てなら貸金業法 |
| 「大家に『出て行け』と言われました」 | 借地借家 + 借地借家法による保護の検討 |

### ステップ4: 利益相反チェック

- 相手方の氏名 — クリニックが相手方を代理していないか？
- 関連当事者 — 利益相反の可能性がある人物は？

フラグのみ。利益相反の解決は指導弁護士が行う。

### ステップ5: トリアージ分類

| 分類 | 意味 |
|---|---|
| **緊急** | 期限が数日以内、安全上の問題、不可逆的な損害が差し迫っている |
| **要早期対応** | 期限が数週間以内、損害が継続中だが直ちに不可逆的ではない |
| **通常** | 差し迫った期限なし、通常のキューで対応可能 |
| **対象外の可能性** | クリニックの実務分野外 — 紹介先の検討をフラグ |

### ステップ6: 法テラス利用可能性の確認

依頼者の経済状況に応じて、法テラス（日本司法支援センター）の民事法律扶助制度の利用可能性を確認。詳細は `/legal-clinic-jp:houterasu-support` を参照。

### ステップ7: 期限の引き渡し

インテークで期限が判明した場合、`/legal-clinic-jp:deadlines --add` ブロックを出力に含める。

## このスキルが行わないこと

- **案件受任の判断。** 学生が分析し、指導弁護士が判断。
- **利益相反の解決。** フラグのみ。指導弁護士が判断。
- **インテーク中の法的助言。** インテークは情報収集。助言は分析と指導弁護士のレビュー後。
- **最終文書の作成。** サマリーは出発点。学生が読み、誤りを修正し、分析を構築する。
