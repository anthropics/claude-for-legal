# /hanshakai-check

反社会的勢力排除条項（暴排条項）の存在確認と完全性検証を行います。

## 目的

政府指針（2007年「企業が反社会的勢力による被害を防止するための指針」）および各都道府県の暴力団排除条例に基づき、契約書に適切な反社排除条項が含まれているかを検証します。

## ワークフロー

### ステップ1: 設定の読み込み

`~/.claude/plugins/config/claude-for-legal/commercial-legal-jp/CLAUDE.md` を読み込む。以下を抽出：
- 自社の反社排除条項の標準ポジション
- ひな形の有無

### ステップ2: 反社排除条項の存在確認

契約書内で以下のキーワードを検索：
- 反社会的勢力
- 暴力団
- 暴力団員
- 暴力団関係企業
- 総会屋
- 社会運動等標ぼうゴロ
- 特殊知能暴力集団
- 反社
- 暴排

**条項が存在しない場合：** 重大な欠落として報告し、追加を強く推奨する。

### ステップ3: 三要素の充足確認

反社排除条項の完全性を以下の三要素で評価：

#### 要素1: 表明保証

以下の表明保証が含まれているか確認：

| チェック項目 | 充足 |
|---|---|
| 自らが暴力団、暴力団員、暴力団準構成員、暴力団関係企業、総会屋、社会運動等標ぼうゴロ、特殊知能暴力集団その他これらに準ずる者（以下「反社会的勢力」）に該当しないこと | |
| 自らの役員が反社会的勢力に該当しないこと | |
| 反社会的勢力に自己の名義を利用させていないこと | |
| 反社会的勢力が経営に実質的に関与していないこと | |
| 自社もしくは第三者の不正の利益を図る目的、または第三者に損害を加える目的をもって反社会的勢力を利用していないこと | |
| 反社会的勢力に対して資金等の供給、便宜の提供をしていないこと | |
| 反社会的勢力と社会的に非難されるべき関係を有していないこと | |

#### 要素2: 誓約事項

以下の誓約が含まれているか確認：

| チェック項目 | 充足 |
|---|---|
| 暴力的な要求行為を行わないこと | |
| 法的な責任を超えた不当な要求行為を行わないこと | |
| 取引に関して脅迫的な言動をし、または暴力を用いないこと | |
| 風説を流布し、偽計を用い、または威力を用いて相手方の信用を毀損し、業務を妨害しないこと | |
| 反社会的勢力を利用しないこと | |

#### 要素3: 解除権

以下の解除関連条項が含まれているか確認：

| チェック項目 | 充足 |
|---|---|
| 表明保証違反時の無催告解除権 | |
| 誓約事項違反時の無催告解除権 | |
| 解除により相手方に損害が生じても賠償義務を負わない旨 | |
| 解除した当事者に損害が生じた場合、相手方が賠償する旨 | |

### ステップ4: 暴力団排除条例との適合性

各都道府県の暴力団排除条例では、事業者に対して暴力団排除の努力義務を課しています。契約書の条項が以下の点で条例の趣旨に適合しているか確認：

- 契約締結前の確認義務（暴力団排除条項の導入）
- 暴力団等との取引の排除
- 不当な要求に対する拒絶

**注意:** 条例の具体的な内容は都道府県によって異なります。自社の所在地と相手方の所在地の条例を確認することを推奨。

### ステップ5: 調査義務の有無

- 相手方の反社会的勢力に該当しないことの調査義務が規定されているか
- 調査協力義務が規定されているか
- 定期的な確認（反社データベース照会等）の義務が規定されているか

### ステップ6: 損害賠償条項（違約金条項）の有無

- 反社排除条項違反時の違約金条項が規定されているか
- 違約金の金額基準は適切か（契約金額の一定割合が一般的）
- 損害賠償の予定（民法第420条）としての位置づけか、それとも違約罰か
