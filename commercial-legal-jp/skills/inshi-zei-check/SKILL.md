# /inshi-zei-check

印紙税法に基づき、契約書が課税文書に該当するか、該当する場合の印紙税額を判定します。

## 目的

日本の印紙税法では、特定の文書（課税文書）の作成時に収入印紙の貼付が必要です。印紙税の貼付漏れには過怠税が課されます（本来の印紙税額の3倍、自主的な申出の場合は1.1倍）。このスキルは契約書の課税文書該当性を判定し、必要な印紙税額を算出します。

## ワークフロー

### ステップ1: 契約書の形態確認

まず契約書の形態を確認：

- **電子契約（クラウドサイン、DocuSign等）の場合:** 電子契約は「文書の作成」に該当しないため、印紙税は不課税。その旨を報告して終了。
  - 根拠：印紙税法第2条「別表第一の課税物件の欄に掲げる文書のうち...作成したもの」
  - 国税庁見解：電磁的記録により作成されたものは「文書」に該当しない

- **紙の契約書の場合:** ステップ2に進む。

- **PDF印刷の場合:** プリントアウトに署名・押印する場合は「文書の作成」に該当する可能性がある。確認を求める。

### ステップ2: 課税文書の該当性判定

印紙税法別表第一の課税物件表に照らして、契約書の文書番号を判定：

| 号 | 文書の種類 | 典型的な契約書 |
|---|---|---|
| 第1号 | 不動産等の譲渡契約書、地上権等の設定契約書、消費貸借契約書、運送契約書 | 不動産売買契約書、金銭消費貸借契約書 |
| 第2号 | 請負に関する契約書 | 工事請負契約書、システム開発委託契約書、広告制作契約書 |
| 第7号 | 継続的取引の基本となる契約書 | 基本契約書、取引基本契約書、代理店契約書 |
| 第12号 | 信託行為に関する契約書 | 信託契約書 |
| 第13号 | 債務の保証に関する契約書 | 保証契約書 |
| 第14号 | 金銭又は有価証券の寄託に関する契約書 | 寄託契約書 |
| 第15号 | 債権譲渡又は債務引受けに関する契約書 | 債権譲渡契約書 |

**非課税文書の確認：**
- 記載金額が1万円未満の第1号・第2号文書は非課税
- 国等が作成した文書は非課税（印紙税法第5条）
- 営業に関しない受取書は非課税

**注意すべき判定ポイント：**
- **「請負」と「委任」の区別:** 「業務委託契約書」と題していても、内容が請負（仕事の完成を約するもの）であれば第2号文書に該当する。委任（事務の処理を委託するもの）は課税文書に該当しない。
- **第7号文書の判定:** 3ヶ月以上の期間、営業者間の売買等の取引に関する基本的事項を定めた契約書は第7号文書（4,000円）。ただし、第1号・第2号にも該当する場合は税額が高い方で課税。
- **変更契約書・覚書:** 重要な事項を変更する場合は課税文書に該当する可能性がある。

### ステップ3: 印紙税額の算出

課税文書に該当する場合、記載金額に応じた印紙税額を算出：

**第2号文書（請負契約書）の税額表（主要部分）：**

| 記載金額 | 印紙税額 |
|---|---|
| 1万円未満 | 非課税 |
| 1万円以上 100万円以下 | 200円 |
| 100万円超 200万円以下 | 400円 |
| 200万円超 300万円以下 | 1,000円 |
| 300万円超 500万円以下 | 2,000円 |
| 500万円超 1,000万円以下 | 10,000円 |
| 1,000万円超 5,000万円以下 | 20,000円 |
| 5,000万円超 1億円以下 | 60,000円 |
| 1億円超 5億円以下 | 100,000円 |
| 5億円超 10億円以下 | 200,000円 |
| 10億円超 50億円以下 | 400,000円 |
| 50億円超 | 600,000円 |
| 記載金額なし | 200円 |

**第7号文書（継続的取引の基本契約書）:** 一律4,000円

**注意:** 税額表は変更される可能性があります。最新の税額表は国税庁のウェブサイトで確認してください `[model knowledge --- verify]`。

### ステップ4: 実務上の留意点

- **印紙税の負担者:** 法律上は文書の作成者が負担。実務上は折半または一方が負担する取決めが一般的。
- **消印:** 収入印紙に消印（割印）を忘れないこと。消印がない場合は過怠税の対象。
- **電子契約への移行提案:** 印紙税のコスト削減の観点から、電子契約への移行を検討する価値があることを付記。
