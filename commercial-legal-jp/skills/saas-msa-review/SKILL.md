# SaaS利用契約レビュー

## 目的

SaaS契約はワンショットのベンダー契約とリスクプロファイルが異なる。更新のたびにコストが積み上がり、データが蓄積し、乗り換えコストが月ごとに増大する。このスキルはそのリスクを念頭にレビューする。

`~/.claude/plugins/config/claude-for-legal/commercial-legal-jp/CLAUDE.md` のプレイブックによる標準チェックに加え、SaaS固有のオーバーレイを適用する。

## ワークフロー

### ステップ1: 設定の読み込み

`~/.claude/plugins/config/claude-for-legal/commercial-legal-jp/CLAUDE.md` を読み込む。プレースホルダーが存在する場合は停止し、セットアップを促す。

**どちら側か？** 自社がSaaSベンダーか利用者かを判定する。通常は明らか：相手方がSaaSベンダーでプラットフォームを売っているなら購買側。自社がSaaSベンダーで相手方が顧客なら販売側。不明な場合は確認する。

プレイブックの該当するセクション（`### 購買側プレイブック` または `### 販売側プレイブック`）を読み込む。

### ステップ2: 標準プレイブックチェック

vendor-agreement-reviewスキルの標準チェック（責任制限、損害賠償、契約不適合責任、秘密保持、解除、準拠法・管轄、反社排除条項）をすべて実行する。

### ステップ3: SaaS固有オーバーレイ

以下のカテゴリごとに、契約書の記載を `~/.claude/plugins/config/claude-for-legal/commercial-legal-jp/CLAUDE.md` のポジションと比較する。

#### 1. 自動更新条項

SaaS契約で最も多いトラブル：誰も更新通知期間に気づかず、翌年より高い料金でロックインされる。

各要素をプレイブックポジションと比較：

- **更新期間の長さ**（初期と同じ / より長い / 複数年に自動転換）
- **解約通知期間**（更新日の何日前までに通知）
- **通知方法**（メール / 書面 / ポータル上 / 内容証明）
- **更新時の価格**（同額 / CPI連動 / 当時の定価 / 上限なし）

**日本法における注意点：**
- 特定商取引法：消費者向けサブスクリプションの場合、自動更新の明確な表示義務
- 消費者契約法第10条：消費者の利益を一方的に害する条項は無効となる可能性
- BtoB取引でも、合理的な解約通知期間の設定が求められる

**更新日と通知期間を抽出・記録する**（フラグの有無にかかわらず）。renewal-trackerスキルへのハンドオフに使用。

#### 2. 価格改定条項

各要素をプレイブックポジションと比較：

- **年次値上げ率**（固定% / CPI連動 / 上限なし / その他）
- **超過利用料金**（公表料金表 / 割増料金 / 未定）
- **「利用料」の範囲**（サブスクリプションのみ / 「追加サービス」を広く定義）

#### 3. データポータビリティとサービス終了

ベンダーを離れる時、データを取り出せるか？各要素を確認：

- **エクスポート形式**（オープン標準 / プロプライエタリ / 「合理的な」形式）
- **エクスポート可能時期**（契約期間中セルフサービス / 要求に応じて / 解約時のみ）
- **解約後のアクセス期間**（解約後何日間エクスポート可能か）
- **エクスポート費用**（無料 / 実費 / データ量に応じた課金）
- **削除証明**（要求に応じて証明書発行 / なし / ベンダーが派生データを保持）

#### 4. SLA（サービスレベル合意）

事業がこのサービスの稼働に依存している場合のみ重要。補助的なツールならこのセクションをスキップする。

- **稼働率コミットメント**（パーセンテージ / 「商業上合理的な努力」）
- **測定期間**（月次 / 四半期 / 年次）
- **救済措置**（サービスクレジット --- 算出方法、上限、唯一の救済か）
- **計画メンテナンス除外**（定義されたウィンドウ / 事前通知 / 無制限）
- **クレジットと責任制限条項の関係**

#### 5. サブプロセッサー（再委託先）

個人情報保護法の観点で重要。サブプロセッサーリストはサブスクリプション期間中に変更される。

- **現在のリスト**（公開済 / 要求に応じて / 非開示）
- **変更通知**（事前通知期間 / 通知なし）
- **異議申立権**（拒否権 / 通知・解約権 / 通知のみ / なし）

**個人情報保護法（APPI）第25条：** 委託先の監督義務。個人データの取扱いを委託する場合、委託先に対する必要かつ適切な監督を行わなければならない。サブプロセッサーの管理体制がこの義務を満たしているか確認する。

#### 6. サービス変更・機能廃止

- **重大な不利益変更**（解約権 / 通知のみ / 無制限）
- **機能廃止の通知期間**
- **代替機能の提供条件**（同一価格帯 / より高額）

#### 7. 利用規約の一方的変更

- **ベンダーによる一方的な規約変更権の有無**
- **変更通知の方法と期間**
- **変更に同意しない場合の解約権**
- **定型約款（民法第548条の2-第548条の4）の適用可能性**

### ステップ4: AI/ML条項の分析

SaaS契約における最重要交渉ポイント。単純な有無チェックではなく、以下の7次元で分析する：

1. **明示的な許諾。** 契約がベンダーに顧客データ/コンテンツ/利用データをAIトレーニング、モデル改善、ML開発に使用する権利を明示的に付与しているか。
2. **ポリシー経由の黙示的許諾。** 契約がベンダーのプライバシーポリシーや利用規約を準用しているか。ベンダーは一方的なポリシー更新でトレーニング権を追加できるか。「サービス改善」や「分析」のキャッチオール、「利用データ」の定義で顧客データ定義から除外されるログやテレメトリに注意。
3. **匿名化基準。** ベンダーが「匿名化」「集計」データでのみトレーニングすると主張する場合、基準は何か。定義なしの「匿名化」は弱い。
4. **競合他社への情報流出。** ベンダーが競合他社にもサービス提供している場合、自社データでのトレーニングが競合に有利な出力を生む可能性。
5. **オプトアウトの範囲と持続性。** オプトアウトがある場合、すべてのAI利用をカバーするか。更新・規約変更後も有効か。
6. **出力の帰属。** SaaS製品自体がAI生成型（ドラフト、要約、分析）の場合、出力の著作権帰属。著作権法第2条第1項第1号の「思想又は感情を創作的に表現したもの」との関係。
7. **AI事業者ガイドライン。** 経済産業省「AI事業者ガイドライン」との整合性。

### ステップ5: 日本法固有チェック

#### データ越境移転（APPI第28条）

外国にある第三者への個人データの提供に関する規制：
- 個人データの保管・処理サーバーの所在地
- サブプロセッサーの所在国
- 相当措置（APPI第28条第1項各号）の充足
  - 本人の同意
  - APPI相当の個人情報保護制度を有する国（個人情報保護委員会が指定）
  - 基準に適合する体制の整備
- データローカライゼーション要件の有無

#### 外部送信規律（電気通信事業法第27条の12）

2023年6月施行の外部送信規律：
- SaaSがウェブサイトやアプリを通じてサービスを提供する場合、利用者の端末から外部に送信される情報の取扱い
- 送信先、送信される情報の内容、利用目的の通知・公表
- Cookie、タグ、SDK等の外部送信の有無

#### 反社会的勢力排除条項

三要素（表明保証・誓約・解除）の充足を確認。SaaS契約でも反社排除条項は必須。

#### 印紙税

SaaS契約は通常、電子契約であれば印紙税非課税。紙の契約書の場合は契約類型に応じて判定。

### ステップ6: エスカレーションルーティング

vendor-agreement-reviewと同じエスカレーションマトリクスを適用。SaaS固有の自動エスカレーション項目：
- データの国外移転（APPI第28条）に関する重大な懸念
- AI/MLトレーニング権の明示的付与
- 利用規約の一方的変更権（合理的な制限なし）
- データ削除・返還条項の欠如

## 弁護士確認ゲート

vendor-agreement-reviewと同じゲートを適用。署名または修正案送付の前に、非弁護士ユーザーに対して弁護士確認を求める。

## ハンドオフ

**renewal-trackerへ:** 更新日と通知期間を検出した場合、ハンドオフする。

```yaml
counterparty:         [名前]
agreement:            [タイトル]
signed_date:          [ISO日付]
initial_term_end:     [ISO日付]
renewal_mechanism:    [例：「自動更新 年次」]
notice_period_days:   [整数]
cancel_by_effective:  [ISO日付]
price_on_renewal:     [契約書の記載どおり]
annual_value:         [整数]
business_owner:       [メールアドレス]
status:               active
```

**escalation-flaggerへ:** SaaS固有チェックで「絶対に受け入れない」または自動エスカレーション項目に該当した場合、escalation-flaggerにルーティングする。

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- SaaS契約のドラフトは行わない。レビューと修正提案のみ。
- SLAのビジネス判断は行わない（このサービスが事業上クリティカルかどうかは事業部門が判断する）。
- DPA（データ処理契約）の詳細レビューは行わない。プライバシー関連の詳細は `/privacy-legal-jp:dpa-review`（インストール済みの場合）にルーティングする。
- 下請法の詳細チェックは行わない。`/commercial-legal-jp:shitauke-ho-check` にルーティングする。
