# /shitauke-ho-check

下請法（下請代金支払遅延等防止法）に基づくコンプライアンスチェックを実行します。

## 目的

下請法は、親事業者と下請事業者の間の取引における不公正な行為を防止するための法律です。このスキルは、契約書または取引概要から下請法の適用有無を判定し、適用される場合は禁止行為のスクリーニングと書面要件の確認を行います。

## ワークフロー

### ステップ1: 設定の読み込み

`~/.claude/plugins/config/claude-for-legal/commercial-legal-jp/CLAUDE.md` を読み込む。プレースホルダーが存在する場合は停止し、セットアップを促す。

以下を抽出：
- 自社の資本金
- 下請法コンプライアンス体制の現状
- 業種と主な取引類型

### ステップ2: 取引当事者の資本金確認

契約書または取引概要から以下を特定：
- **親事業者（発注者）の資本金**
- **下請事業者（受注者）の資本金**

自社がどちらの立場かを特定する。契約書に資本金の記載がない場合、ユーザーに確認する。

### ステップ3: 取引類型の判定

以下の4つの取引類型のいずれに該当するかを判定：

| 取引類型 | 定義 | 典型例 |
|---|---|---|
| **製造委託** | 物品の製造を委託する取引 | 部品の製造委託、OEM製造 |
| **修理委託** | 物品の修理を委託する取引 | 機械の修理、メンテナンス委託 |
| **情報成果物作成委託** | ソフトウェア、映像、デザイン等の情報成果物の作成を委託する取引 | システム開発、ウェブサイト制作、広告制作 |
| **役務提供委託** | 運送、ビルメンテナンス、コールセンター等の役務の提供を委託する取引 | 運送委託、清掃委託、カスタマーサポート委託 |

### ステップ4: 資本金区分による適用判定

取引類型に応じた資本金基準を適用：

**製造委託・修理委託の場合：**

| 親事業者の資本金 | 下請事業者の資本金 | 適用 |
|---|---|---|
| 3億円超 | 3億円以下（個人含む） | 適用あり |
| 1千万円超〜3億円以下 | 1千万円以下（個人含む） | 適用あり |
| 上記以外 | --- | 適用なし |

**情報成果物作成委託・役務提供委託の場合：**

| 親事業者の資本金 | 下請事業者の資本金 | 適用 |
|---|---|---|
| 5千万円超 | 5千万円以下（個人含む） | 適用あり |
| 1千万円超〜5千万円以下 | 1千万円以下（個人含む） | 適用あり |
| 上記以外 | --- | 適用なし |

**判定結果を明示する：**
- 適用あり → ステップ5以降に進む
- 適用なし → その旨を報告し、根拠を説明して終了
- 判定不能（資本金情報不足） → 必要な情報を特定して確認を求める

### ステップ5: 禁止行為のスクリーニング

契約書の条項を以下の11の禁止行為に照らしてスクリーニング：

| # | 禁止行為 | チェックポイント | 条文 |
|---|---|---|---|
| 1 | **受領拒否** | 正当な理由なく受領を拒否する条項はないか | 第4条第1項第1号 |
| 2 | **代金の支払遅延** | 支払期日は物品等の受領日から60日以内か | 第4条第1項第2号 |
| 3 | **代金の減額** | 正当な理由なく代金を減額する条項はないか | 第4条第1項第3号 |
| 4 | **返品** | 正当な理由なく返品する条項はないか | 第4条第1項第4号 |
| 5 | **買いたたき** | 通常の対価に比べて著しく低い対価ではないか | 第4条第1項第5号 |
| 6 | **購入・利用強制** | 正当な理由なく自社の製品・サービスの購入を強制していないか | 第4条第1項第6号 |
| 7 | **報復措置** | 公正取引委員会への申告を理由とする不利益取扱いはないか | 第4条第1項第7号 |
| 8 | **有償支給原材料等の対価の早期決済** | 原材料代を下請代金から控除する条件は適切か | 第4条第2項第1号 |
| 9 | **割引困難な手形の交付** | 手形サイトは120日以内か（繊維業は90日以内） | 第4条第2項第2号 |
| 10 | **不当な経済上の利益の提供要請** | 金銭、労務等の不当な提供を求めていないか | 第4条第2項第3号 |
| 11 | **不当な給付内容の変更・やり直し** | 正当な理由なく仕様変更・やり直しを求める条項はないか | 第4条第2項第4号 |

各項目について：
- **適合:** 問題なし
- **要注意:** 条文の趣旨に照らして懸念がある → `[review]` タグを付与
- **違反の可能性:** 明確に禁止行為に該当する可能性 → 重要度 HIGH で報告

### ステップ6: 3条書面（発注書面）の記載要件チェック

下請法第3条に基づく発注書面の記載要件を確認：

| # | 必須記載事項 | 確認 |
|---|---|---|
| 1 | 親事業者と下請事業者の商号・名称・事業者別に付された番号等 | |
| 2 | 製造委託等をした日 | |
| 3 | 下請事業者の給付の内容 | |
| 4 | 下請事業者の給付を受領する期日 | |
| 5 | 下請事業者の給付を受領する場所 | |
| 6 | 下請事業者の給付の内容について検査をする場合は、検査を完了する期日 | |
| 7 | 下請代金の額 | |
| 8 | 下請代金の支払期日 | |
| 9 | 手形を交付する場合は、手形の金額と満期 | |
| 10 | 一括決済方式で支払う場合は、金融機関名等 | |
| 11 | 電子記録債権で支払う場合は、電子記録債権の額と満期日 | |
| 12 | 原材料等を有償支給する場合は、品名、数量、対価、引渡日、決済期日、決済方法 | |

欠落している項目を列挙し、補完の必要性を報告する。

### ステップ7: 60日以内支払ルールの確認

- 支払期日が受領日（検収完了日ではなく受領日）から起算して60日以内に設定されているか確認
- 検収期間が設定されている場合、検収完了後ではなく受領日から60日以内であることを確認
- 月締め・翌月末払い等の支払サイトが60日ルールを遵守しているか確認

**注意:** 「検収後60日以内」は違反の可能性がある。受領日から60日が起算点。

### ステップ8: 5条書類（取引記録）の保存義務確認

- 取引記録（5条書類）の作成・保存体制が整っているか確認
- 保存期間は2年間であることを確認
- 電子的な保存が認められることを説明

## 使用例

```
/commercial-legal-jp:shitauke-ho-check 業務委託契約書_ABC社.pdf
```

```
/commercial-legal-jp:shitauke-ho-check
当社（資本金5億円）がB社（資本金3000万円）にシステム開発を委託する取引です。
```
