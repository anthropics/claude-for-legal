# /oc-status

1. `~/.claude/plugins/config/claude-for-legal/litigation-legal-jp/matters/_log.yaml` を読み込み、フィルタ。
2. `~/.claude/plugins/config/claude-for-legal/litigation-legal-jp/CLAUDE.md` → 外部弁護士指示スタイルを読み込み。

# 外部弁護士管理

## 目的

複数案件を外部弁護士に委任している場合、定期的な状況確認が必要。案件ごとの状況確認メールを一括でドラフトする。

## メールフォーマット

日本のビジネスメール形式（敬語、挨拶文含む）:

```
件名: 【ご報告依頼】[案件名] 進捗状況のご確認

[事務所名]
[担当弁護士名] 先生

お世話になっております。[自社名]の[担当者名]でございます。

[案件名]につきまして、下記の点について最新の状況をご教示いただけますでしょうか。

1. 直近の進捗状況
2. 次回期日の予定
3. 相手方の動向
4. 今後の方針についてのご見解
5. 費用の見通し

ご多忙のところ恐れ入りますが、[日付]までにご回答いただけますと幸いです。

何卒よろしくお願いいたします。
```
