# 証人尋問準備 / 陳述書作成支援

## 日本の証人尋問制度

**米国のdeposition（証言録取）は日本に存在しません。** 日本の証人尋問（民事訴訟法第190条-第206条）は法廷で裁判官の主導のもとに行われます。

### 証人尋問の流れ（民事訴訟規則第113条-第133条）

1. **陳述書の提出** — 証人の供述内容を書面化（実務上ほぼ必須）
2. **主尋問** — 申出をした当事者による尋問（民訴規則第113条第2項）
3. **反対尋問** — 相手方による尋問
4. **再主尋問** — 必要に応じて
5. **裁判官による補充尋問** — 裁判官が職権で質問（民訴法第202条第1項）

### 尋問のルール

- **誘導尋問:** 主尋問では原則禁止、反対尋問では許容（民訴規則第115条）
- **異議:** 尋問の形式・内容に対する異議（民訴規則第115条第2項-第3項）
- **書面による尋問に代わる方法:** 裁判所が相当と認めるとき（民訴法第205条）

## モード

ユーザーに確認:
- **主尋問準備** — 自方の証人に対する主尋問の準備
- **反対尋問準備** — 相手方証人に対する反対尋問の準備
- **陳述書作成支援** — 証人の陳述書ドラフトの支援

### 主尋問準備

1. 要件事実チャート（`/litigation-legal-jp:youken-jijitsu-chart`）を参照し、この証人が立証すべき事実を特定
2. 立証すべき事実ごとに質問を構成
3. 誘導尋問にならない質問形式（「〇〇について教えてください」「どのような経緯でしたか」）
4. 文書の提示順序を計画

### 反対尋問準備

1. 相手方証人の陳述書・過去の供述を分析
2. 弾劾材料（矛盾する供述、客観証拠との不整合）を特定
3. 誘導尋問の形式で質問を構成（「〇〇ということですね？」）
4. 弾劾のタイミングと順序を計画

### 陳述書作成支援

**重要:** AIが証人の供述を創作することはしません。以下を支援します:
- 証人から聴取すべき事項のチェックリスト作成
- 証人が口述した内容の整理・構成
- 要件事実に照らした網羅性チェック
- 客観的証拠との整合性確認

> ⚠️ 陳述書は証人自身の言葉で作成されるべきものです。AIが証人の記憶や供述を創作・補完することはありません。証人の実際の供述を聴取し、それを整理・構成する支援のみ行います。
