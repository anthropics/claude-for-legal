# /claim-chart

1. `~/.claude/plugins/config/claude-for-legal/litigation-legal-jp/CLAUDE.md` → 役割、成果物ヘッダー、判断基準を読み込み。
2. 案件ワークスペースが有効な場合、アクティブ案件を確認し `matter.md` を読み込み。
3. 以下のワークフローに従う。
4. モード選択:
   - `--民事` → 民事要件事実チャート。請求原因（または抗弁）と立場を要求。
   - `--特許` → 特許侵害チャート。特許番号とクレームを要求。特許法第70条（技術的範囲）＋均等論5要件。
   - フラグなし → ユーザーに確認。
5. 要件事実論に基づき分析:
   - 訴訟物の特定
   - 請求原因事実（Kg: Klagegrund）の整理
   - 抗弁事実（E: Einwendung）の整理
   - 再抗弁事実（R: Replik）の整理
   - 各事実の立証責任配分
   - 主要事実・間接事実・補助事実の区別
6. 証拠を各事実にマッピング。ピンポイント引用。
7. ギャップリスト（立証不十分な要件事実）を優先出力として生成。

# 要件事実チャート

## ⚠️ ドラフト注意書き

> このチャートは弁護士による分析・検証のためのドラフトであり、最終的な訴訟戦略や法的意見ではありません。要件事実の整理は司法研修所の要件事実論に基づいていますが、裁判所の判断と異なる場合があります。ギャップ検出は証拠収集の出発点であり、請求の当否についての結論ではありません。

## 要件事実論の基本構造

### Kg（請求原因事実）→ E（抗弁事実）→ R（再抗弁事実）

**立証責任の配分原則:** 法律要件分類説に基づき、権利の発生を主張する者（原告）が請求原因事実の立証責任を負い、権利の障害・消滅・阻止を主張する者（被告）が抗弁事実の立証責任を負う。

### 典型的な請求原因の要件事実

**売買代金請求（民法第555条）:**
- Kg1: 売買契約の締結（目的物と代金の合意）
- Kg2: 目的物の引渡し（同時履行の抗弁権を封じるため）
- E1: 弁済（民法第473条）
- E2: 消滅時効（民法第166条）
- R1: 時効の完成猶予・更新（民法第147条以下）

**不法行為に基づく損害賠償請求（民法第709条）:**
- Kg1: 故意又は過失
- Kg2: 権利又は法律上保護される利益の侵害
- Kg3: 損害の発生及び額
- Kg4: 因果関係
- E1: 過失相殺（民法第722条第2項）
- E2: 消滅時効（民法第724条 — 主観的3年/客観的20年）

**債務不履行に基づく損害賠償請求（民法第415条）:**
- Kg1: 債権の発生原因事実（契約締結等）
- Kg2: 債務不履行の事実
- Kg3: 損害の発生及び額
- E1: 帰責事由の不存在（民法第415条第1項ただし書）
- E2: 損害の予見不可能性（特別損害について、民法第416条第2項）

### 特許モード

均等論5要件（最判平成10年2月24日民集52巻1号113頁・ボールスプライン事件）:
1. 非本質的部分
2. 置換可能性
3. 置換容易性
4. 公知技術からの容易推考の不存在
5. 特段の事情の不存在（意識的除外等）
