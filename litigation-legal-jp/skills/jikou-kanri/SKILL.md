# 時効管理

## 目的

消滅時効の管理は訴訟実務において最も重要なリスク管理項目の一つ。時効の完成（=権利の消滅を主張できる状態）により、請求権を失うリスクがある。2020年民法改正で消滅時効の体系が大幅に変更されたため、改正前後の整理が不可欠。

## 2020年改正民法の消滅時効（2020年4月1日施行）

### 一般の消滅時効（民法第166条第1項）

| 起算点 | 期間 | 通称 |
|---|---|---|
| 権利を行使することができることを知った時 | 5年 | 主観的起算点 |
| 権利を行使することができる時 | 10年 | 客観的起算点 |

いずれか早い方の経過により時効が完成する（二重期間制）。

### 特殊な消滅時効

| 請求類型 | 期間 | 根拠 |
|---|---|---|
| 不法行為（一般） | 主観的3年/客観的20年 | 民法第724条 |
| 生命・身体侵害の不法行為 | 主観的5年/客観的20年 | 民法第724条の2 |
| 生命・身体侵害の債務不履行 | 主観的5年/客観的20年 | 民法第167条 |
| 人の生命又は身体の侵害による損害賠償請求権 | 主観的5年/客観的20年 | 民法第167条・第724条の2 |
| 定期金債権 | 各支払期から主観的5年/客観的10年 | 民法第168条 |

### 特別法の時効

| 請求類型 | 期間 | 根拠 |
|---|---|---|
| 賃金請求権 | 当分の間3年（本則5年） | 労働基準法第115条 |
| 退職金請求権 | 5年 | 労働基準法第115条 |
| 商行為の債権 | 5年 | 商法第522条（改正前。改正後は民法に統一） |
| 手形・小切手 | 振出人3年/裏書人1年 | 手形法第70条等 |
| 保険金請求権 | 3年 | 保険法第95条 |

## 時効の完成猶予・更新（2020年改正）

### 完成猶予事由（時効の完成を一時的に止める）

| 事由 | 効果 | 根拠 |
|---|---|---|
| 裁判上の請求 | 事由終了時まで + 6ヶ月 | 民法第147条第1項 |
| 支払督促 | 事由終了時まで + 6ヶ月 | 民法第147条第1項 |
| 民事調停・家事調停 | 事由終了時まで + 6ヶ月 | 民法第147条第1項 |
| 仮差押え・仮処分 | 事由終了時から6ヶ月 | 民法第149条 |
| 催告 | 催告時から6ヶ月 | 民法第150条 |
| 協議を行う旨の合意（書面） | 合意時から1年（又は定めた期間） | 民法第151条 |
| 天災等 | 障害消滅時から3ヶ月 | 民法第161条 |

### 更新事由（時効期間をリセットする）

| 事由 | 効果 | 根拠 |
|---|---|---|
| 確定判決等 | 時効期間がリセット（新たに10年） | 民法第169条 |
| 権利の承認 | 時効期間がリセット | 民法第152条 |
| 強制執行等の終了 | 時効期間がリセット | 民法第148条 |

## ワークフロー

1. **請求類型の特定** — 何の請求権か
2. **起算点の特定** — いつから時効が進行するか
3. **時効期間の確定** — 何年か（改正前/改正後の適用関係を含む）
4. **完成猶予・更新事由の確認** — 時効の進行に影響する事由があるか
5. **残存期間の計算** — いつまでに法的措置を取る必要があるか
6. **アラート** — 🔴 6ヶ月以内 / 🟠 1年以内 / 🟡 2年以内

## 経過措置（改正法附則第10条）

施行日（2020年4月1日）前に債権が生じた場合 → **旧法適用**
施行日以後に債権が生じた場合 → **新法適用**
