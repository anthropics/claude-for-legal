# 証拠説明書

## 目的

証拠説明書は、提出する書証の内容と立証趣旨を裁判所と相手方に示す書面。民事訴訟規則第137条に基づき、書証の申出をするときは証拠説明書を提出しなければならない。

## ⚠️ 弁護士確認ゲート

証拠の整理は訴訟戦略に直結します。弁護士以外のユーザーの場合:

> ⚠️ **弁護士確認ゲート:** 証拠説明書の作成には弁護士の判断が必要です。

## 証拠説明書のフォーマット

| 号証 | 標目 | 原本/写し | 作成日 | 作成者 | 立証趣旨 | 備考 |
|---|---|---|---|---|---|---|
| 甲第1号証 | [文書名] | [原本/写し] | [YYYY年M月D日] | [作成者名] | [この書証で何を立証するか] | |
| 甲第2号証 | | | | | | |

- **原告側:** 甲号証（甲第1号証、甲第2号証…）
- **被告側:** 乙号証（乙第1号証、乙第2号証…）
- 枝番: 甲第1号証の1、甲第1号証の2…

## 立証趣旨の書き方

立証趣旨は、その書証が要件事実のどの部分を立証するために提出するかを簡潔に記載する。

**良い例:**
- 「原告と被告との間で令和〇年〇月〇日に売買契約が締結されたこと」
- 「被告が令和〇年〇月〇日時点で本件商品の瑕疵を認識していたこと」

**悪い例:**
- 「本件の経緯」（漠然すぎる）
- 「被告の不正行為」（法的評価であり事実ではない）

## 二段の推定（民事訴訟法第228条第4項）

私文書の成立の真正の推定:
1. **第一段の推定:** 文書に本人の印章による印影がある → 本人の意思に基づく押印と事実上推定
2. **第二段の推定:** 本人の意思に基づく押印がある → 文書全体が真正に成立したと推定（民訴法第228条第4項）

**反証の方法:**
- 印章の盗用・冒用
- 白紙に押印後の文書作成
- 印影の偽造

## 電子データの証拠能力

- メール: 送受信記録、ヘッダー情報の保全が重要
- チャット（Slack、LINE等）: スクリーンショットでは証拠力が弱い。エクスポートデータが望ましい
- 電子署名付き文書: 電子署名法第3条による推定
- ウェブサイト: アーカイブサービス（Wayback Machine等）による保全、スクリーンショットの日時記録
