# /matter-workspace

1. `~/.claude/plugins/config/claude-for-legal/litigation-legal-jp/CLAUDE.md` → `## 案件ワークスペース` を確認。
2. `有効` が `✗` の場合: 企業内弁護士設定のため案件ワークスペースは不要と説明。
3. サブコマンドに応じて実行:
   - `new` → 案件作成、`matter.md` 作成
   - `list` → 案件一覧表示
   - `switch` → アクティブ案件の切替
   - `close` → 案件のアーカイブ（削除はしない）
   - `none` → アクティブ案件の解除

# 案件ワークスペース

法律事務所の弁護士は複数のクライアント・案件にまたがって業務を行う。案件ワークスペースは、あるクライアントのコンテキストが別のクライアントに漏れないようにする。

**デフォルトは無効。** 企業内弁護士はこの機能を使用しない。案件ワークスペースはコールドスタートで法律事務所向けに有効化される。
