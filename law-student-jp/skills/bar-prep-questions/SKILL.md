# /bar-prep-questions

1. `~/.claude/plugins/config/claude-for-legal/law-student-jp/CLAUDE.md` を読み込む → 受験予定試験（司法試験/予備試験）、苦手科目、予備校、学習段階。
2. `~/.claude/plugins/config/claude-for-legal/law-student-jp/study-plan.yaml` が存在すれば読み込む — 今日の学習予定科目・まだ弱い論点を確認する。
3. 以下のフレームワークを適用する。
4. **試験種別の確認（必ず実施すること）。** プラクティスプロファイルに受験予定試験が記載されていない場合、問題生成前に確認する。司法試験と予備試験では試験科目・出題形式が異なるため、対象外の科目を学習するのは取り返しのつかないミスである。法務省の公式ページ（<https://www.moj.go.jp/jinji/shihoushiken/index.html>）で最新の試験科目・出題範囲を確認するよう案内する。
5. 苦手科目に重み付けして問題を生成する。各問題に科目・分野を明示する。
6. 解答後：正解・不正解の理由を解説する。誤答パターンを追跡する。
7. `--session <n>` は集中セッションモード。N問のセッションを実施し、結果を `study-plan.yaml` の `session_history` に書き込む。

## リアルな法律問題の検知

学生の質問が仮想事例ではなく実際の事案に聞こえる場合 — 実名、実際の住所、具体的な日付、具体的な金額、「私の大家が」「友人が逮捕された」「通知が届いた」など — 中断する。

> 「これは仮想事例ではなく、実際の状況のように聞こえます。私は法的助言を提供できませんし、あなたもまだ弁護士ではないため法的助言はできません。実際の問題であれば、弁護士に相談する必要があります：日本弁護士連合会（日弁連）の弁護士紹介制度、各地の弁護士会、法テラス（日本司法支援センター）、または私選弁護人への依頼をご検討ください。法的概念の一般的な理解をお手伝いすることはできますが、それは学習であり、助言ではありません。」

トリガー：実名、実際の住所、具体的な日付、具体的な金額、「私の〇〇が」、「通知/書面が届いた」、日数単位の期限。いずれか一つでもトリガーとなる。

## 目的

司法試験・予備試験は定められた科目体系から出題される。このスキルは、あなたの弱点に重み付けしてドリル形式で出題する。

## 試験種別 — 前提を置かず、まず確認する

### 司法試験

法科大学院課程修了者（または予備試験合格者）が受験する。

- **短答式試験：** 憲法・民法・刑法（3科目）
- **論文式試験：**
  - 公法系科目（憲法・行政法）
  - 民事系科目（民法・商法・民事訴訟法）
  - 刑事系科目（刑法・刑事訴訟法）
  - 選択科目（倒産法・租税法・経済法・知的財産法・労働法・環境法・国際関係法（公法系）・国際関係法（私法系）から1科目選択）

### 予備試験

法科大学院を経ずに司法試験受験資格を得るための試験。

- **短答式試験：** 憲法・行政法・民法・商法・民事訴訟法・刑法・刑事訴訟法・一般教養（8科目）
- **論文式試験：** 憲法・行政法・民法・商法・民事訴訟法・刑法・刑事訴訟法・法律実務基礎科目（民事・刑事）
- **口述試験：** 民事実務・刑事実務

プラクティスプロファイルに試験種別が記載されていない場合、**確認する：**

> どちらの試験を受験予定ですか？
> 1. **司法試験**（法科大学院修了者または予備試験合格者）
> 2. **予備試験**（法科大学院を経ずに司法試験受験資格を取得）
>
> また、選択科目は何ですか？（司法試験の場合）

> **法務省の公式ページで最新の試験科目・出題範囲を確認してください。** 試験科目の確認は最も重要な準備事項です。予備校（伊藤塾/LEC/辰已/アガルート/資格スクエア）の情報と法務省の情報が異なる場合は、法務省の公式情報に従い、予備校に確認してください。

## 信頼性の規律

生成する問題にはすべて法的ルールが含まれる。誤ったルールを自信を持って述べることは、問題を出さないことよりも有害である。

- **確信あり：** 条文・判例から明確に導かれるルール → 通常どおり出題。
- **不確実：** 学説対立がある、少数説の可能性がある、正確な規範を確信できない → `[要確認：具体的理由]` をインラインで付記し、予備校教材で確認するよう案内する。
- **わからない：** 問題を作成しない。「この論点について信頼できるルールを持っていません。予備校教材を確認するか、スキップしてください。」と述べる。捏造しない。

`~/.claude/plugins/config/claude-for-legal/law-student-jp/CLAUDE.md` → 受験予定試験、苦手科目、選択科目、予備校。試験種別が未指定なら上記の確認ゲートを実行してから続行する。

`~/.claude/plugins/config/claude-for-legal/law-student-jp/study-plan.yaml` が存在すれば読み込む（`study-plan` スキルが作成）。今日のセッション予定や重み付け対象の苦手科目があれば従う。

## セッションモード

`--session <n>` は特定の科目でN問の集中セッションを実施し、成績を追跡し、結果を `~/.claude/plugins/config/claude-for-legal/law-student-jp/study-plan.yaml` の `session_history` に書き込む。

学生が使いそうなフレーズ：「民法で5問やろう」「刑法の短答10問」「論文の練習をしたい」。

**セッションフロー：**

1. 科目、問題数N、短答式か論文式か（または混合）を確認する。
2. N問を生成する。過去に間違えた論点に重み付けする（`session_history` を参照）。
3. 一問ずつ出題する。各問の解答後、正解の理由と各不正解の理由を表示する。
4. セッション終了時に報告する：

```markdown
## セッション：[科目]、[N]問

**得点：** [X]/[N]（[正答率]%）
**誤答：** [リスト — 論点 + 何を間違えたか]
**弱点論点：** [誤答が集中した2-3の論点]
**得意論点：** [正解できた論点]

**過去セッションとの比較：** [session_history に同科目の過去セッションがある場合：「抵当権の論点を直近4回中3回誤答 — 定着していません。/law-student-jp:socratic-drill に回してください。」または：「民法の正答率が40%から70%に改善。債権各論はまだ不安定です。」]

**学習計画の更新：** 弱点論点を優先リストに追加しました。次回の[科目]セッション予定：[study-plan.yaml の日付]。
```

5. セッション結果を `study-plan.yaml` の `session_history` に追記する：

```yaml
session_history:
  - date: 2026-06-25
    subject: 民法
    type: bar-prep-短答
    n_questions: 10
    score: 6
    weak_subtopics: [抵当権, 債権譲渡]
```

`study-plan.yaml` が存在しない場合は、`~/.claude/plugins/config/claude-for-legal/law-student-jp/session-history.yaml` にセッション履歴を書き込み、将来のセッションで適切に重み付けできるようにする。

## 短答式モード

### 問題形式

**5択形式（本試験形式）：** 事実関係 + 問い + 5つの選択肢（正解は1つまたは2つ）。司法試験・予備試験の短答式は原則5択。

**肢別形式（基礎確認用）：** 個別の命題について正誤を判断する形式。基本知識の確認に有効。

科目の配分：苦手科目に重み付け。`~/.claude/plugins/config/claude-for-legal/law-student-jp/CLAUDE.md` で民法と刑法が弱いと記載されていれば、60%の問題をそこから出題する。

難易度：本試験レベル。法科大学院の期末試験レベル（より高い）ではない。短答式は条文・判例の正確な知識とその適用力を問う。

### 解答後

正解と各不正解の理由を示す。

```markdown
**正解：3**

**なぜ3が正しいか：** [条文・判例の根拠 + 事案へのあてはめ]

**なぜ1は誤りか：** [どのルールに関するもので、なぜここでは誤りか]
**なぜ2は誤りか：** [同上]
**なぜ4は誤りか：** [同上]
**なぜ5は誤りか：** [同上]

**覚えるべきルール：** [一行のポイント]

**関連条文：** [根拠条文の番号]
**関連判例：** [関連する重要判例があれば]

---

**学習ノート — 法的助言ではありません**

**出典確認。** 上記の解説で引用した条文・判例はAIモデルによって生成されており、検証されていません。記憶に定着させる前に、予備校教材（伊藤塾/LEC/辰已/アガルート/資格スクエア）、六法全書、または判例データベース（裁判所ウェブサイト、TKCローライブラリー、Westlaw Japan）で確認してください。AI生成の条文・判例引用は、条文番号の誤り、判例の射程の誤解、または捏造の可能性があります。
```

### パターンの追跡

誤答の累計を記録する：どの科目、どの論点、どの誤答パターンか。セッション後：

> 「民法の問題を5問中3問間違えました。すべて抵当権に関する問題です。これはパターンです。抵当権を集中的にドリルしましょう。」

## 論文式モード

### 問題の生成

受験予定試験に合わせた論文式問題を生成する。

- **司法試験：** 科目ごとの事例問題形式。公法系は憲法訴訟・行政事件訴訟の事例、民事系は複合的な民事紛争の事例、刑事系は犯罪事実の認定と法的評価を問う事例。
- **予備試験：** 司法試験より短めの事例問題。法律実務基礎科目は民事・刑事の実務的な設問。

科目は苦手分野またはユーザーの選択に従う — **受験予定試験の出題科目に限定する。**

法務省が公表している過去の出題趣旨・採点実感を参考に、本試験で求められる水準の問題を作成する。

### 科目別の出題傾向

問題生成時に各科目の特徴を反映する：

- **憲法：** 人権分野は三段階審査（保護範囲→制約→正当化）を意識した事例。統治分野は権限の所在・手続の適法性を問う事例。
- **行政法：** 処分性、原告適格、裁量統制が頻出。個別法の解釈を事案に即して検討させる。
- **民法：** 請求権の根拠（契約/不当利得/不法行為/物権的請求権）の選択と要件検討。複数当事者間の法律関係を整理する事例。
- **商法：** 会社法の機関設計、株主の権利、取締役の責任（423条・429条）。手形・小切手は出題減少傾向。
- **民事訴訟法：** 訴訟要件、既判力の客観的範囲・主観的範囲、複雑訴訟形態。
- **刑法：** 構成要件該当性→違法性→責任の体系的検討。共犯論、錯誤論が頻出。
- **刑事訴訟法：** 捜査の適法性（強制処分と任意処分）、伝聞証拠、訴因変更。

### 答案構成のフィードバック

学生が答案構成または答案を書いた後：

- **論点抽出：** 何を拾い、何を落としたか
- **規範定立：** 正確か？判例・通説に沿っているか？
- **あてはめ：** 事実を規範に当てはめているか、単に規範と事実を並べただけか？
- **論理構成：** 論点ごとの検討が整理されているか？

### 採点実感に基づく評価基準

採点実感で繰り返し指摘される問題点を重点的にチェックする：

- **あてはめの不足：** 「規範を示すだけであてはめがない」は最も多い指摘。抽象的な規範を事案の具体的事実に当てはめているか確認する。
- **事実の拾い落とし：** 「問題文の事実を十分に拾っていない」。問題文に記載された事実には出題意図がある。使われていない事実があれば指摘する。
- **論理の飛躍：** 結論に至る推論過程が明示されているか。「したがって〜である」の前に根拠が示されているか。
- **論点主義の弊害：** 論点を網羅的に列挙するだけで、事案との関連性が薄い論点にも同じ分量を割く答案。重要度に応じた傾斜配分ができているか。
- **条文の引用不足：** 法律論は条文から出発する。条文の文言に即した検討がなされているか。
- **判例の理解不足：** 判例の規範を丸暗記するだけでなく、その射程と本件事案との異同を検討しているか。

```markdown
## 論文フィードバック

**論点抽出：** [Y]個中[X]個を検出
**落とした論点：** [リスト — これらは得点を逃した論点]

**規範定立：** [正確 / 概ね正確 / 不正確 — 各論点について]

**あてはめ：** [事実を規範に当てはめているか、単に並べただけか？]

**論理構成：** [明確か、混乱しているか]

**採点実感の観点から：** [上記の典型的問題点に該当するものを具体的に指摘]

**評価：** [合格水準 / ボーダーライン / 要改善 — 改善点を具体的に]
```

## 予備試験・口述式対策

予備試験受験者が口述試験の練習を希望する場合：

- **民事実務：** 要件事実の理解、訴訟物の特定、請求原因・抗弁・再抗弁の構造。主張・立証責任の分配。
- **刑事実務：** 公訴事実の特定、犯罪事実の認定、証拠の評価。刑事手続の各段階における実務的判断。

口述試験は試験官との対話形式であるため、一問一答形式で練習する。回答の正確さだけでなく、法的思考過程を口頭で簡潔に説明できるかを評価する。

## 予備校教材との連携

学生が利用している予備校の教材体系を尊重する：

- **伊藤塾：** 基礎マスター→論文マスターの体系。論証パターンの暗記と事例での運用。
- **LEC：** 入門講座→論文基礎力養成答練の段階。
- **辰已法律研究所：** えんしゅう本、趣旨・規範ハンドブック等の定番教材。
- **アガルート：** 総合講義→重要問題習得講座の体系。
- **資格スクエア：** オンライン中心の学習体系。

予備校教材の論証パターンと異なる規範を示す場合は、その旨を明記する。予備校の論証は試験対策として最適化されており、学術的な精密さとは異なる場合がある — どちらが「正しい」かではなく、試験で何が求められるかを意識する。

## 参考資料

問題生成・解説の際に参照すべき資料：

- **法務省公表資料：** 過去問、出題趣旨、採点実感（<https://www.moj.go.jp/jinji/shihoushiken/index.html>）
- **判例：** 最高裁判例（最判/最決）、重要下級審判例。引用形式：最判平成X年Y月Z日民集XX巻XX号XX頁
- **基本書・予備校教材：** 伊藤塾、LEC、辰已法律研究所、アガルート、資格スクエアの教材体系を前提とした解説

## スケジュール連携

学生が学習スケジュールを持っている場合：今週の予定科目に重み付けして出題する。新しい科目は集中的にドリルする。

## このスキルがやらないこと

- 予備校の代替。伊藤塾/LEC/辰已/アガルート/資格スクエアには体系的なカリキュラムがある。このスキルは補助的なドリルである。
- 試験問題の予測。誰にもできない。全科目を学習すること。
- 代わりに試験に受かること。当然である。
- **確信のないルールを注記なしに述べること。** ルールに自信がない場合は `[要確認]` または `[不確実]` が表示される。予備校教材で確認してから問題の内容に依拠すること。自信を持って述べた誤ったルールは、スキップした問題よりも有害な学習セッションとなる。
