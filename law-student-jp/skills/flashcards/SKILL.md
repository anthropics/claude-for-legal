# /flashcards

1. `~/.claude/plugins/config/claude-for-legal/law-student-jp/CLAUDE.md` を読み込み → 科目、弱点分野、アウトラインの場所を確認。
2. 以下のフレームワークを適用。
3. フラグで分岐：
   - `--generate`：ソース（アウトラインパス、ノート、教科書）からカード作成ルールに従いカードを生成。`~/.claude/plugins/config/claude-for-legal/law-student-jp/flashcards/[科目]/cards.md` に保存。
   - `--drill`（デフォルト）：復習期限到来のカード＋新規カードを優先表示。問題を表示→回答を待つ→正解を表示→自己評価→バケット・次回復習日を更新。
   - `--review`：バケット別にデッキを一覧表示。
   - `--stats`：進捗スナップショット。停滞カードを口頭ドリル用にフラグ。
   - `--session <n>`：集中N枚セッション。過去の誤答＋復習期限到来カードを優先。結果を `study-plan.yaml` → `session_history` に追記。
4. 信頼度の規律を適用：ソースなしの知識から生成したカードには `[要確認]` を付与。

## 実際の法律問題チェック

学生の質問が学習の仮想事例ではなく実際の状況に聞こえる場合 — 自分の賃貸借契約、自分の交通違反、家族の事業、友人の逮捕、具体的な金額、具体的な期限、実在の当事者名 — 一旦停止する。

> 「これは仮想事例ではなく、実際の状況のようです。私は法的助言はできませんし、あなたもまだ法曹資格がないので法的助言はできません。実際の問題であれば、弁護士に相談する必要があります：法テラス（0570-078374）、各地の弁護士会の法律相談窓口、または弁護士紹介制度をご利用ください。法的概念の一般的な理解をお手伝いすることはできますが、それは学習であって助言ではありません。」

注意サイン：実名、実住所、実際の日付、具体的な金額、「私の大家/上司/親/友人」、「通知が来た/呼び出しを受けた」、日数で計算された期限。いずれか一つでもトリガーとなる。

## 目的

アウトラインは体系的理解のため。フラッシュカードは暗記のため。司法試験・予備試験は、条文の趣旨・要件、判旨、論点の規範の素早い想起を求める。このスキルはアウトライン（またはノート・教科書抜粋）からカードを生成し、簡易的な間隔反復でドリルし、定着度を追跡する。

**本格的なSRSシステムではない。** シンプルなLeitner式バケット。学習には十分で、維持も軽い。Ankiを使いたければAnkiを使うこと。これはチャット内で素早くドリルしたいとき用。

## 信頼度の規律

他のコンテンツ生成スキルと同じルール：

- ユーザー提供のソース（アウトライン、ノート、教科書抜粋）からカードを生成する場合、カードの問題と正解はそのソースに基づく。確信度は高い。
- ソースなしの知識からカードを生成する場合、確信度の低い規範・条文・判例を含むカードには `[要確認：規範 — ソースで確認のこと]` を付与。
- 不得意な分野では、数を水増しせず少なく生成する。正確なカード8枚のほうが、5枚が誤っている20枚より良い。

## コンテキスト読み込み

- `~/.claude/plugins/config/claude-for-legal/law-student-jp/CLAUDE.md` → 科目、弱点分野、既存アウトライン
- `~/.claude/plugins/config/claude-for-legal/law-student-jp/flashcards/[科目]/cards.md` が存在する場合（増分構築）
- ユーザー提供のソース（アウトラインパス、ノート、教科書抜粋）

## モード

フラグ：`--generate | --drill | --review | --stats | --session <n>`（デフォルト：確認して分岐）

### `--session <n>` — 集中N枚セッション

学生が「民法で5枚やりたい」と言ったり `/law-student-jp:session 民法 5 --flashcards` を実行したとき用。

- `~/.claude/plugins/config/claude-for-legal/law-student-jp/study-plan.yaml` が存在すれば読み込み、該当科目の `session_history` を確認。
- 優先順位：過去に誤答したカード > 復習期限到来カード > 新規カード。
- N枚を1枚ずつ `--drill` のフローで実施。
- セッション終了時、結果を `study-plan.yaml` → `session_history` に追記：

```yaml
session_history:
  - date: 2026-06-25
    subject: 民法
    type: flashcards
    n_cards: 5
    right: 3
    partial: 1
    wrong: 1
    stuck_topics: [詐害行為取消権]
```

- `study-plan.yaml` がなければ `~/.claude/plugins/config/claude-for-legal/law-student-jp/session-history.yaml` に保存。

### `--generate` — カード生成

**入力：**
- 科目（科目名または論点）
- ソース（アウトラインパス、ノート、または「CLAUDE.mdに記録された既存アウトラインを使用」）
- オプション：生成枚数の目標（デフォルト10-20枚/セッション）

**カード構造：**

```markdown
### カード [N]
**問：** [質問 — 一概念、一カード]
**答：** [正解 — 規範・条文の趣旨・判旨、1-2文]
**出典：** [アウトラインの該当箇所、教科書のページ、判例集の引用]
**バケット：** 新規
**最終復習：** —
**次回復習：** [今日の日付]
**補足：** [任意 — 区別すべき論点、例外、注意点]
```

**カード作成ルール：**
1. **一概念一カード。** 「不法行為の要件」は4枚のカードになる。1枚ではない。
2. **表面は質問であり、トピック名ではない。** 「不法行為の故意」は不可。「民法709条の不法行為の成立要件4つを挙げよ」が正しい。
3. **裏面は規範であり、論述ではない。** 正解に段落が必要なら、複数カードに分割する。
4. **出典を記載** — ドリル中に再確認できるように。

**カード内容の類型：**
- **条文の趣旨・要件** — 条文番号、要件の列挙、趣旨の一文要約
- **判旨（重要判例）** — 判例名、判旨の核心部分、射程
- **論点の規範** — 論点名、判例・学説の規範定立
- **法的定義** — 法概念の定義、類似概念との区別
- **要件事実** — 請求原因事実、抗弁事実の整理

**引用の確認。** ソースの貼り付けなしに知識から生成されたカードの規範・判例・条文はAIモデルによる生成であり、未検証である。カードを暗記する前に、教科書、判例集、法令データベース（e-Gov法令検索、裁判所ウェブサイト）で確認すること。誤ったカードを完全に暗記することは、カードがないことより有害。

### `--drill` — ドリルセッション

**優先順位：**
1. `次回復習 <= 今日` かつ バケット != 定着 のカード
2. 未挑戦の新規カード
3. 復習期限到来も新規もない場合：定着カードの復習（忘却防止）を提案

**ドリルフロー（カードごと）：**
1. 問題を表示。回答を待つ。
2. ユーザーが回答（または「スキップ」/「わからない」と入力）
3. 正解を表示。
4. ユーザーが自己評価：`正解` / `部分的` / `不正解` / `わからない`
5. バケット・次回復習日を以下の表に従い更新：

| 自己評価 | バケット変更 | 次回復習 |
|---|---|---|
| 正解 | 1つ上へ（新規→学習中→復習→定着） | 新規+1日, 学習中+3日, 復習+7日, 定着+21日 |
| 部分的 | 変更なし | +1日 |
| 不正解 | 1つ下へ（復習→学習中、学習中→新規、新規は維持） | 今日+4時間 |
| わからない | 1つ下へ | 今日+4時間 |

### `--review` — デッキ一覧

科目内の全カードを表示。バケット別にグループ化。デッキの内容確認やカード内容の手動調整に使用。

### `--stats` — 進捗スナップショット

科目別：総カード数、バケット分布、今日の復習対象数、今週の復習実績。`新規` に2回以上戻ったカードをハイライト — それらは `/law-student-jp:socratic-drill` で口頭練習すべき停滞概念。

## 他スキルとの連携

- **outline-builder:** アウトライン構築・拡張後に、新しい内容からフラッシュカードの生成を提案
- **socratic-drill:** 2回以上不正解のカードは `/law-student-jp:socratic-drill` に誘導 — フラッシュカードだけでは理解できていない概念には不十分
- **bar-prep-questions:** 予備試験短答式対策で、フラッシュカードの成績が低い科目の出題比率を上げる

## 保存構造

```
flashcards/
└── [科目]/
    └── cards.md
```

科目ごとに1ファイル。カードはマークダウン形式。バケット・復習メタデータはカードごとにインライン記載。大規模デッキ（500枚超）には最適ではないが、通常の法科大学院の学習規模には十分。

## このスキルがやらないこと

- **Ankiの代替。** 既にフラッシュカードの習慣があるなら継続すること。これはチャット内でアプリを切り替えずにドリルしたいとき用。
- **枚数目標のためにカードを水増しする。** ソースから確信度の高いカードが8枚しか生成できなければ、8枚を提供する。`[要確認]` だらけの推測で水増しするのは、少ないデッキより悪い。
- **学習規律を強制する。** 復習を飛ばした日の蓄積は自己責任。スキルは復習対象を表示するだけ。ドリルするかどうかは自分で決める。
- **規範を教える。** カードは既に学習した内容のドリル用。カードが一貫して不正解なら、問題は上流にある — `/law-student-jp:socratic-drill` を使うか、ソースを読み直すこと。
