# /exam-forecast

1. `~/.claude/plugins/config/claude-for-legal/law-student-jp/CLAUDE.md` を読み込み → 受験区分（司法試験/予備試験）、科目、学習状況を確認。
2. 以下のワークフローを適用。
3. 過去問を取り込み（PDF、テキスト貼り付け、パス指定）。サンプルサイズを確認。
4. 各過去問を分析：出題形式、科目配分、論点の種類、事実関係の密度、繰り返し出題パターン。
5. 過去問横断の出題傾向分析 — 安定パターンと変動パターンを整理。
6. 法改正の出題可能性と論点の周期性を組み合わせて出題予測を生成。
7. `~/.claude/plugins/config/claude-for-legal/law-student-jp/exam-forecasts/[科目]/forecast-[YYYY-MM-DD].md` に保存。予測ではなく学習優先度の指針として位置づける。

---

## 目的

司法試験・予備試験には出題傾向がある。論点の周期性、法改正後の出題パターン、科目系統ごとの特徴。過去問を分析すれば、効率的な学習配分が見える。

出題予測ではない。傾向分析に基づく学習の重みづけ。過去問から抽出できるパターンを示し、どこに時間を割くべきかの判断材料を提供する。

## 信頼度の規律

- 出題頻度分析（どの論点が何年に出題されたか、出題頻度の統計）— 過去問が手元にある範囲で確信度は高い。
- 今後の出題可能性の推定 — `[不確実]` がデフォルト。「過去[N]年の問題では[論点]が[M]回出題されています。次回も出題される可能性はありますが、出題委員の判断次第です。学習時間の配分の参考にしてください」と明記する。
- 過去問が3年分未満の場合、明示的にサンプル不足を伝える。1年分のデータからパターンを読み取るのはノイズに過ぎない。
- 法改正の出題可能性は、改正法施行後の出題実績（改正民法、改正刑法等）を踏まえて推定するが、出題確約ではないことを明記する。

## コンテキスト読み込み

- `~/.claude/plugins/config/claude-for-legal/law-student-jp/CLAUDE.md` → 受験区分、科目、学習進捗
- ユーザー提供の過去問（PDF、貼り付けテキスト、パス指定）
- オプション：法務省公表の出題趣旨・採点実感（取得可能な場合）

**司法試験は出題委員が非公開のため、特定の出題者のパターン分析はできない。** 科目・論点・法改正の出題履歴に基づくパターン分析を行う。

## ワークフロー

### ステップ 1：取り込み

- 対象科目は何か？（公法系/民事系/刑事系/選択科目）
- 司法試験か予備試験か？
- 何年分の過去問があるか？
- 法務省の出題趣旨・採点実感は手元にあるか？
- 直近の法改正で学習範囲に影響があるものはあるか？

過去問が3年分未満：薄いサンプルとして警告。傾向推定の精度は低い。
司法試験と予備試験を混在して分析する場合：出題傾向の共通部分と相違点を区別する。

### ステップ 2：各過去問の分析

各年度の過去問について：

- 出題形式（論文式/短答式、問題数、設問構成）
- 論点カバー範囲（どの論点がどの比率で出題されているか）
- 問題の性質（事例問題/一行問題/判例分析型/制度論型）
- 事実関係の密度（事実関係の詳細さ、当事者の複雑さ）
- 法改正との関連（改正法施行後に改正論点が出題されたか）
- 出題趣旨・採点実感からの示唆（公表されている場合）

### ステップ 3：横断的パターン分析

複数年度で一貫する傾向を整理する：

**安定パターン（ほとんどの年度で出題）：**
- 論点の出題頻度（例：「不法行為は民法で過去5年中4年出題」）
- 出題形式の傾向（例：「民事系は常に複数当事者の事例問題」）
- 繰り返し出題される定番論点

**周期的パターン（一定間隔で出題）：**
- 論点の周期性（例：「株主代表訴訟は2-3年周期で出題」）
- 法改正後の出題タイミング（例：「改正民法の債権法分野は施行翌年に集中出題」）

**法改正の出題可能性：**
- 未出題の改正論点 — 出題可能性が高い
- 既出題の改正論点 — 再出題の頻度は低いが、応用問題の可能性あり
- 施行後3年以内の改正 — 出題可能性を重視

**出題されていない論点：**
- 学習範囲に含まれるが長期間未出題の論点 — 完全に捨てず、軽く押さえる

### ステップ 4：出題予測の生成

**ヘッダー — 必須。予測の先頭行に必ず記載。** プラグイン設定 `## Outputs` に従い、すべての学習成果物にヘッダーを付与する。出題予測も学習成果物であり、省略・言い換え・位置変更は不可：

```
学習ノート — 法的助言ではありません
```

傾向分析と法改正情報を組み合わせた予測：

```markdown
学習ノート — 法的助言ではありません

# 出題予測 — [科目] — [日付]

**分析対象年度数：** [N]年分
**サンプル信頼度：** [薄い（3年未満）/ 中程度（3-5年）/ 高い（6年以上）]
**受験区分：** [司法試験 / 予備試験]
**注意事項：** [例：「予備試験と司法試験の過去問を混在分析。出題傾向に共通点はあるが、問題の深度は異なる」]

---

## 論点別出題頻度

- **問題構成：** [事例問題○問 + 制度論○問、等]
- **事実関係の密度：** [複雑な事実関係 / 簡潔 / 混在]
- **設問形式：** [包括的設問 / 小問分割 / 段階的設問]

## 定番論点（繰り返し出題）

- [論点A] — 過去[M/N]年で出題。出題頻度が学習配分に対して高い。
```

### ステップ 5：保存先

`~/.claude/plugins/config/claude-for-legal/law-student-jp/exam-forecasts/[科目]/forecast-[YYYY-MM-DD].md` に保存。バージョン管理 — 新たな過去問や情報が入手できた場合、再実行して追記する。

## 他スキルとの連携

- **outline-builder:** 予測の重みづけをアウトライン構成の深度判断に反映 — 重点論点はより詳細に
- **flashcards:** 重点論点のカードを優先的に生成
- **irac-practice:** 予測上位の論点を答案練習の題材に使用
- **bar-prep-questions:** 予備試験短答式の対策には関連するが、予測モデルは異なる

## このスキルがやらないこと

- **具体的な問題を予測する。** 過去問はパターンを示すが、来年の問題文は見えない。
- **過去問なしで機能する。** 過去問がなければ傾向分析はできない。学習範囲の整理にフォールバックする。
- **学習範囲の取捨選択を決める。** 予測は重みづけであり、論点の切り捨てではない。出題頻度が低いからと論点を捨てるのは、受験生が最も後悔するパターン。
- **出題委員の変更を反映する。** 司法試験の出題委員は非公開であり、委員の交代による傾向変化は事前に把握できない。
- **1-2年分の過去問で信頼できる予測を出す。** サンプル不足。その旨を明記する。
