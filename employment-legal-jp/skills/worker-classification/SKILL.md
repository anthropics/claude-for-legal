## 目的

労働基準法上の「労働者」に該当するかは、契約の形式ではなく実態に基づいて判断される（労基研報告「労働基準法の『労働者』の判断基準について」昭60.12.19）。業務委託契約であっても実態が雇用であれば、労基法・社会保険の適用を受ける。偽装請負と判断された場合、労働者派遣法違反（第26条）のリスクもある。さらに2024年11月施行のフリーランス保護法（特定受託事業者に係る取引の適正化等に関する法律）により、フリーランスへの発注にも新たな義務が課される。

## ワークフロー

### ステップ1: 基本情報の収集

以下をすべて1つのプロンプトで聞く:

> 労働者性の判断に必要な情報です。分かる範囲でお答えください:
>
> **業務内容**
> - どのような業務を行っていますか（行う予定ですか）？
> - その業務は御社の主要事業の一部ですか、それとも周辺的な業務ですか？
> - 特定のプロジェクトですか、それとも継続的な業務ですか？
> - 専門的な技能・資格が必要な業務ですか？
>
> **指揮監督**
> - 仕事の依頼を断ることはできますか？
> - 業務の進め方（手順、方法）について御社が指示していますか？
> - 勤務時間は決められていますか？ 遅刻・早退で不利益はありますか？
> - 勤務場所は指定されていますか？ 御社のオフィスで働いていますか？
> - 他の人が代わりに業務を行うことはできますか（代替性）？
>
> **報酬・経済的関係**
> - 報酬は時間単位ですか、成果物単位ですか、月額固定ですか？
> - 業務に必要な機器・器具は誰が負担していますか？
> - 他社の仕事も受けていますか（専属性）？
> - 自ら事業体（法人、個人事業主）として登録していますか？
>
> **契約形態**
> - 現在の契約形式は何ですか（業務委託 / 請負 / 準委任 / SES / 派遣）？
> - 契約期間はどのくらいですか？
> - 御社の従業員と同じ業務をしている人はいますか？
>
> **既存か新規か**
> - この業務はすでに開始していますか、それともこれから始まりますか？

### ステップ2: 労働者性の判断基準

労働基準法の「労働者」の判断基準（昭60.12.19労基研報告）に基づき分析する:

#### 使用従属性の判断

**A. 指揮監督下の労働**

| 判断要素 | 労働者寄りの事実 | 事業者寄りの事実 | 本件の事実 | 判定 |
|---|---|---|---|---|
| 仕事の依頼の諾否の自由 | 断れない | 自由に断れる | | |
| 業務遂行上の指揮監督 | 具体的な指示に従う義務 | 成果物の内容のみ指定 | | |
| 時間的拘束性 | 勤務時間が指定、遅刻で制裁 | 自由に決定 | | |
| 場所的拘束性 | 勤務場所が指定 | 自由に決定 | | |
| 代替性 | 本人が行う必要 | 他者に委託可能 | | |

**B. 報酬の労務対償性**

| 判断要素 | 労働者寄りの事実 | 事業者寄りの事実 | 本件の事実 | 判定 |
|---|---|---|---|---|
| 報酬の計算方法 | 時間を基礎に計算 | 成果物に対する対価 | | |
| 欠勤・遅刻の控除 | 控除あり | 控除なし | | |
| 報酬の額 | 同種業務の従業員と同程度 | 著しく高額 | | |

#### 補強要素

| 判断要素 | 労働者寄りの事実 | 事業者寄りの事実 | 本件の事実 | 判定 |
|---|---|---|---|---|
| 事業者性（機器の負担） | 会社が提供 | 自己負担 | | |
| 事業者性（報酬の額） | 一般従業員と同程度 | 著しく高額 | | |
| 専属性 | 他社の仕事を禁止/制限 | 自由に受注 | | |
| その他（源泉徴収等） | 給与所得として源泉徴収 | 事業所得として支払 | | |
| その他（服務規律の適用） | 就業規則の適用あり | 適用なし | | |

### ステップ3: 偽装請負のリスク分析

労働者派遣法に基づく偽装請負のリスクを分析する:

| チェック項目 | リスクあり | リスクなし | 本件 |
|---|---|---|---|
| 発注者が業務の細部まで指示 | 🔴 | ✅ | |
| 発注者が勤務時間を管理 | 🔴 | ✅ | |
| 発注者の事業所で発注者の従業員と混在して勤務 | 🔴 | ✅ | |
| 発注者が業務の割振り・順序を決定 | 🔴 | ✅ | |
| 受託者の管理者が実質的に不在 | 🔴 | ✅ | |

**偽装請負と判断された場合のリスク:**

| リスク | 内容 |
|---|---|
| 労働者派遣法違反 | 無許可派遣（1年以下の懲役又は100万円以下の罰金） |
| 直接雇用のみなし | 労働者派遣法第40条の6（労働契約申込みみなし制度） |
| 社会保険の遡及適用 | 雇用関係が認められた場合、社会保険料の遡及支払い |
| 未払賃金 | 労基法上の労働者と認められた場合の残業代等の遡及支払い |

### ステップ4: フリーランス保護法の適用確認

特定受託事業者に係る取引の適正化等に関する法律（2024年11月施行）:

| 確認事項 | 内容 | 該当 |
|---|---|---|
| 適用対象 | 業務委託の相手方が「特定受託事業者」（従業員を使用しないフリーランス）に該当するか | ☐ |
| 書面交付義務 | 業務内容、報酬額、支払期日等を記載した書面の交付 | ☐ |
| 報酬支払期日 | 給付を受領した日から60日以内 | ☐ |
| 禁止行為（継続的業務委託） | 受領拒否、報酬減額、返品、買いたたき、購入強制、不当な経済上の利益提供要請、不当な給付内容の変更 | ☐ |
| ハラスメント対策 | 業務委託先のフリーランスに対するハラスメント防止措置 | ☐ |
| 契約の中途解除 | 30日前の予告義務（6ヶ月以上の継続的業務委託） | ☐ |

`[モデル知識 — 要確認: フリーランス保護法の施行状況と公正取引委員会のガイドラインの最新情報を確認すること]`

### ステップ5: 総合判定


## 弁護士確認ゲート（consequential-action gate）

**「労働者性なし」の最終判断または業務委託契約の続行可の判断を出力する前に:** Read `## 利用者情報` in `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md`. If the Role is **法務部員・人事部員・その他**:

> 労働者性の判断を誤ると、社会保険料の遡及支払い、未払残業代の請求、偽装請負による刑事罰等の重大なリスクがあります。この業務委託について弁護士または社会保険労務士に相談しましたか？
>
> **はい** の場合 → 進めます。
> **いいえ** の場合 → 以下の要約を弁護士・社労士にお持ちください:
>
> - 業務内容、契約形式、契約期間
> - 使用従属性の各判断要素の分析結果
> - 偽装請負リスクの評価
> - フリーランス保護法の適用の有無
> - ギャップ分析（契約形式と実態の不一致）
> - 労働者性が認められた場合の影響（社会保険遡及、未払賃金、派遣法違反）
> - 弁護士に聞くべきこと（この契約は維持できるか、是正するとした場合の方法、リスクの大きさ）
>
> 弁護士・社労士をお探しの場合: 各地の弁護士会または社会保険労務士会の紹介サービスをご利用ください。

Do not produce a final "労働者性なし" output past this gate without an explicit yes.

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルがやらないこと

- 労働者性の最終決定を行うこと。判断要素を分析し、リスクを評価する。
- 業務委託契約書を一から作成すること。既存の契約・実態のレビューを行う。
- 労働基準監督署への届出を行うこと。必要な届出は指摘する。
- 社会保険の遡及手続を行うこと。遡及が必要な場合のリスクを指摘する。
