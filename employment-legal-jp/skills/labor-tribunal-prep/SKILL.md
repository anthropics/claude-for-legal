## 目的

労働審判は、個別労働関係紛争を原則3回以内の期日で迅速に解決する手続である（労働審判法第15条2項）。第1回期日までに主張・立証の大部分を準備する必要があり、短期間での集中的な準備が求められる。このスキルは申立て側・被申立て側の双方の準備を支援する。

## 弁護士確認ゲート

**このスキルは弁護士の監督下での使用を前提とする。** `## 利用者情報` の役割が弁護士以外の場合:

## ワークフロー

### Step 1: 事案の基本情報

- **立場:** 申立人側（労働者側） / 相手方側（使用者側）
- **紛争の種類:** 解雇無効 / 未払賃金（残業代） / ハラスメントによる損害賠償 / 雇止め無効 / 配転命令無効 / その他
- **申立ての状況:** 申立て前 / 申立て済み（第1回期日: [日付]）/ 答弁書準備中
- **相手方の情報:** 氏名・住所・代理人弁護士の有無
- **時効の確認:** 消滅時効の進行状況（賃金請求権: 当面3年、退職金: 5年）

### Step 2: 争点整理

事案の類型に応じた争点を整理する:

#### 解雇無効の場合
1. 解雇の種類（普通解雇 / 整理解雇 / 懲戒解雇）
2. 解雇理由の特定
3. 解雇権濫用法理（労契法第16条）の適用
4. 整理解雇の場合は4要件の充足度
5. 手続要件の充足（解雇予告等）
6. バックペイの計算（解雇日から解決日までの賃金）

#### 未払賃金（残業代）の場合
1. 労働時間の認定方法（タイムカード、PC ログ、メール送信時刻等）
2. 管理監督者性の争い
3. 固定残業代の有効性
4. 割増賃金の計算基礎
5. 付加金の請求（労基法第114条）
6. 遅延損害金（退職後は年14.6%: 賃確法第6条）

### Step 3: 証拠整理

| 証拠番号 | 証拠の標目 | 立証趣旨 | 入手状況 |
|---|---|---|---|
| 甲(乙)第1号証 | | | 手元にあり / 要取得 / 相手方が保持 |

### Step 4: 解決金の相場分析

| 要素 | 内容 | 解決金への影響 |
|---|---|---|
| 勤続年数 | | 長いほど高額 |
| 月額賃金 | | 解決金の基礎 |
| 解雇理由の強弱 | | 弱いほど高額 |
| バックペイ期間 | | 長いほど高額 |
| 再就職の状況 | | 未就職の場合高額 |
| **相場の目安** | 月収の3〜6ヶ月分が中央値 | `[モデル知識 — 要確認]` |

### Step 5: 申立書/答弁書のドラフト支援

申立書（答弁書）の構成:
1. 申立ての趣旨（求める審判の内容）
2. 申立ての理由（紛争の経緯、法的主張）
3. 予想される争点に対する主張
4. 証拠方法
5. 附属書類
