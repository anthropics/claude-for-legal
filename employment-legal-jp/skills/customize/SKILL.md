# /customize

1. Load `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md`.
2. Show the customizable sections with current values.
3. Ask what the user wants to change.
4. Make the change, explain downstream effects, confirm, write.

---

## 目的

プラクティスプロファイルの一部を変更したい場合に、コールドスタートインタビュー全体を再実行せずに個別の設定変更を行う。

## ワークフロー

### ステップ1: 設定の読み込み

`~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md`（および `~/.claude/plugins/config/claude-for-legal/company-profile.md`）を読み込む。プラグイン設定が存在しないか `[PLACEHOLDER]` が残っている場合:

> セットアップがまだ完了していません。先に `/employment-legal-jp:cold-start-interview` を実行してください。カスタマイズは既存のプロファイルを調整するためのものです。

### ステップ2: カスタマイズ可能なセクションの表示

以下のセクションを現在の値とともに表示する:

| セクション | 内容 | 影響範囲 |
|---|---|---|
| **組織情報** | 会社名、従業員数、事業場数 | 就業規則の作成義務判定、社会保険の適用拡大判定 |
| **利用者情報** | 役割、顧問弁護士、顧問社労士 | 出力ヘッダー、弁護士確認ゲート |
| **連携ツール** | HRIS、勤怠管理、給与計算の接続状況 | 休暇トラッカー、データ取得方法 |
| **就業規則** | 有無、最終更新日、届出先労基署 | 就業規則監査、変更レビュー |
| **36協定** | 有無、有効期間、特別条項 | 労働時間の上限チェック |
| **労働組合** | 有無、過半数代表者の選出 | 就業規則変更手続 |
| **ハラスメント窓口** | 設置状況、担当者 | 社内調査スキル |
| **公益通報窓口** | 設置状況 | 社内調査スキル |
| **エスカレーション** | エスカレーション先の連絡先 | 全スキルのエスカレーション |
| **雇用形態** | 正社員・契約社員等の人数 | 適用法令の判定 |
| **外国人労働者** | 在留資格管理の状況 | 採用レビュー |
| **社会保険・労働保険** | 適用状況 | 社会保険Q&A |
| **変形労働時間制・裁量労働制** | 採用している制度 | 労働時間・賃金Q&A |

### ステップ3: 変更の実施

> 何を変更しますか？ セクション名を選ぶか、変更したい内容を説明してください。

変更時に以下を行う:

1. 現在の値を表示
2. 新しい値を確認
3. 変更による下流への影響を説明
4. 確認を得てから書き込み

**影響の説明例:**

- *従業員数を50人→55人に変更:* 「2024年10月からの社会保険適用拡大（51人以上）の対象になります。短時間労働者の社会保険加入手続を確認してください。」
- *36協定の特別条項を「なし」→「あり」に変更:* 「`/wage-hour-qa` が特別条項の上限（月100時間未満/年720時間）を基準にチェックするようになります。」
- *ハラスメント窓口を「未設置」→「設置済み」に変更:* 「`/internal-investigation` がハラスメント事案の相談窓口経由の案件として処理できるようになります。」

### ステップ4: 共有プロファイルの変更

会社名、業種等の共有プロファイル情報の変更は `~/.claude/plugins/config/claude-for-legal/company-profile.md` に書き込む:

> この変更は全プラグインに影響します — 他のプラグインでもこの情報が使用されます。

### ステップ5: 完了

> 変更しました。次回の出力から反映されます。他に変更はありますか？ `/employment-legal-jp:customize` でいつでも変更できます。

---

## このスキルがやらないこと

- セクションを削除すること。値を「なし」や「未設定」に変更することは可能。
- コールドスタートインタビュー全体を再実行すること。全体の再設定は `/employment-legal-jp:cold-start-interview --redo`。
- 他のプラグインの設定を変更すること。共有プロファイル以外はこのプラグイン固有。
