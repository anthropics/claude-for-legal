# /leave-tracker

1. Load `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 連携ツール、雇用形態。
2. Read leave register at `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/leave-register.yaml`.
3. Calculate status against applicable regimes.
4. Alerts only for leaves requiring action. Clean leaves summarized one line each.

---

## 目的

年次有給休暇の年5日取得義務（労基法第39条第7項）の違反には30万円以下の罰金が科される（労基法第120条）。産前産後休業・育児休業・介護休業には法定の期間と手続要件がある。このスキルは休暇・休業の取得状況を管理し、法定義務の充足状況を監視する。

## コンテキストの読み込み

`~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 連携ツール（HRIS接続の有無）、雇用形態。

HRIS未接続で `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/leave-register.yaml` も存在しない場合:

> 休暇・休業データがありません。以下のいずれかで共有してください:
> - HRISの接続設定（`/employment-legal-jp:cold-start-interview --check-integrations`）
> - 休暇データの直接入力（`/employment-legal-jp:log-leave`）
> - スプレッドシートのアップロード

## ワークフロー

### ステップ1: 年次有給休暇の管理

#### 付与日数テーブル（労基法第39条）

**通常の労働者:**

| 勤続年数 | 付与日数 |
|---|---|
| 6ヶ月 | 10日 |
| 1年6ヶ月 | 11日 |
| 2年6ヶ月 | 12日 |
| 3年6ヶ月 | 14日 |
| 4年6ヶ月 | 16日 |
| 5年6ヶ月 | 18日 |
| 6年6ヶ月以上 | 20日 |

**パートタイム労働者（比例付与 — 週所定労働日数4日以下かつ週所定労働時間30時間未満）:**

| 勤続年数 | 週4日 | 週3日 | 週2日 | 週1日 |
|---|---|---|---|---|
| 6ヶ月 | 7日 | 5日 | 3日 | 1日 |
| 1年6ヶ月 | 8日 | 6日 | 4日 | 2日 |
| 2年6ヶ月 | 9日 | 6日 | 4日 | 2日 |
| 3年6ヶ月 | 10日 | 8日 | 5日 | 2日 |
| 4年6ヶ月 | 12日 | 9日 | 6日 | 3日 |
| 5年6ヶ月 | 13日 | 10日 | 6日 | 3日 |
| 6年6ヶ月以上 | 15日 | 11日 | 7日 | 3日 |

#### 年5日取得義務の監視（労基法第39条第7項）

| 確認事項 | 内容 | ステータス |
|---|---|---|
| 対象者 | 年10日以上付与された労働者 | |
| 義務 | 付与日から1年以内に5日を時季指定して取得させる | |
| 年次有給休暇管理簿の作成 | 時季、日数、基準日を記録（3年間保存） | |
| 計画年休 | 労使協定による計画的付与（5日を超える部分）は取得日数に算入可 | |
| 罰則 | 違反1件につき30万円以下の罰金（労働者ごと） | |

**アラート基準:**

| アラート | 条件 | アクション |
|---|---|---|
| 🔴 緊急 | 基準日から10ヶ月経過で取得3日未満 | 即時の時季指定が必要 |
| 🟠 警告 | 基準日から8ヶ月経過で取得3日未満 | 時季指定の計画を策定 |
| 🟡 注意 | 基準日から6ヶ月経過で取得2日未満 | 取得を促す声かけ |
| ✅ 正常 | 上記に該当しない | 通常管理 |

### ステップ2: 産前産後休業（労基法第65条）

| 項目 | 内容 | 期間 |
|---|---|---|
| 産前休業 | 出産予定日の6週間前（多胎妊娠は14週間前） | 本人の請求が必要 |
| 産後休業 | 出産の翌日から8週間 | 強制休業（6週間経過後は本人請求+医師の許可で就業可） |
| 社会保険料免除 | 産前産後休業期間中 | 事業主負担分・本人負担分とも |
| 出産手当金 | 標準報酬日額の3分の2 | 健康保険から支給 |
| 出産育児一時金 | 1児につき50万円（産科医療補償制度加入の場合） | |

`[モデル知識 — 要確認: 出産育児一時金の額は最新の制度で確認すること]`

### ステップ3: 育児休業（育介法第5条〜）

| 項目 | 内容 |
|---|---|
| 対象 | 1歳未満の子を養育する労働者（男女問わず） |
| 期間 | 子が1歳に達するまで（保育所に入れない等の場合1歳6ヶ月→2歳まで延長可） |
| 分割取得 | 2回まで分割可 |
| 社会保険料免除 | 育児休業期間中（月末時点で育休中、または同月内14日以上取得） |
| 育児休業給付金 | 休業開始時賃金日額の67%（180日経過後50%） |

#### 産後パパ育休（出生時育児休業 — 育介法第9条の2）

| 項目 | 内容 |
|---|---|
| 対象 | 出生後8週間以内の子を養育する労働者（主に父親） |
| 期間 | 4週間（28日）まで |
| 分割 | 2回まで分割可 |
| 申出期限 | 原則2週間前まで |
| 休業中の就業 | 労使協定がある場合、本人が合意した範囲で就業可 |

**管理上のチェックポイント:**

| 確認事項 | 期限 | ステータス |
|---|---|---|
| 育児休業の申出受理 | 休業開始予定日の1ヶ月前まで | ☐ |
| 社会保険料免除の届出 | 速やかに | ☐ |
| 育児休業給付金の申請 | ハローワークへ | ☐ |
| 復帰時の面談 | 復帰前 | ☐ |
| 短時間勤務制度の案内 | 3歳未満の子がいる場合 | ☐ |

### ステップ4: 介護休業（育介法第11条〜）

| 項目 | 内容 |
|---|---|
| 対象家族 | 配偶者、父母、子、配偶者の父母、祖父母、兄弟姉妹、孫 |
| 期間 | 対象家族1人につき通算93日 |
| 分割 | 3回まで分割可 |
| 介護休暇 | 対象家族1人なら年5日、2人以上なら年10日（時間単位取得可） |
| 介護休業給付金 | 休業開始時賃金日額の67% |
| 短時間勤務等の措置 | 利用開始から3年以上の期間で2回以上利用可能な措置を講じる義務 |

### ステップ5: 子の看護等休暇・介護休暇

| 項目 | 子の看護等休暇 | 介護休暇 |
|---|---|---|
| 対象 | 小学校3年生修了前の子（9歳に達する日以後の最初の3月31日まで）を養育する労働者 | 要介護状態にある対象家族の介護をする労働者 |
| 日数 | 子1人なら年5日、2人以上なら年10日 | 対象家族1人なら年5日、2人以上なら年10日 |
| 取得単位 | 時間単位で取得可 | 時間単位で取得可 |
| 取得事由 | 負傷・疾病、予防接種・健康診断、感染症に伴う学級閉鎖等、入園式・卒園式等の行事参加 | 介護、通院等の付添い、介護サービスの手続代行等 |
| 有給/無給 | 法律上は無給でよい（就業規則による） | 法律上は無給でよい（就業規則による） |

`[モデル知識 — 要確認: 子の看護等休暇の対象年齢拡大等の法改正の最新状況を確認すること]`

### ステップ6: 社会保険料免除の追跡

| 休業の種類 | 免除対象 | 届出 | ステータス |
|---|---|---|---|
| 産前産後休業 | 健康保険料・厚生年金保険料（事業主・本人とも） | 産前産後休業取得者申出書 | ☐ |
| 育児休業 | 健康保険料・厚生年金保険料（事業主・本人とも） | 育児休業等取得者申出書 | ☐ |
| 育児休業終了時の標準報酬月額改定 | 復帰後の報酬が低下した場合の随時改定の特例 | 育児休業等終了時報酬月額変更届 | ☐ |
| 養育期間の従前標準報酬月額みなし | 子の養育による報酬低下時の年金計算の特例 | 養育期間標準報酬月額特例申出書 | ☐ |
| 賞与に係る保険料免除 | 育児休業等の期間が1ヶ月を超える場合に限る（健康保険法第159条の3等） | — | ☐ |

## 次のステップ決定ツリー

> **次のステップを選んでください:**
> 1. **休暇・休業の新規記録** — `/employment-legal-jp:log-leave` で新しいエントリを追加
> 2. **年5日取得義務の対応** — 未取得者への時季指定計画を作成
> 3. **育児休業の手続確認** — 届出漏れのチェックと手続リストの作成
> 4. **社会保険料免除の届出確認** — 届出状況の確認と未届出の対応
> 5. **その他** — ご希望をお知らせください

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルがやらないこと

- 休暇の承認・不承認を決定すること。法定要件と期限を管理する。
- 社会保険の届出を行うこと。届出の必要性と期限を通知する。
- 給付金の申請を行うこと。申請の必要性と手続を案内する。
- 就業規則の休暇規定を変更すること。規定の問題点は指摘する。
