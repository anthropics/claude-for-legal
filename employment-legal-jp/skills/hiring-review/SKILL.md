## 目的

労基法第15条は、労働契約の締結に際し労働条件の明示を義務付けている。2024年4月からは有期契約の更新上限の明示、無期転換申込権の明示等が追加された。このスキルは雇用契約書・労働条件通知書の法令適合性と、競業避止義務等の付随条項の有効性を確認する。

## コンテキストの読み込み

`~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 雇用形態、就業規則の整備状況、利用者情報。

## 出力ヘッダー

Prepend the work-product header from `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → `## 出力設定` (it differs by user role — see `## 利用者情報`).

## ワークフロー

### ステップ1: 基本情報の確認

以下の情報を確認する（すべて1つのプロンプトで聞く）:

- **雇用形態:** 正社員 / 契約社員（有期雇用） / パートタイマー / 嘱託（再雇用）
- **勤務地:** 本社 / 支店 / リモートワーク / 転勤の可能性
- **職種:** 具体的な業務内容
- **試用期間の有無:** 有の場合、期間と延長条項
- **採用経路:** 新卒 / 中途 / 紹介 / 派遣からの切替
- **書類の種類:** 雇用契約書 / 労働条件通知書 / 内定通知書 / 兼用書式

### ステップ3: 就業規則との整合性

雇用契約書の内容が就業規則の基準を下回っていないか確認する:

- 労働契約の内容は就業規則で定める基準に達しない部分は無効（労契法第12条）
- 無効となった部分は就業規則の基準による
- 就業規則を上回る個別合意は有効

### ステップ4: 試用期間の法的性質

| 確認事項 | 内容 | チェック |
|---|---|---|
| 期間の長さ | 通常3〜6ヶ月。1年超は合理性が問題に | ☐ |
| 法的性質 | 解約権留保付労働契約（三菱樹脂事件・最大判S48.12.12） | — |
| 本採用拒否の基準 | 客観的に合理的な理由と社会通念上の相当性が必要 | ☐ |
| 延長条項 | 延長の要件と上限が明確か | ☐ |
| 試用期間中の待遇 | 本採用後と異なる場合、その差異が合理的か | ☐ |
| 最低賃金の減額特例 | 試用期間中の減額特例を利用する場合、許可を受けているか | ☐ |

> **判例参考:**
> - 三菱樹脂事件（最大判S48.12.12）— 試用期間の法的性質と本採用拒否の制限 `[モデル知識 — 要確認]`
> - 神戸弘陵学園事件（最判H2.6.5）— 試用期間の長さの合理性 `[モデル知識 — 要確認]`

### ステップ5: 競業避止義務・秘密保持義務の有効性

#### 競業避止義務条項

日本法では退職後の競業避止義務の有効性は以下の要素で判断される:

| 要素 | チェックポイント | 判定 |
|---|---|---|
| 守るべき企業の利益 | 営業秘密・ノウハウ等の正当な保護利益があるか | ☐ |
| 従業員の地位 | 対象者が企業秘密に接する地位にあったか | ☐ |
| 制限の期間 | 合理的な期間か（1年以内が目安、2年超は厳しい） | ☐ |
| 制限の地域 | 地理的範囲が合理的か | ☐ |
| 制限の業種・職種 | 制限範囲が過度に広くないか | ☐ |
| 代償措置 | 競業避止の対価としての金銭的補償はあるか | ☐ |

> **判例参考:**
> - フォセコ・ジャパン事件（奈良地判S45.10.23）— 競業避止義務の有効性判断基準 `[モデル知識 — 要確認]`

**注意:** 代償措置なしの競業避止義務は無効とされるリスクが高い。

#### 秘密保持義務条項

| 確認事項 | 内容 |
|---|---|
| 秘密情報の定義 | 具体的かつ明確に定義されているか |
| 対象範囲 | 過度に広範でないか（「業務上知り得た一切の情報」は無効リスク） |
| 期間 | 退職後の秘密保持義務の期間 |
| 不正競争防止法との関係 | 営業秘密の3要件（秘密管理性、有用性、非公知性）を満たすか |

### ステップ6: 内定の法的性質

| 項目 | 内容 |
|---|---|
| 法的性質 | 始期付解約権留保付労働契約（大日本印刷事件・最判S54.7.20） |
| 内定取消しの制限 | 採用内定の取消事由は、客観的に合理的と認められ社会通念上相当として是認できるものに限られる |
| 内定取消しが認められる例 | 卒業できなかった、健康状態が業務に耐えない、重大な経歴詐称、刑事事件を起こした |
| 企業の経営悪化 | 整理解雇の4要件に準じた判断が必要 |

> **判例参考:**
> - 大日本印刷事件（最判S54.7.20）— 内定の法的性質 `[モデル知識 — 要確認]`

### ステップ7: 外国人雇用の確認（該当する場合）

| 確認事項 | 内容 | チェック |
|---|---|---|
| 在留資格の確認 | 就労可能な在留資格を有しているか | ☐ |
| 在留資格と業務の整合性 | 従事させる業務が在留資格の活動範囲内か | ☐ |
| 在留期間の確認 | 在留期間の残存期間 | ☐ |
| 外国人雇用状況届出 | ハローワークへの届出義務（雇入れ・離職時） | ☐ |
| 資格外活動許可 | 留学生のアルバイト等、資格外活動の場合の許可の有無 | ☐ |

### ステップ8: パートタイム・有期雇用労働者の追加チェック

パートタイム・有期雇用労働法が適用される場合:

| 確認事項 | 根拠 | チェック |
|---|---|---|
| 不合理な待遇差の禁止 | 同法第8条 | ☐ |
| 差別的取扱いの禁止（通常の労働者と同視すべき者） | 同法第9条 | ☐ |
| 待遇差の説明義務 | 同法第14条2項 | ☐ |
| 正社員転換推進措置 | 同法第13条 | ☐ |

## 弁護士確認ゲート（consequential-action gate）

**「送付可」のレコメンデーションを出力する前に:** Read `## 利用者情報` in `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md`. If the Role is **法務部員・人事部員・その他**:

> 雇用契約書・労働条件通知書は法的拘束力を持つ文書です。労働条件の明示義務違反には罰則があり（労基法第120条 — 30万円以下の罰金）、また競業避止義務条項や試用期間の設定は後のトラブルの原因となり得ます。この書類について弁護士または社会保険労務士に相談しましたか？
>
> **はい** の場合 → 進めます。
> **いいえ** の場合 → 以下の要約を弁護士・社労士にお持ちください:
>
> - 雇用形態、職種、勤務地
> - 労働条件明示事項の充足状況（欠落事項があれば）
> - 試用期間の設定内容
> - 競業避止義務条項の有効性リスク
> - 就業規則との不整合（あれば）
> - 弁護士に聞くべきこと（この契約書で法的に問題ないか、追加すべき条項はあるか）
>
> 弁護士・社労士をお探しの場合: 各地の弁護士会または社会保険労務士会の紹介サービスをご利用ください。

Do not produce a "送付可" output past this gate without an explicit yes.

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルがやらないこと

- 採用の決定を行うこと。書類の法的適合性をチェックする。
- 雇用契約書を一から作成すること。既存の書類のレビューを行う。新規作成は `/employment-legal-jp:policy-drafting` で対応。
- 在留資格の申請手続を行うこと。在留資格の確認と注意点の指摘を行う。
- 面接の質問を作成すること。採用プロセスの法的チェックは行う。
