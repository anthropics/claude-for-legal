## 目的

ハラスメント事案、コンプライアンス違反、不正行為等の社内調査を体系的に支援する。適切な調査手続を経ることは、事実認定の正確性と、その後の懲戒処分等の有効性を担保するために不可欠である。日本法には米国のUpjohn warning（弁護士代理の告知義務）に相当する制度はないが、調査の公正性と被調査者の権利への配慮は求められる。

## ワークフロー

### ステップ1: 事案の分類とインテーク

以下を1つのプロンプトで確認する:

> 調査を開始するために以下を確認します:
>
> **事案の概要**
> - どのような事案ですか（ハラスメント / コンプライアンス違反 / 不正行為 / その他）
> - 申告者は誰ですか（匿名でも可）
> - 対象者（被疑者）は誰ですか
> - いつ頃の行為についてですか
>
> **事案の種類**
> - ハラスメント（パワハラ / セクハラ / マタハラ / その他）
> - 不正行為（横領 / 情報漏洩 / 経費不正 / その他）
> - コンプライアンス違反（法令違反 / 社内規程違反）
> - 公益通報に該当する可能性があるか
>
> **調査体制**
> - 弁護士が関与していますか
> - 調査チームのメンバーは誰ですか
> - 外部調査委員会を設置する必要がありますか

### ステップ2: 調査計画の策定

| 項目 | 内容 |
|---|---|
| 調査目的 | 事実関係の確認と法的評価 |
| 調査範囲 | 対象行為、対象期間、関係者の範囲 |
| 調査期間 | 目標期間（通常2〜4週間、重大事案は延長） |
| 調査チーム | 調査担当者、監督者、記録者 |
| 秘密保持 | 調査に関する情報の取扱い |
| 証拠保全 | 保全すべき証拠のリスト |

### ステップ3: 証拠の保全

| 証拠の種類 | 保全方法 | 優先度 |
|---|---|---|
| メール・チャットログ | IT部門に保全を依頼（削除防止） | 高 |
| 勤怠記録 | 対象期間のデータをエクスポート | 高 |
| 人事記録 | 対象者の評価履歴、懲戒履歴 | 高 |
| 監視カメラ映像 | 上書き前に保全（保存期間に注意） | 高 |
| 経費データ | 対象期間の経費申請・承認記録 | 中 |
| PC・スマートフォン | 必要に応じてフォレンジック調査 | 状況による |

**注意:** 証拠保全に際しては個人情報保護法への配慮が必要。メール監視等は就業規則にモニタリングに関する規定があるか確認する。

### ステップ4: ヒアリングの実施

#### ヒアリングの順序

| # | 対象 | 目的 | 注意点 |
|---|---|---|---|
| 1 | 申告者 | 事実関係の詳細確認 | 二次被害の防止、報復禁止の説明 |
| 2 | 関係者・目撃者 | 裏付け情報の収集 | 秘密保持の依頼 |
| 3 | 対象者（被疑者） | 弁明の機会の付与 | 弁明の機会は懲戒処分の有効性に影響 |

#### ヒアリング時の注意事項

| 項目 | 内容 |
|---|---|
| 記録の作成 | 発言内容を詳細に記録（可能であれば同意を得て録音） |
| 弁護士の同席 | 日本法上、被疑者に弁護士の同席を認める義務はないが、重大事案では検討 |
| 秘密保持の説明 | 調査に関する情報を第三者に口外しないよう依頼 |
| 不利益取扱いの禁止 | ハラスメント申告者への報復禁止を説明 |
| プライバシーの配慮 | 他のヒアリング対象者の発言内容を不必要に開示しない |
| Upjohn warningについて | 日本には米国のUpjohn warningに相当する制度はない。弁護士が誰の利益のために調査しているか（会社のため）を説明することは推奨されるが、法的義務ではない |

### ステップ5: ハラスメント調査の特別手続

ハラスメント事案の場合、以下の追加チェックを行う:

#### パワーハラスメントの判断基準（労推法第30条の2）

3要素すべてを満たす場合にパワハラに該当:

| 要素 | 内容 | 確認 |
|---|---|---|
| 優越的な関係に基づく | 上司から部下、先輩から後輩、集団から個人等 | ☐ |
| 業務上必要かつ相当な範囲を超えた | 業務上の合理性がない、社会通念上許容されない | ☐ |
| 就業環境が害された | 身体的・精神的な苦痛、就業環境への悪影響 | ☐ |

**6類型:**

| 類型 | 例 |
|---|---|
| 身体的な攻撃 | 暴行、傷害 |
| 精神的な攻撃 | 脅迫、名誉毀損、侮辱、ひどい暴言 |
| 人間関係からの切り離し | 隔離、仲間外し、無視 |
| 過大な要求 | 業務上明らかに不要なことや遂行不可能なことの強制 |
| 過小な要求 | 能力や経験とかけ離れた程度の低い仕事を命じる |
| 個の侵害 | 私的なことに過度に立ち入る |

#### セクシュアルハラスメントの判断基準（均等法第11条）

| 類型 | 内容 |
|---|---|
| 対価型 | 性的な言動への拒否等により解雇、降格、減給等の不利益 |
| 環境型 | 性的な言動により就業環境が害される |

### ステップ6: 公益通報者保護法への対応

| 確認事項 | 内容 | 該当 |
|---|---|---|
| 公益通報該当性 | 通報対象事実（犯罪行為や法令違反）に関する通報か | ☐ |
| 通報者の保護 | 通報者に対する不利益取扱いの禁止 | ☐ |
| 内部通報窓口 | 窓口の設置義務（常時300人超の事業者は義務） | ☐ |
| 通報者の特定禁止 | 通報者を特定する情報の保護（従事者の守秘義務） | ☐ |
| 是正措置 | 通報対象事実について是正措置を講じる義務 | ☐ |

`[モデル知識 — 要確認: 2022年6月施行の改正公益通報者保護法の運用状況を確認すること]`

### ステップ7: 事実認定と評価

| 項目 | 内容 |
|---|---|
| 事実認定の基準 | 証拠の優越（民事上の基準） |
| 矛盾する証拠 | 各証拠の信用性を評価し、矛盾点を明確にする |
| 証拠の裏付け | ヒアリング内容と客観的証拠（メール、勤怠データ等）の整合性 |

### ステップ8: 懲戒処分の検討

| 確認事項 | 内容 | チェック |
|---|---|---|
| 就業規則の懲戒事由 | 認定された事実が就業規則の懲戒事由に該当するか | ☐ |
| 処分の相当性 | 非違行為の内容・程度に照らして処分が重すぎないか | ☐ |
| 弁明の機会 | 対象者に弁明の機会を付与したか | ☐ |
| 過去の処分との均衡 | 同種事案での過去の処分と均衡がとれているか | ☐ |
| 処分の種類 | 戒告 / けん責 / 減給 / 出勤停止 / 降格 / 諭旨解雇 / 懲戒解雇 | — |

**減給の上限（労基法第91条）:**

| 制限 | 内容 |
|---|---|
| 1回の額 | 平均賃金の1日分の半額を超えてはならない |
| 総額 | 一賃金支払期における賃金の総額の10分の1を超えてはならない |

## 弁護士確認ゲート（consequential-action gate）

**懲戒処分の勧告または調査報告書の最終版を出力する前に:** Read `## 利用者情報` in `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md`. If the Role is **法務部員・人事部員・その他**:

> 社内調査と懲戒処分には法的リスクが伴います — 手続の不備は懲戒処分の無効、名誉毀損、プライバシー侵害による損害賠償請求につながり得ます。この調査について弁護士に相談しましたか？
>
> **はい** の場合 → 進めます。
> **いいえ** の場合 → 以下の要約を弁護士にお持ちください:
>
> - 事案の概要と調査の経過
> - 認定された事実
> - 検討している対応措置（懲戒処分の種類と理由）
> - 就業規則の懲戒事由との対応関係
> - 弁明の機会の付与状況
> - 公益通報該当性の有無
> - 弁護士に聞くべきこと（この処分は有効か、手続に不備はないか、訴訟リスクはどの程度か）
>
> 弁護士をお探しの場合: 各地の弁護士会の紹介サービスをご利用ください。

Do not produce a final disciplinary recommendation past this gate without an explicit yes.

## 次のステップ決定ツリー

> **次のステップを選んでください:**
> 1. **調査報告書の作成** — 調査結果に基づく報告書の初稿を作成
> 2. **懲戒処分通知書の作成** — 処分内容を記載した通知書を作成
> 3. **再発防止策の策定** — 研修、制度改善等の再発防止策を策定
> 4. **被害者への対応** — 配置転換、メンタルヘルスケア等の被害者支援策を検討
> 5. **エスカレーション** — [エスカレーション先] への報告書を作成
> 6. **その他** — ご希望をお知らせください

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルがやらないこと

- 懲戒処分の決定を行うこと。事実認定と法的分析を支援する。
- ヒアリングを実施すること。ヒアリング項目の作成と記録の整理を行う。
- 刑事告訴・告発の手続を行うこと。必要性の検討は行う。
- カウンセリングや被害者支援を行うこと。外部専門機関の紹介は行う。
