1. Load `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 組織情報、労務管理体制。

## 目的

就業規則その他の社内規程を、労基法をはじめとする労働関連法令に適合する形でドラフトする。厚生労働省のモデル就業規則を参考にしつつ、組織の実態に合わせた内容にカスタマイズする。常時10人以上の労働者を使用する使用者は就業規則の作成・届出義務がある（労基法第89条）。

## コンテキストの読み込み

`~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 従業員数、事業場数、就業規則の整備状況、変形労働時間制の採用状況。

## 出力ヘッダー

Prepend the work-product header from `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → `## 出力設定` (it differs by user role — see `## 利用者情報`).

## ワークフロー

### ステップ1: 規程の種類と範囲の特定

対応可能な規程:

| 規程 | 作成の必要性 | 主な根拠法令 |
|---|---|---|
| 就業規則（本則） | 常時10人以上で義務 | 労基法第89条 |
| 賃金規程 | 就業規則の一部として | 労基法第89条2号 |
| 退職金規程 | 制度がある場合 | 労基法第89条3号の2 |
| 育児介護休業規程 | 事実上必須 | 育介法 |
| ハラスメント防止規程 | 全事業主に義務 | パワハラ防止法、均等法 |
| テレワーク（在宅勤務）規程 | テレワーク導入時 | テレワークガイドライン |
| 副業・兼業規程 | 副業許可時 | 副業・兼業ガイドライン |
| 秘密情報管理規程 | 推奨 | 不正競争防止法 |
| 公益通報者保護規程 | 300人超で義務 | 公益通報者保護法 |
| 安全衛生管理規程 | 推奨 | 安衛法 |
| 出張旅費規程 | 制度がある場合 | — |
| 慶弔見舞金規程 | 制度がある場合 | — |

以下を確認する:

> どの規程を作成しますか？ また、以下を教えてください:
> - 新規作成か、既存規程の改訂か
> - 参考にすべき既存の規程はあるか
> - 特に盛り込みたい内容や、組織固有の事情はあるか

### ステップ2: 就業規則（本則）の必須記載事項

就業規則を作成する場合、以下の事項を網羅する:

#### 絶対的必要記載事項（労基法第89条1-3号）

| # | 事項 | 記載内容の例 |
|---|---|---|
| 1 | 始業及び終業の時刻 | 9:00〜18:00 |
| 2 | 休憩時間 | 12:00〜13:00（60分） |
| 3 | 休日 | 土曜日、日曜日、祝日、年末年始 |
| 4 | 休暇 | 年次有給休暇、産前産後休業、育児休業、介護休業等 |
| 5 | 交替制の場合の就業時転換 | 該当する場合 |
| 6 | 賃金の決定・計算・支払方法 | 月給制、銀行振込 |
| 7 | 賃金の締切り・支払時期 | 月末締め、翌月25日払い |
| 8 | 昇給 | 年1回、4月 |
| 9 | 退職に関する事項（解雇の事由含む） | 退職手続、解雇事由 |

#### 相対的必要記載事項（労基法第89条3号の2〜10号）

定めがある場合に記載が必要:

| # | 事項 |
|---|---|
| 1 | 退職手当（適用範囲、決定・計算・支払方法、支払時期） |
| 2 | 臨時の賃金（賞与等）、最低賃金額 |
| 3 | 食費、作業用品その他の負担 |
| 4 | 安全及び衛生 |
| 5 | 職業訓練 |
| 6 | 災害補償及び業務外の傷病扶助 |
| 7 | 表彰及び制裁（種類及び程度） |
| 8 | その他当該事業場の全労働者に適用される定め |

### ステップ3: 各種規程のドラフト

規程の種類に応じて、以下の構成でドラフトする:

#### 共通構成

```
第1章 総則
  第1条（目的）
  第2条（適用範囲）
  第3条（定義） — 必要に応じて

第2章〜 各論（規程の種類により異なる）

附則
  施行日
  経過措置（既存の制度からの移行がある場合）
```

#### 育児介護休業規程のドラフト要素

| 章 | 内容 | 根拠法令 |
|---|---|---|
| 育児休業 | 対象者、期間、申出手続、延長、分割取得 | 育介法第5条〜 |
| 産後パパ育休 | 対象者、期間、分割、休業中の就業 | 育介法第9条の2〜 |
| 子の看護休暇 | 対象者、日数、取得単位 | 育介法第16条の2〜 |
| 育児のための短時間勤務 | 対象者、期間、勤務時間 | 育介法第23条 |
| 所定外労働の制限 | 対象者、請求手続 | 育介法第16条の8 |
| 時間外労働・深夜業の制限 | 対象者、請求手続 | 育介法第17条、第19条 |
| 介護休業 | 対象者、期間、分割、申出手続 | 育介法第11条〜 |
| 介護休暇 | 対象者、日数、取得単位 | 育介法第16条の5〜 |
| 介護のための短時間勤務等 | 措置の内容、期間 | 育介法第23条3項 |
| 不利益取扱いの禁止 | — | 育介法第10条等 |
| ハラスメントの防止 | — | 育介法第25条 |

#### ハラスメント防止規程のドラフト要素

| 章 | 内容 | 根拠法令 |
|---|---|---|
| パワーハラスメント | 定義（3要素6類型）、禁止行為 | パワハラ防止法（労推法第30条の2） |
| セクシュアルハラスメント | 定義、禁止行為 | 均等法第11条 |
| マタニティハラスメント | 定義、禁止行為 | 均等法第11条の3、育介法第25条 |
| 相談窓口 | 設置、担当者、相談方法 | 指針 |
| 調査手続 | 事実確認の方法、プライバシー保護 | 指針 |
| 対応措置 | 被害者への配慮、行為者への処分 | 指針 |
| 不利益取扱いの禁止 | 相談したことによる不利益取扱いの禁止 | 各法 |
| 再発防止 | 研修、啓発活動 | 指針 |

### ステップ4: 法令適合性チェック

ドラフトした規程が法定基準を下回っていないか確認する:

- 労基法の基準を下回る条項 → 無効（労基法第13条）
- 育介法の基準を下回る条項 → 無効
- 最低賃金を下回る賃金 → 無効（最低賃金法第4条2項）

### ステップ5: 届出準備

| 書類 | 内容 | 部数 |
|---|---|---|
| 就業規則（変更）届 | 所定の届出書式 | 2部 |
| 就業規則（変更後の全文） | ドラフトした規程 | 2部 |
| 意見書 | 過半数代表者の意見を記した書面 | 2部 |

## 出力

> **ドラフトであり、施行する規程ではない。** 就業規則その他の社内規程は法的拘束力を持ち、一度施行すると不利益変更の制約を受ける。弁護士または社会保険労務士が内容を確認し、専門家としての責任を持ってから施行すること。未確認のまま施行しないこと。

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルがやらないこと

- 規程を施行すること。ドラフトを作成する。施行は経営判断。
- 届出手続を行うこと。届出書類の作成は支援する。
- 過半数代表者を選出すること。選出手続の説明は行う。
- 既存の労働契約を変更すること。規程の変更は `/employment-legal-jp:handbook-updates` で対応。
