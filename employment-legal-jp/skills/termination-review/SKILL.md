## 目的

解雇は日本法上極めて厳格に規制されている。労働契約法第16条の解雇権濫用法理により、客観的に合理的な理由を欠き、社会通念上相当であると認められない解雇は無効となる。このスキルは、解雇・退職の各類型について法的リスクを体系的にチェックし、労働審判や訴訟に発展するリスクを事前に評価する。

## コンテキストの読み込み

`~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → エスカレーション体制、就業規則の解雇事由、雇用形態、高リスクフラグ。

## ワークフロー

### Step 1: 基本事実の確認

以下の情報を確認する（すべて1つのプロンプトで聞く）:

- **対象者:** 氏名またはポジション
- **雇用形態:** 正社員 / 契約社員（有期雇用） / パートタイマー / 試用期間中
- **勤続年数:** 入社日と現在までの期間
- **退職・解雇の種類:**
  - 普通解雇（能力不足、協調性欠如、健康上の理由等）
  - 整理解雇（経営上の必要性による人員削減）
  - 懲戒解雇（重大な規律違反）
  - 退職勧奨（合意退職を目的とした働きかけ）
  - 合意退職（双方の合意による退職）
  - 雇止め（有期契約の更新拒絶）
  - 試用期間中の本採用拒否
- **退職・解雇の理由:** 具体的な事実関係
- **就業規則の解雇事由:** 該当する条項
- **予定日:** いつの退職・解雇を予定しているか

### Step 2: 高リスクフラグスキャン

**これが最も重要なステップ。** 以下のすべてのフラグを確認する:

| フラグ | リスクの理由 | 確認事項 |
|---|---|---|
| **産前産後休業・育児休業の取得/申出** | 均等法第9条3項・育介法第10条違反（不利益取扱い） | 産休・育休の取得中または取得申出後か？ 復帰後間もないか？ |
| **ハラスメント申告歴** | 不利益取扱い禁止（均等法第11条2項等） | セクハラ・パワハラ・マタハラの相談・申告をしたか？ |
| **労働組合活動** | 不当労働行為（労組法第7条1号） | 組合員か？ 組合活動に参加しているか？ |
| **傷病休職中** | 休職期間満了前の解雇は原則無効 | 現在休職中か？ 休職期間は満了しているか？ |
| **有期契約の反復更新** | 雇止め法理（労契法第19条） | 何回更新しているか？ 更新の期待を持たせる言動はあったか？ |
| **内部通報歴** | 公益通報者保護法による保護 | 内部通報・公益通報を行ったか？ |
| **外国人労働者** | 在留資格との関係 | 在留資格の種類は？ 在留期間は？ 退職後の在留資格への影響は？ |
| **管理監督者性の疑義** | 名ばかり管理職の問題（残業代未払いリスク） | 管理監督者として扱っているが、実態は？ 経営への参画、出退勤の自由、待遇は？ |
| **メンタルヘルス不調** | 安全配慮義務違反（労契法第5条） | メンタル不調の原因が業務にあるか？ 産業医の意見は？ |
| **直近の賃金引下げ・降格** | 不利益変更との関連 | 解雇前に賃金引下げや降格を行ったか？ その手続は適正か？ |
| **指導・注意の記録不足** | 解雇の相当性の立証困難 | PIP、書面での注意・指導の記録はあるか？ 口頭のみか？ |
| **同種事案との均衡** | 懲戒権の濫用 | 同様の行為をした他の従業員への対応は？ |

**いずれかのフラグが該当 → `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` のエスカレーション表に従い、退職・解雇の実行前にエスカレーション。** 実行後ではなく、実行前に。

### Step 3: 解雇類型別分析

対象の解雇類型に応じて、以下の分析を行う:

#### 普通解雇（労契法第16条）

解雇権濫用法理の2要件を分析:

1. **客観的に合理的な理由** — 解雇理由が就業規則の解雇事由に該当するか。具体的な事実に基づいているか。
   - 能力不足: 具体的な能力不足の事実、改善の機会の付与、配置転換の検討
   - 協調性欠如: 具体的なエピソード、注意・指導の経緯
   - 健康上の理由: 医師の診断、復職可能性の検討、配置転換の検討
2. **社会通念上の相当性** — 解雇という重大な処分に相当するか。
   - 注意・指導の経緯は十分か
   - 改善の機会を与えたか（PIP等）
   - 配置転換等の解雇回避措置を検討したか
   - 従業員の事情（勤続年数、家族状況等）を考慮したか

> **判例参考:**
> - 高知放送事件（最判S52.1.31）— 2回の寝過ごしによるアナウンサー解雇を無効 `[モデル知識 — 要確認]`
> - セガ・エンタープライゼス事件（東京地決H11.10.15）— 能力不足解雇に改善機会の付与が必要 `[モデル知識 — 要確認]`

#### 整理解雇（4要件/4要素）

整理解雇の4要件（近年は4要素として総合判断する裁判例も多い）を分析:

1. **人員削減の必要性** — 経営上の必要性が客観的に認められるか。
   - 財務状況（売上減少、赤字等）の具体的数値
   - 人員削減以外のコスト削減策の実施状況
2. **解雇回避努力の履行** — 解雇以外の手段を十分に検討・実施したか。
   - 役員報酬の削減
   - 新規採用の停止
   - 希望退職の募集
   - 配置転換・出向
   - 一時帰休
   - 残業規制
3. **人選の合理性** — 被解雇者の選定基準が客観的・合理的か。
   - 選定基準の明確性（勤務成績、勤続年数、家族状況等）
   - 選定過程の透明性
   - 恣意的な選定でないか
4. **手続の妥当性** — 労働者・労働組合への説明・協議を十分に行ったか。
   - 整理解雇の必要性の説明
   - 人選基準の説明
   - 対象者との個別面談
   - 労働組合または過半数代表者との協議

> **判例参考:**
> - 東洋酸素事件（東京高判S54.10.29）— 整理解雇4要件の確立 `[モデル知識 — 要確認]`
> - ナショナル・ウエストミンスター銀行事件（東京地決H12.1.21）— 4要素としての総合判断 `[モデル知識 — 要確認]`

#### 懲戒解雇

1. **就業規則の懲戒事由該当性** — 就業規則に懲戒解雇事由が明記されているか。該当する事由は何か。
2. **相当性原則** — 非違行為の内容・程度に比して懲戒解雇は重すぎないか。
   - 非違行為の重大性
   - 過去の処分歴
   - 他の従業員との均衡
   - 情状酌量の余地
3. **適正手続** — 弁明の機会を付与したか。懲戒委員会等の手続を経たか。
4. **退職金の不支給・減額** — 就業規則の規定に基づく不支給・減額は可能か。「永年の勤続の功を抹消するほどの著しい背信行為」に該当するか。

> **判例参考:**
> - フジ興産事件（最判H15.10.10）— 就業規則に懲戒事由の定めが必要 `[モデル知識 — 要確認]`
> - ダイハツ工業事件（最判S58.9.16）— 相当性原則 `[モデル知識 — 要確認]`

#### 退職勧奨

1. **退職勧奨と退職強要の境界** — 退職強要にならない範囲で行われているか。
   - 面談の回数は適切か（多数回の長時間面談は退職強要とされるリスク）
   - 面談の態様は適切か（暴言、脅迫、精神的圧迫の有無）
   - 退職の意思がないことを明確にした後も繰り返していないか
2. **退職条件の提示** — 退職金の上乗せ、再就職支援等の条件は適切か。
3. **退職合意書の作成** — 合意退職の意思表示が自由な意思に基づくことを確認。

> **判例参考:**
> - 下関商業高校事件（最判S55.7.10）— 退職勧奨の限界 `[モデル知識 — 要確認]`
> - 日本IBM事件（東京高判H24.10.31）— 退職勧奨の適法性判断基準 `[モデル知識 — 要確認]`

#### 雇止め（労契法第19条）

1. **雇止め法理の適用判断:**
   - 有期契約が反復更新されて実質的に無期と同視できるか（第19条1号）
   - 更新されるとの合理的な期待があるか（第19条2号）
2. **更新回数と通算期間** — 何回更新し、通算何年か。
3. **更新時の手続** — 更新の都度契約書を作成しているか。更新基準を明示しているか。
4. **無期転換申込権（労契法第18条）** — 通算5年超の場合、無期転換申込権が発生している可能性。
5. **不更新条項の有効性** — 契約に不更新条項がある場合でも、従前の更新経緯に照らして雇止め法理が適用される可能性。

#### 試用期間中の本採用拒否

1. 試用期間は「解約権留保付労働契約」であり、通常の解雇より広い解約の自由があるが、完全に自由ではない。
2. 本採用拒否にも客観的に合理的な理由と社会通念上の相当性が必要（三菱樹脂事件・最大判S48.12.12）。
3. 採用時に知り得なかった事実に基づくものか。

### Step 4: 手続要件の確認

| 手続 | 根拠法令 | 内容 | チェック |
|---|---|---|---|
| 解雇予告 | 労基法第20条 | 30日前の予告、または30日分以上の平均賃金（解雇予告手当）の支払い | ☐ 予告済み / ☐ 予告手当支払い予定 |
| 解雇予告の除外 | 労基法第20条但書 | 天災事変・労働者の責めに帰すべき事由 → 労基署長の認定が必要 | ☐ 該当なし / ☐ 除外認定申請予定 |
| 解雇理由証明書 | 労基法第22条 | 労働者から請求があった場合、遅滞なく交付 | ☐ 準備済み |
| 退職時の証明 | 労基法第22条1項 | 使用期間、業務の種類、地位、賃金、退職の事由 | ☐ 準備済み |
| 離職証明書 | 雇用保険法第76条 | ハローワークへの届出（離職票の交付） | ☐ 手配済み |
| 社会保険の資格喪失届 | 健康保険法・厚生年金保険法 | 資格喪失日から5日以内に届出 | ☐ 手配済み |
| 源泉徴収票の交付 | 所得税法第226条 | 退職後1ヶ月以内に交付 | ☐ 手配済み |
| 有給休暇の残日数確認 | 労基法第39条 | 退職日までの消化または買取りの検討 | ☐ 確認済み |

### Step 5: 退職合意書の検討

退職勧奨・合意退職の場合、退職合意書に含めるべき事項:

1. **退職日** — 合意退職の場合は合意日以降の特定日
2. **退職事由** — 会社都合 / 自己都合（雇用保険の給付に影響）
3. **退職金・解決金** — 金額、支払時期、支払方法
4. **未払賃金・残業代の清算** — 未払いがないことの確認
5. **有給休暇の処理** — 買取りの有無
6. **競業避止義務** — 期間、地域、業種の合理的制限。代償措置の有無。
7. **秘密保持義務** — 在職中に知り得た営業秘密・個人情報の取扱い
8. **口外禁止条項** — 退職条件の第三者への非開示
9. **清算条項** — 双方に債権債務がないことの確認
10. **SNS等への投稿制限** — 会社の名誉・信用を毀損する投稿の禁止

### Step 6: 労働審判リスク評価

| 評価項目 | 内容 |
|---|---|
| **手続の概要** | 労働審判法に基づく迅速な紛争解決手続。原則3回以内の期日で終結。 |
| **申立費用** | 訴額に応じた収入印紙（解雇無効の場合は160万円とみなし → 印紙代は数千円程度） |
| **審理期間** | 平均約75日（3回の期日） |
| **解決金相場** | 月収の3〜6ヶ月分が中央値。勤続年数、解雇理由の強さ、バックペイの期間で変動。 `[モデル知識 — 要確認]` |
| **訴訟移行リスク** | 異議申立てにより訴訟に移行する確率（約2割） `[モデル知識 — 要確認]` |
| **バックペイ** | 解雇無効の場合、解雇日から復職日（または和解日）までの賃金支払義務 |

## 弁護士確認ゲート（consequential-action gate）

**「Go」レコメンデーションまたは実行可の退職日チェックリストを出力する前に:** Read `## 利用者情報` in `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md`. If the Role is **法務部員・人事部員・その他**:

> 従業員の解雇・退職には法的リスクが伴います — 解雇無効、損害賠償、労働審判等の紛争に発展する可能性があります。この退職・解雇について弁護士または社会保険労務士に相談しましたか？
>
> **はい** の場合 → 進めます。
> **いいえ** の場合 → 以下の要約を弁護士・社労士にお持ちください:
>
> - 対象者、雇用形態、退職・解雇の種類、理由、予定日
> - 検出された高リスクフラグとその詳細
> - 解雇類型分析の結果
> - 手続上の未対応事項
> - 退職合意書の検討事項
> - 労働審判に発展した場合の想定リスク
> - 弁護士に聞くべきこと（この解雇は有効か、指導記録は十分か、退職合意書に追加すべき条項はあるか）
>
> 弁護士・社労士をお探しの場合: 各地の弁護士会（日弁連のウェブサイトから検索可能）または社会保険労務士会の紹介サービスをご利用ください。労働問題は初回相談で方向性が決まることが多く、早期の相談が最も費用対効果が高い対応です。

Do not produce a "進行可" output past this gate without an explicit yes.

## このスキルがやらないこと

- 解雇の決定を下すこと。決定をチェックする。
- 退職面談を行うこと。管理職が行う。
- 判例法理を記憶から断定すること — 引用はすべてソースタグ付きで、確認を要する。
- 訴訟が起きないことを保証すること。明らかな問題を事前に発見しリスクを低減する。
