# /labor-management-agreement

1. Load `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 36協定の締結・届出状況、変形労働時間制・裁量労働制の採用状況。
2. Use the workflow below.
3. Check each agreement for validity, filing status, and compliance with legal limits.

---

## 目的

日本の労働法では、法定労働時間を超えて労働させるには36協定の締結・届出が必要であり（労基法第36条）、変形労働時間制やフレックスタイム制の導入にも労使協定が必要である。これらの労使協定は有効期限があり、届出を怠ると法令違反となる。このスキルは労使協定の管理・更新・適法性チェックを行う。

## ワークフロー

### Step 1: 管理対象の労使協定を特定

以下の労使協定の有無を確認する:

| 協定の種類 | 根拠法令 | 要届出 | 有無 |
|---|---|---|---|
| 36協定（時間外・休日労働） | 労基法第36条 | ✓ | ☐ |
| 1ヶ月単位の変形労働時間制 | 労基法第32条の2 | ✓ | ☐ |
| 1年単位の変形労働時間制 | 労基法第32条の4 | ✓ | ☐ |
| フレックスタイム制（清算期間1ヶ月超） | 労基法第32条の3 | ✓ | ☐ |
| 専門業務型裁量労働制 | 労基法第38条の3 | ✓ | ☐ |
| 企画業務型裁量労働制 | 労基法第38条の4 | ✓（労使委員会決議） | ☐ |
| 計画年休 | 労基法第39条6項 | ✗ | ☐ |
| 賃金控除（全額払いの例外） | 労基法第24条1項但書 | ✗ | ☐ |
| 事業場外みなし労働時間制 | 労基法第38条の2 | 条件付き | ☐ |

### Step 2: 36協定の詳細チェック

36協定が存在する場合、以下を確認する:

#### 基本事項
- 協定当事者（労働組合名 or 過半数代表者名）
- 過半数代表者の選出方法は適正か（管理監督者でないこと、民主的な手続による選出）
- 有効期間（推奨: 1年）
- 届出先労基署と届出日

#### 時間外労働の上限規制との適合性

| 上限 | 法定基準 | 協定内容 | 適合 |
|---|---|---|---|
| 月の上限（原則） | 45時間 | | ☐ |
| 年の上限（原則） | 360時間 | | ☐ |
| 月の上限（特別条項） | 100時間未満（休日労働含む） | | ☐ |
| 年の上限（特別条項） | 720時間 | | ☐ |
| 複数月平均（特別条項） | 2-6ヶ月平均80時間以内（休日労働含む） | | ☐ |
| 特別条項の発動回数 | 年6回以内 | | ☐ |

#### 適用猶予業種の確認
- 建設事業、自動車運転の業務、医師: 2024年4月から上限規制適用
- 該当する場合、経過措置の適用状況を確認

### Step 3: 有効期限管理

各協定の有効期限と更新期限を整理する:

```
| 協定 | 有効期限 | 更新期限（推奨） | ステータス |
|---|---|---|---|
| 36協定 | YYYY-MM-DD | 期限の1ヶ月前 | 有効 / 期限切れ / 要更新 |
| [その他] | | | |
```

> **アラート:** 有効期限が30日以内に到来する協定がある場合は 🟠 アラートを発出。期限切れの協定がある場合は 🔴 法令違反アラートを発出。

### Step 4: 届出状況の確認

届出が必要な協定について、届出の有無と届出先を確認する。未届出の場合:

> 🔴 **法令違反:** [協定名] が未届出です。届出なしに時間外労働を命じることは労基法違反であり、6ヶ月以下の懲役または30万円以下の罰金が科されます（労基法第119条1号）。速やかに所轄労基署に届け出てください。

## 弁護士/社会保険労務士確認ゲート

36協定をはじめとする労使協定は労働基準監督署への届出を要する法定書類である。

**役割が弁護士又は社会保険労務士でない場合:**

> ⚠️ この労使協定を締結・届出する前に、弁護士又は社会保険労務士に確認済みですか？
>
> 不備のある36協定のもとでの時間外労働は違法となります（労基法第32条・第119条）。
>
> 確認済みですか？ [はい/いいえ]
>
> 「いいえ」の場合 → 協定書の最終出力を生成しません。
