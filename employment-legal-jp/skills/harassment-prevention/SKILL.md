# /harassment-prevention

1. Load `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → ハラスメント相談窓口の設置状況、研修実施状況。
2. Use the workflow below.
3. Determine whether the request is about prevention infrastructure or incident response.

---

## 目的

2020年6月（中小企業は2022年4月）からパワーハラスメント防止措置が事業主に義務化された（労働施策総合推進法第30条の2）。セクシュアルハラスメント（均等法第11条）およびマタニティハラスメント（均等法第11条の3、育介法第25条）の防止措置も義務である。このスキルは防止体制の整備と事案対応の双方を支援する。

## ワークフロー

### Step 1: 対応の種類を判定

- **防止体制の整備・確認** → Step 2A へ
- **事案発生時の対応** → Step 2B へ
- **規程のレビュー** → Step 2C へ

### Step 2A: 防止体制の整備状況チェック

事業主が講ずべき措置（厚生労働大臣の指針）:

| # | 措置 | 状況 |
|---|---|---|
| 1 | 事業主の方針の明確化と周知・啓発 | ☐ |
| 2 | 就業規則等への懲戒規定の整備 | ☐ |
| 3 | 相談窓口の設置（内部・外部） | ☐ |
| 4 | 相談窓口担当者の適切な対応の確保 | ☐ |
| 5 | 事実関係の迅速かつ正確な確認 | ☐ |
| 6 | 被害者に対する適正な配慮措置 | ☐ |
| 7 | 行為者に対する適正な措置 | ☐ |
| 8 | 再発防止措置 | ☐ |
| 9 | 相談者・協力者等に対する不利益取扱いの禁止 | ☐ |
| 10 | プライバシー保護措置 | ☐ |

### Step 2B: 事案発生時の対応フロー

1. **相談の受付** — 相談者の話を傾聴。事実関係の概要を記録。
2. **事実確認** — 相談者、行為者、第三者からのヒアリング。
3. **ハラスメント該当性の判断:**
   - パワハラ: (1) 優越的な関係を背景とした言動、(2) 業務上必要かつ相当な範囲を超えた言動、(3) 労働者の就業環境が害されること — 3要素すべてを満たすか
   - セクハラ: 対価型（不利益を与える）/ 環境型（就業環境を害する）のいずれかに該当するか
   - マタハラ: 妊娠・出産・育児休業等を理由とする不利益取扱いに該当するか
4. **対応措置の決定** — 配置転換、懲戒処分、関係改善の援助等
5. **再発防止措置** — 研修の実施、方針の再周知等
6. **記録の保存** — 相談内容、事実確認の結果、対応措置を記録

> **弁護士確認ゲート:** 重大な事案（刑事事件に該当する可能性、損害賠償請求のリスク、行為者が役員等）の場合、弁護士への相談を推奨。`/employment-legal-jp:internal-investigation` で本格的な社内調査を開始することも検討。

### Step 2C: 規程のレビュー

ハラスメント防止規程に以下が含まれているか確認:
- ハラスメントの定義（パワハラ・セクハラ・マタハラの各類型）
- 禁止行為の具体例
- 相談窓口の設置と連絡先
- 相談から解決までのフロー
- 事実確認の方法
- 懲戒処分の規定
- 不利益取扱い禁止の明記
- プライバシー保護
- 再発防止措置

## 次のステップ決定ツリー

> **次のステップを選んでください:**
> 1. **ハラスメント防止規程のドラフト** — 規程の新規作成または改訂
> 2. **相談窓口体制の構築** — 内部・外部窓口の設計
> 3. **研修プログラムの設計** — 管理職向け・全社員向け研修の内容案
> 4. **社内調査の開始** — `/employment-legal-jp:internal-investigation` で調査を開始
> 5. **その他** — ご希望をお知らせください
