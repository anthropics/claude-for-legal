## 目的

就業規則の変更による労働条件の不利益変更は、原則として労働者の合意がなければ行えない（労契法第9条）。ただし、変更後の就業規則を周知し、変更が合理的なものである場合は有効となる（労契法第10条）。不利益変更の合理性判断を誤ると、変更が無効とされ、変更前の労働条件が適用される。このスキルは変更の不利益変更該当性と合理性を体系的に分析し、手続要件の充足も確認する。

## コンテキストの読み込み

`~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 就業規則の整備状況、労働組合の有無、過半数代表者の選出状況。

## ワークフロー

### ステップ1: 変更内容の把握

以下を確認する:

- どの条項を変更するのか
- 変更前の内容（現行規定）
- 変更後の内容（案）
- 変更の理由（法令改正対応 / 経営上の必要性 / 制度見直し / その他）
- 変更の時期（いつから適用するか）

新旧対照表がある場合は取得する。ない場合:

> 変更箇所を確認します。現行の就業規則と変更案を共有してください:
> - ファイルパス
> - テキストの直接貼付
> - 変更箇所の説明

### ステップ2: 不利益変更の該当性判断

変更が労働者にとって不利益な変更に該当するか分析する:

| 変更類型 | 不利益変更に該当する例 | 該当しない例 |
|---|---|---|
| 賃金・手当 | 基本給の引下げ、手当の廃止・減額 | 手当の新設、昇給幅の拡大 |
| 労働時間 | 所定労働時間の延長、休憩時間の短縮 | 労働時間の短縮、フレックス制の導入 |
| 休日・休暇 | 休日数の削減、有給休暇の付与日数減 | 休日の増加、新たな休暇制度の導入 |
| 退職金 | 支給率の引下げ、算定方法の不利な変更 | 退職金制度の新設 |
| 福利厚生 | 住宅手当の廃止、福利厚生制度の縮小 | 福利厚生の拡充 |
| 人事制度 | 降格要件の緩和、定年の引下げ | 定年の延長、昇進機会の拡大 |
| 懲戒 | 懲戒事由の追加、処分の重罰化 | — |

**不利益変更に該当しない場合 → ステップ4（手続要件の確認）に進む。**

**不利益変更に該当する場合 → ステップ3（合理性テスト）に進む。**

### ステップ3: 合理性テスト（労契法第10条）

不利益変更の合理性を以下の7要素で分析する。判例（秋北バス事件・最大判S43.12.25、第四銀行事件・最判H9.2.28）に基づく:

#### 要素1: 労働者の受ける不利益の程度

| 確認事項 | 内容 |
|---|---|
| 不利益の内容 | 具体的に何がどの程度不利益になるか |
| 金銭的影響 | 年収ベースでの影響額（概算） |
| 影響を受ける労働者の範囲 | 全員 / 特定の層（年齢、勤続年数等） |
| 不利益の重大性 | 賃金の直接的な減少は重大な不利益と評価される |

#### 要素2: 労働条件の変更の必要性

| 確認事項 | 内容 |
|---|---|
| 変更の背景 | 経営状況、業界動向、法令改正等 |
| 変更しない場合のリスク | 企業の存続・競争力への影響 |
| 客観的な裏付け | 財務データ等の客観的根拠 |
| 高度の必要性 | 賃金等の重要な労働条件の変更には高度の必要性が必要 |

#### 要素3: 変更後の就業規則の内容の相当性

| 確認事項 | 内容 |
|---|---|
| 同業他社との比較 | 業界水準と比較して相当か |
| 社会一般との比較 | 社会通念に照らして相当か |
| 代替措置・経過措置 | 不利益を緩和する措置があるか |

#### 要素4: 労働組合等との交渉の状況

| 確認事項 | 内容 |
|---|---|
| 交渉の相手方 | 労働組合 / 過半数代表者 |
| 交渉の経過 | 十分な説明と協議を行ったか |
| 合意の有無 | 組合の同意は得られたか |
| 過半数代表者の選出方法 | 民主的な手続で選出されているか（使用者が指名は不可） |

#### 要素5: その他の事情

| 確認事項 | 内容 |
|---|---|
| 経過措置 | 段階的な移行期間を設けているか |
| 代償措置 | 不利益を補う別の措置があるか |
| 他の労働条件との関連 | 総合的にみて労働者に不利益か |
| 変更の経緯 | 過去の変更経緯、労使の信頼関係 |

> **判例参考:**
> - 秋北バス事件（最大判S43.12.25）— 就業規則の不利益変更の合理性判断の枠組み `[モデル知識 — 要確認]`
> - 第四銀行事件（最判H9.2.28）— 合理性判断の具体的要素 `[モデル知識 — 要確認]`
> - みちのく銀行事件（最判H12.9.7）— 特定の層に重大な不利益を課す変更の限界 `[モデル知識 — 要確認]`
> - 大曲市農業協同組合事件（最判S63.2.16）— 賃金制度の変更と合理性 `[モデル知識 — 要確認]`

#### 合理性の総合評価

| 評価 | 説明 |
|---|---|
| ✅ 合理性あり | 変更の必要性が高く、不利益の程度が相対的に軽微で、十分な手続を経ている |
| 🟡 合理性は認められるが懸念あり | 一部の要素に弱い点があり、追加の措置（経過措置等）が推奨される |
| 🟠 合理性に疑義あり | 複数の要素で問題があり、変更内容の見直しまたは手続の補充が必要 |
| 🔴 合理性なし | 重大な不利益を課す変更であり、必要性・相当性・手続のいずれかに重大な欠陥がある |

### ステップ4: 手続要件の確認

| # | 手続 | 根拠 | 内容 | チェック |
|---|---|---|---|---|
| 1 | 過半数代表者の意見聴取 | 労基法第90条1項 | 労働組合（過半数組合がある場合）または過半数代表者からの意見聴取 | ☐ |
| 2 | 意見書の作成 | 労基法第90条2項 | 意見を記した書面を変更届に添付 | ☐ |
| 3 | 労基署への届出 | 労基法第89条 | 変更届、変更後の就業規則、意見書を所轄労基署に届出 | ☐ |
| 4 | 労働者への周知 | 労契法第7条、労基法第106条 | 備付け、掲示、書面交付、電子的方法のいずれかによる周知 | ☐ |

**過半数代表者の適格性チェック:**

| 確認事項 | 適格 | 不適格 |
|---|---|---|
| 選出方法 | 投票、挙手等の民主的な手続 | 使用者による指名 |
| 管理監督者でないこと | 一般の労働者 | 労基法第41条2号の管理監督者 |
| 選出目的の明示 | 「就業規則の変更についての意見を聴取する代表者」と明示 | 親睦会の代表等の自動就任 |

**注意:** 意見聴取は「同意」を得ることではない。反対意見であっても手続としては有効。ただし、不利益変更の合理性判断においては交渉の経緯が考慮される。

### ステップ5: 経過措置の検討

不利益変更の場合、以下の経過措置を検討する:

| 措置 | 内容 | 例 |
|---|---|---|
| 段階的移行 | 数年かけて段階的に新制度に移行 | 年1%ずつ退職金支給率を引下げ |
| 激変緩和措置 | 一定期間、不利益の上限を設定 | 年収減少幅を年10%以内に制限 |
| 代償措置 | 別の利益で不利益を補う | 手当廃止と引換えに基本給引上げ |
| 選択制 | 旧制度と新制度の選択を認める | 退職金制度の移行で選択権付与 |
| 適用除外 | 一定の層を変更の適用対象外とする | 定年間近の従業員は旧制度適用 |

### ステップ6: 新旧対照表の作成

変更箇所を新旧対照表形式で整理する:

```markdown
| 条項 | 現行規定 | 変更後 | 変更の理由 |
|---|---|---|---|
| 第○条 | [現行の文言] | [変更後の文言] | [変更理由] |
```

## 弁護士確認ゲート（consequential-action gate）

**「変更可」のレコメンデーションまたは変更届の最終版を出力する前に:** Read `## 利用者情報` in `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md`. If the Role is **法務部員・人事部員・その他**:

> 就業規則の不利益変更は、合理性が認められない場合、変更が無効とされるリスクがあります。無効とされた場合、変更前の労働条件が適用され、差額の支払義務が生じ得ます。この変更について弁護士または社会保険労務士に相談しましたか？
>
> **はい** の場合 → 進めます。
> **いいえ** の場合 → 以下の要約を弁護士・社労士にお持ちください:
>
> - 変更の内容（新旧対照表）
> - 不利益変更の該当性と合理性テストの結果
> - 影響を受ける労働者の範囲と金銭的影響
> - 手続の充足状況
> - 提案する経過措置
> - 弁護士に聞くべきこと（この変更は合理性が認められるか、経過措置は十分か、個別同意を取るべきか）
>
> 弁護士・社労士をお探しの場合: 各地の弁護士会または社会保険労務士会の紹介サービスをご利用ください。

Do not produce a "変更可" output past this gate without an explicit yes.

End with the next-steps decision tree per CLAUDE.md `## 出力設定`. Customize the options:

> **次のステップを選んでください:**
> 1. **変更届の準備** — 変更届、新旧対照表、意見書のセットを作成
> 2. **経過措置のドラフト** — 経過措置の具体的な条項案を作成
> 3. **従業員説明資料の作成** — 変更内容を分かりやすく説明する資料を作成
> 4. **個別同意書の作成** — 個別の労働者から同意を取得する場合の同意書を作成
> 5. **就業規則全体の監査** — `/employment-legal-jp:work-rules-audit` で全体の法令適合性を確認
> 6. **エスカレーション** — [エスカレーション先] への報告書を作成
> 7. **その他** — ご希望をお知らせください

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルがやらないこと

- 変更の決定を行うこと。合理性を分析し、リスクを評価する。
- 労基署への届出を行うこと。届出書類の作成は支援する。
- 従業員への説明会を実施すること。説明資料の作成は支援する。
- 労働組合との交渉を行うこと。交渉のポイントは助言する。
