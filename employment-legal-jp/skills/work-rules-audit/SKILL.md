# /work-rules-audit

1. Load `~/.claude/plugins/config/claude-for-legal/employment-legal-jp/CLAUDE.md` → 従業員数、事業場数、就業規則の整備状況。
2. Use the workflow below.
3. Output the audit report with findings categorized by severity.

---

## 目的

就業規則は使用者と労働者の権利義務を定める最も基本的な文書であり、常時10人以上の労働者を使用する使用者は作成・届出義務がある（労基法第89条）。法改正への追随が遅れると、法定基準を下回る条項が残存し、その条項は無効となる（労基法第13条）。このスキルは就業規則の法令適合性を体系的に監査する。

## ワークフロー

### Step 1: 就業規則の取得

就業規則のファイルパスまたはテキストが提供されていない場合:

> 就業規則を確認します。以下のいずれかで共有してください:
> - ファイルパス
> - テキストの直接貼付
> - 「就業規則がない」場合はその旨お知らせください

就業規則がない場合（従業員10人以上）:

> 🔴 **法令違反:** 常時10人以上の労働者を使用する事業場は就業規則の作成・届出が義務です（労基法第89条）。違反には30万円以下の罰金が科されます（労基法第120条1号）。`/employment-legal-jp:policy-drafting` で就業規則の作成を支援できます。

### Step 4: 法定基準との適合性チェック

就業規則の各条項が法定基準を下回っていないか確認する。下回る場合は無効（労基法第13条）:

| チェック項目 | 法定基準 | 根拠 | 適合 |
|---|---|---|---|
| 労働時間 | 1日8時間、1週40時間（特例44時間） | 労基法第32条 | ☐ |
| 休憩 | 6時間超→45分、8時間超→1時間 | 労基法第34条 | ☐ |
| 休日 | 毎週少なくとも1日、または4週4日 | 労基法第35条 | ☐ |
| 時間外・休日労働の割増率 | 時間外25%、休日35%、深夜25%、月60時間超50% | 労基法第37条 | ☐ |
| 年次有給休暇 | 6ヶ月継続勤務+8割出勤→10日、以後加算 | 労基法第39条 | ☐ |
| 年5日の有給休暇取得義務 | 10日以上付与者に年5日を時季指定して取得させる | 労基法第39条7項 | ☐ |
| 産前産後休業 | 産前6週（多胎14週）、産後8週 | 労基法第65条 | ☐ |
| 育児休業 | 原則1歳まで（条件により2歳まで延長） | 育介法第5条 | ☐ |
| 介護休業 | 対象家族1人につき通算93日、3回まで分割可 | 育介法第11条 | ☐ |
| 解雇予告 | 30日前の予告または30日分の平均賃金 | 労基法第20条 | ☐ |
| 解雇制限 | 業務上傷病の休業中+30日、産前産後休業中+30日 | 労基法第19条 | ☐ |

## 弁護士/社会保険労務士確認ゲート

就業規則の修正・変更は法律事務に該当しうる。

**役割が弁護士又は社会保険労務士でない場合:**

> ⚠️ この就業規則の修正案を実施する前に、弁護士又は社会保険労務士に確認済みですか？
>
> 就業規則の変更は労働基準法・労働契約法上の手続が必要です。
>
> 確認済みですか？ [はい/いいえ]
>
> 「いいえ」の場合 → 修正案の最終出力を生成しません。

## 次のステップ決定ツリー

> **次のステップを選んでください:**
> 1. **是正ドラフトの作成** — 違反・不備のある条項の改定案を作成
> 2. **就業規則変更届の準備** — 変更届、意見書、新旧対照表を作成
> 3. **規程全体の改訂** — `/employment-legal-jp:policy-drafting` で規程の全面改訂
> 4. **その他** — ご希望をお知らせください
