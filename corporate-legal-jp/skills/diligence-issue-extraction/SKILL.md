# /diligence-issue-extraction（DDイシュー抽出）

1. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## M&A・組織再編`（DDカテゴリ、重要性基準）を読み込む。
2. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/deals/[code]/deal-context.md` → ディール固有の基準を読み込む。
3. 以下のワークフローに従う。
4. 対象書類を読み込み、重要性フィルタを適用してイシューを抽出。
5. ハウスメモフォーマットでファインディングスを出力。同意・許認可等はクロージングチェックリストへハンドオフ。

---

## コンテキストの読み込み

- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → DD構成（カテゴリ、重要性基準）
- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → イシューメモフォーマット
- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/deals/[code]/deal-context.md` → ディール固有の基準、VDRの場所

deal-context.mdが存在しない場合は、どのディールか確認。

---

## 目的

M&Aにおける法務デューディリジェンスの効率化。対象会社の法的リスクを体系的に抽出し、ディールチームが意思決定に必要な情報を提供する。DDの対象書類は数百から数千件に及ぶ場合があるが、ディールに影響する重要なイシューを漏れなく特定する。

---

## ワークフロー

### Step 1: VDRの棚卸し

VDR MCP（Box等）が接続されている場合、インデックスを取得。VDRフォルダをDDカテゴリにマッピングし、カバレッジの不足をフラグ。

```markdown
## VDR棚卸し: [ディールコード]

| DDカテゴリ | VDRフォルダ | 書類数 | ステータス |
|---|---|---|---|
| 会社組織 | /01-会社組織 | 45 | レビュー済み |
| 重要契約 | /02-契約 | 312 | 進行中 |
| 知的財産 | /03-知財 | 89 | 未着手 |
| 許認可 | /04-許認可 | 23 | 未着手 |
| 労務 | /05-労務 | 156 | 未着手 |
| [等] | | | |

**不足:** [VDRにコンテンツのないDDカテゴリ — 追加資料の依頼が必要]
```

### Step 2: 重要性フィルタの適用

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`又はdeal-contextの基準に従う。

### Step 3: イシューの抽出

各書類について、カテゴリごとの標準的な検討事項に照らしてチェック:

**重要契約 — 標準抽出項目:**
- チェンジ・オブ・コントロール条項（本ディールでトリガーされるか？同意が必要か？）
- 債権譲渡制限特約（民法第466条 — 2020年改正後は譲渡制限特約があっても譲渡自体は有効だが、対抗要件の問題あり）
- 契約上の地位の移転制限（相手方の同意が必要か？）
- 競業避止条項（買主の事業を制限するか？）
- 独占条項（exclusivity）
- 解除条項（ディールを理由に相手方が解除できるか？）
- 下請法対象取引の有無（下請法第2条 — 資本金区分と取引類型に基づく該当性）
- MFN条項（最恵国待遇 — 価格制約）
- 自動更新条項と解約予告期間
- 連帯保証・担保提供の有無

**会社組織 — 標準抽出項目:**
- 株主構成の正確性、新株予約権・転換権の有無
- 取締役会決議の適法性（定足数、特別利害関係取締役の処理）
- 株主間契約の制限（ドラッグ・アロング、タグ・アロング、先買権、共同売却権）
- 子会社・関連会社の構成と関連当事者取引
- 定款の内容確認（機関設計の適法性）

**許認可 — 標準抽出項目（日本特有）:**
- 業法上の許認可の一覧と有効期限
- 許認可の承継可否（合併=包括承継、事業譲渡=個別取得）
- 許認可の欠格事由への該当可能性（役員変更に伴うもの）
- 更新手続の履行状況
- 許認可条件の遵守状況

**労務 — 標準抽出項目（日本特有の拡充項目）:**
- **未払残業代リスク** — 労働時間管理の実態、固定残業代の有効性、管理監督者（労基法第41条第2号）の該当性
- **就業規則の整備状況** — 常時10人以上の労働者を使用する事業場における届出義務（労基法第89条）
- **36協定** — 時間外労働・休日労働に関する労使協定の締結・届出状況、上限規制の遵守
- **ハラスメント事案** — セクハラ・パワハラ・マタハラ等の相談・通報記録、対応状況
- **非正規雇用** — 有期契約労働者の雇止め法理（労契法第19条）、無期転換権（労契法第18条）
- **退職給付債務** — 退職金規程の内容、引当金の計上状況
- **労働組合** — 組合の有無、労働協約の内容
- **外国人雇用** — 在留資格の確認、不法就労リスク

**知的財産 — 標準抽出項目:**
- **職務発明補償** — 職務発明規程の整備状況、相当の利益の支払い（特許法第35条）
- 特許・商標・意匠の権利帰属の連鎖（従業員・委託先からの適切な譲渡があるか）
- ライセンス契約の承継可否（ChoCに基づく解除権の有無）
- オープンソースソフトウェアの利用状況（コピーレフトリスク）
- 知財訴訟・紛争の有無

**環境 — 標準抽出項目（日本特有）:**
- **土壌汚染対策法** — 土地の形質変更・用途変更に伴う調査義務、汚染の有無
- 廃棄物処理法 — マニフェストの管理状況、適正処理の確認
- 有害物質の使用・保管状況
- 環境関連の訴訟・行政処分の有無
- アスベスト使用の有無（建物）

**反社会的勢力 — 必須チェック項目:**
- **反社チェックの実施状況** — 対象会社の役員・株主・主要取引先
- 暴力団排除条項の契約への組込み状況
- 過去の反社関連事案の有無
- → `/corporate-legal-jp:anti-organized-crime-screening`と連携

**訴訟・紛争 — 標準抽出項目:**
- 係属中の訴訟・仲裁・調停
- 行政処分・行政指導の有無
- 潜在的な訴訟リスク（クレーム、内部通報等）
- 製造物責任（PL法）リスク

**コンプライアンス — 標準抽出項目:**
- 内部統制体制の整備状況
- 個人情報保護法への対応状況（プライバシーポリシー、安全管理措置）
- 贈収賄防止体制 → `/corporate-legal-jp:zoushuwai-boushi`と連携
- 独占禁止法・下請法の遵守状況

### Step 4: ファインディングスの記述

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`のイシューメモフォーマットに従う。シードメモの構造を再現。

```
イシュー#N: [タイトル]
カテゴリ: [DDカテゴリ]
重要度: [赤 / 黄 / 緑]
書類: [VDRパス + 書類名]
ファインディング: [書類の内容とそれが重要な理由]
推奨対応: [表明保証への反映 / 補償条項 / 同意取得 / 価格調整 / ディールキラー]
```

**重要度の基準（赤/黄/緑）:**
- 赤: ディールの価値又は構造に影響。重要取引先のCoC条項で同意取得困難。未開示の重要訴訟。許認可の承継不可。未払残業代の潜在債務が多額。
- 黄: 対応が必要だが解決可能。同意取得が必要だが取得見込みあり。就業規則の不備（是正可能）。反社チェック未実施の取引先あり。
- 緑: 記録のため。表明保証と整合的。特段のアクション不要。

**表明保証の日本慣行への対応:**
- 「知り得る限り」（to the knowledge of）の範囲 — 日本の実務では「合理的な調査を行った上で知り得る限り」と「現実に知っている限り」を区別
- knowledge qualifierの対象者の範囲（代表取締役のみか、担当取締役を含むか）
- サンドバッギング条項の有効性（日本法上の議論あり）

### Step 5: カテゴリごとの集約

DDカテゴリごとにファインディングスをグルーピング。カテゴリ内では重要度順にソート。

```markdown
[成果物ヘッダー — ## 出力設定に基づく]

# DDイシュー: [ディールコード] — [カテゴリ]

**レビュー書類:** [N]件中[M]件
**カバレッジ:** [全件 / X万円超 / 上位N件]
**ファインディングス:** [N]赤 [N]黄 [N]緑

---

### ボトムライン

[赤N件・黄N件 — ディールチームが知るべき最重要事項の要約]

---

[各ファインディングス]

---

## 不足事項

- [VDRにない依頼項目]
- [参照されているが未提供の書類]
```

## ハンドオフ

- **`ai-tool-handoff`へ:** Luminance/MNTSQ等が利用可能な場合、大量の契約レビューを委託。本スキルは判断を要する書類（サイドレター、覚書、複雑な契約）を担当。
- **`deal-team-summary`へ:** 集約されたファインディングスがディールチームブリーフに供給。
- **`material-contract-schedule`へ:** 契約レベルの抽出結果が開示スケジュールに供給。
- **`closing-checklist`へ:** クロージング前アクションを伴うすべてのファインディングス:
  - **株主総会決議・取締役会決議** — 組織再編に必要な社内手続
  - **規制当局への届出** — 独禁法、外為法、業法上の届出
  - **第三者からの同意** — CoC条項、契約譲渡制限
  - **許認可の取得・変更** — 承継不可の許認可の新規取得
  - **労働者保護手続** — 労働契約承継法に基づく手続
  - **債権者保護手続** — 合併・会社分割の場合

---

## バッチ処理

大量のカテゴリ（300件の契約等）はバッチで処理。各バッチ後にイシューリストを更新し、赤のアイテムは即座にフラグ — カテゴリ全体の処理完了を待たない。

---

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- DD対象会社の選定・DD範囲の決定 — 依頼者・弁護士の判断
- 会計・税務DDの実施 — 会計士・税理士の領域
- 買収価格への影響分析 — 財務アドバイザーの領域
- 重要性判断のボーダーラインケースの最終判定 — 基準を適用するが、最終判断は弁護士
- 表明保証の交渉 — ファインディングスは交渉の材料であり、交渉そのものではない
