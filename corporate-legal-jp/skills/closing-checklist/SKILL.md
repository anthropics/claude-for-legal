# /closing-checklist（M&Aクロージングチェックリスト）

1. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/deals/[code]/closing-checklist.yaml`を読み込み、以下のモードで処理。
2. ステータス更新の場合: Mode 3（アイテム更新）。
3. それ以外: Mode 4 — ブロッカー、クリティカルパス、クロージングまでの日数。

---

## コンテキストの読み込み

- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## M&A・組織再編`
- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/deals/[code]/deal-context.md` → ディール固有のコンテキスト

---

## 目的

ディールのクロージングに必要な前提条件の充足状況、クロージング書類の準備状況を一元管理し、ブロッカーを可視化する。株式譲渡契約（SPA）、事業譲渡契約、合併契約、会社分割契約、株式交換契約等の各種M&Aスキームに対応。

## 弁護士確認ゲート

M&Aクロージング手続は法律事務に該当しうる。

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` の `## 利用者情報` → `役割` を確認する。

**役割が弁護士でない場合:**

> ⚠️ このクロージングチェックリストに基づき手続を実行する前に、弁護士に確認済みですか？
>
> M&Aクロージング手続の実行は法律事務に該当する可能性があります。
>
> 弁護士に確認済みですか？ [はい/いいえ]
>
> 「いいえ」の場合 → このゲートを超えて最終出力を生成しません。

**役割が弁護士の場合:** ゲートなしで続行。

## Mode 1: 契約書からの初期化

契約書（SPA、事業譲渡契約、合併契約等）を読み込み、以下を抽出:

- すべての前提条件（条件先行条項）
- すべてのクロージング書類
- クロージング前に期限のあるすべてのコベナンツ

各アイテムに契約条項の引用を付す。

### 日本のM&A特有の前提条件の抽出

**1. 独占禁止法 — 企業結合届出（公正取引委員会）**

届出基準の確認:
- **国内売上高合算額200億円超**（企業結合する一方の当事会社グループ）かつ
- **国内売上高50億円超**（他方の当事会社グループ）
- 待機期間: 届出受理日から**30日間**（ただし短縮申請可。延長される場合あり）
- 第二次審査に移行した場合: 報告等の要請から**90日以内**又は届出受理日から**120日**のいずれか遅い日まで

届出基準を契約書・ディールコンテキストから確認し、必要な場合はチェックリストに追加。基準の判定が微妙な場合は`[要確認 — 弁護士に確認]`とフラグ。

**2. 外為法 — 事前届出（財務省・日本銀行）**

- 外国投資家による**指定業種**への投資は事前届出が必要（外為法第27条）
- 指定業種: 武器、航空機、宇宙、原子力、電気・ガス・水道、通信、放送、鉄道、旅客運送、情報処理関連（サイバーセキュリティ）等
- 待機期間: 届出受理日から**30日間**（短縮される場合あり、延長は最長5ヶ月）
- 対象会社の業種が指定業種に該当するか確認。コア業種・非コア業種の区別にも注意。

**3. 株主総会特別決議**

組織再編の類型に応じて必要な決議:

| 類型 | 消滅会社・分割会社側 | 存続会社・新設会社側 |
|---|---|---|
| 吸収合併 | 株主総会特別決議（会社法第783条） | 株主総会特別決議（会社法第795条）※簡易合併の場合は不要 |
| 新設合併 | 株主総会特別決議（会社法第804条） | — |
| 吸収分割 | 株主総会特別決議（会社法第783条） | 株主総会特別決議（会社法第795条）※簡易分割の場合は不要 |
| 新設分割 | 株主総会特別決議（会社法第804条） | — |
| 株式交換 | 株主総会特別決議（会社法第783条） | 株主総会特別決議（会社法第795条）※簡易株式交換の場合は不要 |
| 株式移転 | 株主総会特別決議（会社法第804条） | — |
| 事業譲渡（重要な一部以上） | 株主総会特別決議（会社法第467条） | 株主総会特別決議（事業の全部譲受けの場合、会社法第467条） |

特別決議の要件: 議決権の過半数を有する株主が出席し、出席株主の議決権の**2/3以上**の賛成（会社法第309条第2項）。

**簡易手続・略式手続の適用可否:**
- **簡易手続:** 存続会社等が交付する対価が純資産額の**1/5以下**の場合（会社法第796条第2項）
- **略式手続:** 特別支配会社（議決権の**90%以上**を保有）が行う場合（会社法第784条、第796条）

**4. 反対株主の株式買取請求権**

- 組織再編に反対する株主は、公正な価格での買取りを請求できる（会社法第785条、第797条、第806条等）
- 通知・公告から**20日以内**に買取請求が可能
- 価格の協議が調わない場合は裁判所への価格決定申立て（**30日以内**）

**5. 債権者保護手続**

合併・会社分割の場合に必要（会社法第789条、第799条、第810条等）:
- **官報公告** + **知れている債権者への個別催告**
- 異議申述期間: **1ヶ月以上**
- 異議を述べた債権者に対する弁済、担保提供又は信託
- 定款で日刊新聞紙又は電子公告を公告方法としている場合は個別催告の省略可（ダブル公告）

**6. 労働者保護手続（会社分割の場合）**

労働契約承継法に基づく手続:
- **労働者との事前協議**（7条措置 — 分割契約等の承認を受ける株主総会の日の2週間前の日の前日まで）
- **労働者への通知**（2条通知 — 株主総会の日の2週間前まで）
- 承継される事業に主として従事する労働者: 異議申出期間（通知日から株主総会の日の前日まで、最低13日間）
- 承継されない事業に主として従事する労働者: 異議申出期間あり

**7. 許認可の承継・変更**

- **合併・会社分割:** 許認可は原則として**包括承継**されるが、業法によっては個別の届出・認可が必要
- **事業譲渡:** 許認可は**承継されない** — 新規取得が必要
- 業法別の確認が必要 → `/corporate-legal-jp:license-permit-tracker`と連携

**8. チェンジ・オブ・コントロール条項に基づく同意**

- 重要契約のCoC条項を確認 → `/corporate-legal-jp:material-contract-schedule`と連携
- 同意取得に要する時間を見積もり

## Mode 2: DDファインディングスからの取込み

上流スキルがクロージング前アクションを伴うファインディングスを生成した場合にトリガーされる:

- **`diligence-issue-extraction`のファインディングス** — 同意取得、株主総会決議、取締役会決議、届出、許認可取得等
- **`material-contract-schedule`のCoC/譲渡制限アイテム** — チェンジ・オブ・コントロール条項、債権譲渡制限条項
- **`deal-team-summary`の出力** — エグゼクティブブリーフに集約されたクロージングアクション

ハンドオフスキーマ:

```yaml
handoff:
  item: "[相手方又はアクション（一行）]"
  category: "[第三者同意 | 社内手続 | 規制当局届出 | 許認可 | 債権者保護 | 労働者保護 | クロージング書類]"
  source: "[契約名 / 条文 / VDRパス]"
  blocking: true
  severity: "[赤 / 黄 / 緑]"

  counterparty: "[例: 株式会社ダンモア]"
  approval_body: "[株主総会 / 取締役会 / 規制当局]"
  approval_threshold: "[例: 議決権の2/3以上]"
  statutory_source: "[例: 会社法第783条第1項]"
  estimated_time_to_complete: "[例: 30日]"
  must_occur_before: "[例: クロージング / 効力発生日]"
```

チェックリストに追加。重複は（相手方＋アクション種別）で判定。

## クリティカルパス分析

すべてのブロッカーが同等ではない。独禁法のクリアランスに30日以上かかる場合はクリティカルパス。登記事項証明書の取得が2日で済む場合はクリティカルパスではない。

各ブロッカーについて完了までの所要時間を見積もる。`（期限 - 今日）< 見積所要時間` のアイテムがリスクあり。ステータス報告の最上部に表示。

## 組織再編の類型別チェックリスト

### 合併（吸収合併・新設合併）

```
□ 合併契約の締結（吸収合併）/ 合併計画の作成（新設合併）
□ 事前開示書類の本店備置き（効力発生日の2週間前〜効力発生後6ヶ月）
□ 株主総会特別決議
□ 反対株主への通知・公告
□ 株式買取請求への対応
□ 債権者保護手続（官報公告 + 個別催告）
□ 独禁法届出（該当する場合）
□ 外為法届出（該当する場合）
□ 許認可の承継確認・届出
□ 登記申請書類の準備（合併の効力発生日から2週間以内に登記）
□ 事後開示書類の本店備置き
```

### 会社分割（吸収分割・新設分割）

```
□ 分割契約の締結（吸収分割）/ 分割計画の作成（新設分割）
□ 事前開示書類の本店備置き
□ 株主総会特別決議
□ 反対株主への通知・公告
□ 株式買取請求への対応
□ 債権者保護手続
□ 労働契約承継法に基づく手続:
  □ 労働者との事前協議（7条措置）
  □ 労働者への通知（2条通知）
  □ 異議申出期間の確保
□ 独禁法届出（該当する場合）
□ 許認可の承継確認・届出
□ 登記申請書類の準備
□ 事後開示書類の本店備置き
```

### 株式交換・株式移転

```
□ 株式交換契約の締結 / 株式移転計画の作成
□ 事前開示書類の本店備置き
□ 株主総会特別決議
□ 反対株主への通知・公告
□ 株式買取請求への対応
□ 債権者保護手続（新株予約権付社債の承継がある場合等）
□ 独禁法届出（該当する場合）
□ 登記申請書類の準備
□ 事後開示書類の本店備置き
```

### 事業譲渡

```
□ 事業譲渡契約の締結
□ 株主総会特別決議（重要な一部以上の譲渡の場合）
□ 反対株主への通知・公告
□ 株式買取請求への対応
□ 個別の契約の承継手続（債権譲渡、債務引受、契約上の地位の移転）
□ 許認可の新規取得（事業譲渡では許認可は承継されない）
□ 労働者の転籍同意の取得
□ 独禁法届出（該当する場合）
□ 商号続用の場合の責任（会社法第22条）への対応
```

### 株式譲渡

```
□ 株式譲渡契約の締結
□ 譲渡制限株式の場合: 取締役会（又は株主総会）の承認
□ 株主名簿の名義書換
□ 取締役・監査役の変更（必要な場合）
□ 独禁法届出（該当する場合）
□ 外為法届出（該当する場合）
□ 重要契約のCoC条項への対応
```

## 弁護士確認ゲート（クロージング認定）

**「全前提条件充足」の認定又はクロージングメモを作成する前:**

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`の`## 利用者情報`の役割を確認。役割が**非法務担当者**の場合:

> クロージング条件の充足認定（又はそれを主張するクロージングメモの作成）は法的効果を伴います — 資金移動やクロージング後の義務の起点となります。弁護士の確認は済んでいますか？未確認の場合、弁護士に持っていくためのブリーフを以下に示します:
>
> - 全前提条件のリスト（完了・進行中・未着手のステータス付き）
> - 充足の証拠が不十分なアイテム
> - 期限に間に合わないアイテムに必要なウェイバー
> - 未解決事項（未取得の同意、MAC/表明保証違反リスク等）
> - 弁護士に確認すべき事項

弁護士の明示的な確認なしに「クロージング可能」の認定を出力しない。ステータス追跡と「ブロッカー報告」はゲート不要。

## ハンドオフ

- **`diligence-issue-extraction`から:** クロージング前アクションを伴うファインディングス
- **`material-contract-schedule`から:** CoC条項・譲渡制限条項
- **`license-permit-tracker`へ:** 許認可の承継・取得が必要な場合
- **`integration-management`へ:** クロージング後アイテム

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- 前提条件の法的充足性の判断 — 弁護士の判断
- 届出書の作成・提出 — 弁護士又は専門家が対応
- クロージングの実行判断 — 依頼者・弁護士の判断
- 同意の取得・届出の提出 — 本スキルはそれらが必要であることを追跡する
- 契約書の作成 — 本スキルは追跡であり、ドラフトではない
