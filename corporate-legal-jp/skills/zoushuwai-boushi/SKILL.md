# /zoushuwai-boushi（贈収賄防止）

1. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`を読み込む。
2. 以下のワークフローに従い、贈収賄防止に関するコンプライアンス管理を支援。

---

## コンテキストの読み込み

- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## 組織情報`（業種、海外展開の有無）
- 社内の贈収賄防止方針・ガイドラインが共有されている場合はそれを参照

---

## 目的

贈収賄は、日本法（刑法、不正競争防止法）のみならず、米国FCPA、英国UK Bribery Act等の域外適用の対象にもなりうる重大なコンプライアンスリスクである。本スキルは贈収賄防止のコンプライアンス管理を法務の観点から支援する。

---

## Step 1: 適用法令の確認

### 日本法

**刑法第197条-第198条（贈賄罪・収賄罪）:**
- **贈賄罪（刑法第198条）:** 公務員に対し、その職務に関し、賄賂を供与し、又はその申込み若しくは約束をした者 — 3年以下の懲役又は250万円以下の罰金
- **収賄罪（刑法第197条）:** 公務員が職務に関し賄賂を収受・要求・約束 — 5年以下の懲役
- 「公務員」には、国家公務員、地方公務員、みなし公務員（独立行政法人等の役職員）を含む

**不正競争防止法第18条（外国公務員贈賄罪）:**
- 外国公務員等に対し、国際的な商取引に関して営業上の不正の利益を得るために、金銭その他の利益を供与し、又はその申込み・約束をした者 — **5年以下の懲役若しくは500万円以下の罰金**（又は併科）
- **法人処罰:** **3億円以下の罰金**（同法第22条第1項第3号）
- 「外国公務員等」の範囲: 外国政府の職員、国際機関の職員、外国政府出資企業の役職員等

**国家公務員倫理法・国家公務員倫理規程:**
- 国家公務員が利害関係者から受けてはならない利益供与の類型を規定
- 5,000円以上の飲食は届出が必要（倫理規程第8条）

### 域外適用リスクのある外国法

**米国FCPA（海外腐敗行為防止法）:**
- 適用対象: 米国の発行体、米国内で行為を行った者、**共謀者**
- 日本企業への適用リスク: 米国子会社がある場合、米国上場の場合、米国の銀行口座を使用する場合、米国内でのEメール送受信
- 罰則: 法人に対し最大**2億ドル**の罰金、個人に対し最大**25万ドル**の罰金及び**5年**の懲役

**英国UK Bribery Act 2010:**
- **第7条（贈賄防止の懈怠）:** 企業が贈賄を防止するための適切な手続を有していない場合の法人責任（strict liability に近い）
- 適用対象: 英国で事業の一部を行うすべての企業（日本企業にも適用可能性）
- 抗弁: **adequate procedures**（適切な手続）の存在を立証すれば免責
- ファシリテーション・ペイメント: UK Bribery Actでは**禁止**（FCPAとの相違点）

```
□ 自社に適用される法令の範囲を確認
□ 海外子会社・海外取引先との関係でFCPA/UK Bribery Actの適用リスクがあるか
□ ファシリテーション・ペイメントの取扱いについて方針があるか
```

## Step 2: 贈答・接待の社内基準の確認

### 典型的な社内基準の要素

```
□ 贈答・接待の金額基準（事前承認が必要な金額の閾値）
□ 公務員への贈答・接待の禁止又は厳格な制限
□ 外国公務員への贈答・接待に関する追加的制限
□ 承認権限者の明確化（金額別の承認レベル）
□ 記録・報告の義務
□ 禁止される贈答・接待の類型（現金、旅行招待等）
```

### 贈答・接待の承認申請対応

ユーザーから贈答・接待の承認申請があった場合:

> 以下の情報をお知らせください:
>
> 1. **相手方:** 氏名、所属（企業名 / 官公庁名）、役職
> 2. **相手方の性質:** 民間企業 / 国家公務員 / 地方公務員 / みなし公務員 / 外国公務員
> 3. **贈答・接待の内容:** 食事、贈答品、ゴルフ等
> 4. **金額（見込み）:** 一人当たり及び総額
> 5. **目的:** 取引上の関係維持、会議の一環等
> 6. **取引との関係:** 入札中、契約交渉中、許認可申請中等の状況があるか

**リスク評価の観点:**

| リスク要素 | 高リスク | 低リスク |
|---|---|---|
| 相手方 | 公務員・外国公務員 | 民間企業 |
| 金額 | 社内基準超過 | 社内基準内 |
| タイミング | 入札・許認可申請中 | 通常の取引関係 |
| 頻度 | 同一相手方に頻繁 | 通常の範囲内 |
| 内容 | 現金・旅行・高額品 | 食事・一般的な贈答品 |

## Step 3: エージェント・コンサルタント管理

海外における代理人・コンサルタントの起用は贈賄リスクの重要な源泉:

```
□ エージェント・コンサルタントの選定プロセスにDD（バックグラウンドチェック）が含まれているか
□ 報酬の妥当性（市場水準との比較）
□ 契約書に贈賄防止条項が含まれているか
□ 支払先・支払方法の確認（第三者への支払い、オフショア口座への支払い等）
□ 定期的な監査・モニタリングの実施
□ レッドフラグ（異常な支払要求、政府関係者との関係等）の確認
```

**レッドフラグの例:**
- エージェントが政府関係者の親族・知人
- 報酬が市場水準を大幅に上回る
- 成功報酬のみの報酬体系
- 第三者口座又はオフショア口座への支払い要求
- 現金での支払い要求
- サービスの実態が不明確

## Step 4: リスク評価

組織全体の贈収賄リスクを評価:

```
□ 事業を行う国・地域のCPI（腐敗認識指数）スコア
□ 公務員との接触頻度（許認可業種、政府調達への参加等）
□ 海外エージェント・コンサルタントの利用状況
□ 過去の贈賄関連事案の有無
□ コンプライアンス研修の実施状況
□ 内部通報制度の利用状況
□ 第三者を通じた支払いの管理状況
```

## 弁護士確認ゲート

**以下の場合は弁護士への相談を推奨:**
- 公務員又は外国公務員への贈答・接待で金額基準を超える場合
- レッドフラグが検出された場合
- 内部通報により贈賄の疑いが報告された場合
- 当局からの照会・調査がある場合

> これは贈収賄防止コンプライアンスの観点からの分析です。贈賄該当性の法的判断は弁護士が行うべきです。特に、当局の調査が関わる場合は速やかに弁護士（刑事・コンプライアンス専門）に相談してください。

---

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- 贈賄該当性の法的判断 — 弁護士の判断
- 捜査機関への対応 — 弁護士の領域
- コンプライアンス研修の実施 — 研修プログラムの設計支援は可能だが、実施そのものは別途
- 内部通報の受付・調査 — 内部通報窓口の運営は別の仕組み
- 司法取引の検討 — 弁護士の専管領域
