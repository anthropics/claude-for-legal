# /anti-organized-crime-screening（反社チェック）

1. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`を読み込む。
2. 以下のワークフローに従い、反社チェックのプロセス管理、結果の記録、契約条項の確認を行う。

---

## コンテキストの読み込み

- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## 組織情報`（業種、所在地）

---

## 目的

反社会的勢力との関係遮断は、政府指針（2007年6月19日犯罪対策閣僚会議幹事会申合せ「企業が反社会的勢力による被害を防止するための指針」）及び各都道府県の暴力団排除条例に基づく企業の社会的責任である。金融機関、上場会社はもちろん、一般事業会社においても反社チェックは取引開始時・M&A時の必須プロセスとなっている。

本スキルは反社チェックのプロセス管理と記録を支援する。データベースの検索や照会そのものは行わない。

---

## Step 1: チェック対象の特定

### チェックが必要なタイミング

| タイミング | 対象 | 優先度 |
|---|---|---|
| 新規取引開始時 | 取引先（法人・個人事業主）、その代表者 | 必須 |
| 役員就任時 | 就任予定の取締役・監査役 | 必須 |
| M&A時 | 対象会社の役員・株主・主要取引先 | 必須 |
| 株主変更時 | 新規株主（第三者割当増資、株式譲渡） | 必須 |
| 不動産取引時 | 売主・買主・仲介者 | 必須（暴排条例で義務化されている場合あり） |
| 定期的な再チェック | 既存取引先・役員（年1回等） | 推奨 |

### チェック対象情報の収集

各対象について以下の情報を収集:


## Step 2: 調査手段

本スキルは以下の調査手段の**プロセス管理**を支援する。実際の検索・照会はユーザーが行う。

### (1) 商業登記情報の確認

```
□ 法人の登記事項証明書の取得・確認
□ 役員構成の確認
□ 本店所在地の確認（頻繁な移転がないか）
□ 事業目的の確認（不自然な事業目的がないか）
```

### (2) インターネット・新聞記事検索

```
□ 対象者名 + 「暴力団」「反社」「逮捕」「送検」「摘発」等のキーワード検索
□ 新聞記事データベース（日経テレコン等）での検索
□ 官報（破産情報等）の確認
□ 対象者名の表記ゆれ（旧字体、通称等）も含めた検索
```

### (3) 反社データベースサービスの利用

```
□ 契約している反社データベースサービスでの照会
  （例: 日経リスク&コンプライアンス、リスクモンスター、帝国データバンク等）
□ 照会結果の記録・保存
```

### (4) 暴力追放運動推進センター・警察への照会

```
□ 暴力追放運動推進センター（暴追センター）への照会（必要に応じて）
□ 所轄警察署への照会（必要に応じて — 通常は暴追センター経由）
□ 照会に必要な資料の準備
```

## Step 4: 暴力団排除条項の確認

### 契約書における暴排条項のチェック

```
□ 取引基本契約書に暴排条項が含まれているか
□ 暴排条項の内容が自社の基準を満たしているか
□ 以下の要素が含まれているか:
  □ 表明保証（反社会的勢力でないことの確約）
  □ 確約事項（反社会的勢力との関係を持たないこと等）
  □ 解除条項（違反した場合の無催告解除権）
  □ 損害賠償（解除に伴う損害の賠償義務は相手方に帰属）
```

### 暴力団排除条項のテンプレート（`--template`）

```
（反社会的勢力の排除）
第X条
1 甲及び乙は、それぞれ相手方に対し、次の各号の事項を確約する。
 (1) 自らが、暴力団、暴力団関係企業、総会屋若しくはこれらに準ずる者又は
    その構成員（以下総称して「反社会的勢力」という。）ではないこと。
 (2) 自らの役員（業務を執行する社員、取締役、執行役又はこれらに準ずる者
    をいう。）が反社会的勢力ではないこと。
 (3) 反社会的勢力に自己の名義を利用させ、この契約を締結するものでないこと。
 (4) 自ら又は第三者を利用して、次の行為をしないこと。
    ア 相手方に対する脅迫的な言動又は暴力を用いる行為
    イ 偽計又は威力を用いて相手方の業務を妨害し、又は信用を毀損する行為
2 甲又は乙の一方について、次のいずれかに該当した場合には、その相手方は、
  何らの催告を要せずして、本契約を解除することができる。
 (1) 前項(1)又は(2)の確約に反する申告をしたことが判明した場合
 (2) 前項(3)の確約に反し契約をしたことが判明した場合
 (3) 前項(4)の確約に反した行為をした場合
3 前項の規定により本契約が解除された場合には、解除された者は、解除により
  生じる損害について、その相手方に対し一切の請求を行わない。
4 第2項の規定により本契約が解除された場合には、解除された者は、解除により
  相手方に生じた損害を賠償する。
```

## Step 5: M&A時の反社チェック

M&Aの文脈で反社チェックが必要な場合（`diligence-issue-extraction`からの連携）:

```
M&A反社チェック対象リスト — [ディールコード]

対象会社の役員:
□ [役員名1] — [チェックステータス]
□ [役員名2] — [チェックステータス]

対象会社の主要株主:
□ [株主名1] — [チェックステータス]
□ [株主名2] — [チェックステータス]

対象会社の主要取引先（上位N社）:
□ [取引先名1] — [チェックステータス]
□ [取引先名2] — [チェックステータス]
```

**反社チェックの結果がディールに与える影響:**
- 反社該当: **ディールキラー**（取引中止を強く推奨）
- 過去の関係あり（現在は解消）: 表明保証での手当て + 追加DD
- グレーゾーン: 弁護士による詳細調査の推奨

---

## 弁護士確認ゲート

**反社該当の疑いがある場合:**

> 反社会的勢力への該当が疑われる調査結果が出ています。関係遮断の方法、契約解除の手続、損害賠償請求、当局への通報等については弁護士に相談してください。特に、既存取引の解消は相手方からの報復リスクもあり、専門家の助言の下で慎重に進める必要があります。

---

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- 反社データベースへの直接アクセス — ユーザーが照会し、結果を記録
- 反社該当性の最終判定 — 法務部門・弁護士の判断
- 関係遮断の交渉・通知 — 弁護士の関与の下で実施
- 警察への通報手続 — 弁護士と協議の上で対応
