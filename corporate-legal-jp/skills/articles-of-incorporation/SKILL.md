# /articles-of-incorporation（定款レビュー）

1. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`を読み込む。
2. 定款を読み込み、以下のステップに従ってレビュー。
3. 変更案がある場合は新旧対照表を作成。

---

## コンテキストの読み込み

- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## 取締役会・株主総会`（ガバナンスモデル、取締役構成等）
- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## 組織情報`（法人形態、上場/非上場）
- 定款のシードドキュメント（あれば）

---

## 目的

定款は会社の根本規則であり（会社法第26条）、記載事項には会社法の強行規定に違反する場合に無効となるもの、定款で別段の定めが可能なデフォルト規定、及び任意に定められる事項がある。本スキルは定款の法的整合性を体系的にレビューし、実務上の改善提案や変更議案の作成を支援する。

---

## Step 1: 記載事項の分類確認

### 絶対的記載事項（会社法第27条）— 欠くと定款自体が無効

```
□ 目的
□ 商号
□ 本店の所在地
□ 設立に際して出資される財産の価額又はその最低額
□ 発起人の氏名又は名称及び住所
```

### 相対的記載事項 — 定めがなくても定款は有効だが、定めなければ効力を生じない

主要なもの:
- 株式の譲渡制限（会社法第107条第1項第1号、第108条第1項第4号）
- 種類株式に関する定め（会社法第108条）
- 取締役会・監査役・会計参与の設置（会社法第326条第2項）
- 取締役の任期の伸長（非公開会社、最長10年 — 会社法第332条第2項）
- 監査役の任期の伸長（非公開会社、最長10年 — 会社法第336条第2項）
- 取締役会の書面決議（会社法第370条）
- 中間配当の定め（会社法第454条第5項）
- 相続人等に対する売渡請求（会社法第174条）

### 任意的記載事項 — 会社法に反しない限り自由に定めることができる

- 事業年度
- 定時株主総会の開催時期
- 公告方法
- 取締役・監査役の員数
- 株主総会の基準日

---

## Step 2: 強行規定との整合性チェック

**違反がある場合は当該条項が無効** — 即座にフラグ。

### 機関設計の適法性

会社法上の機関設計ルールに基づくチェック:

**公開会社の場合:**
- 取締役会の設置が必須（会社法第327条第1項第1号）
- 監査役（又は監査等委員会・指名委員会等）の設置が必須（会社法第327条第2項）
- 会計参与を監査役の代わりにすることは不可

**非公開会社の場合:**
- 取締役会は任意
- 取締役会を設置する場合、監査役（又は会計参与）の設置が必要（会社法第327条第2項）
- 取締役1名のみの会社も可能

**大会社の場合（資本金5億円以上又は負債200億円以上）:**
- 会計監査人の設置が必須（会社法第328条）
- 会計監査人設置会社は監査役の設置が必須（監査等委員会・指名委員会等設置会社を除く）

**上場会社の場合:**
- 社外取締役の設置が必須（会社法第327条の2）

```
□ 機関設計が会社法の規定に適合しているか
□ 公開/非公開の区別と機関設計が整合しているか
□ 大会社の場合の追加要件を満たしているか
□ 上場会社の場合の社外取締役要件を満たしているか
```

### 取締役の任期

- **公開会社:** 選任後**2年**以内の最終の事業年度の定時株主総会終結時まで（会社法第332条第1項）。短縮は可、伸長は不可。
- **非公開会社:** 定款で最長**10年**まで伸長可能（会社法第332条第2項）
- **監査等委員会設置会社の監査等委員である取締役:** **2年**（短縮不可、会社法第332条第4項）
- **指名委員会等設置会社の取締役:** **1年**（会社法第332条第6項）

### 監査役の任期

- 原則: 選任後**4年**以内の最終の事業年度の定時株主総会終結時まで（会社法第336条第1項）。短縮は原則不可。
- **非公開会社:** 定款で最長**10年**まで伸長可能（会社法第336条第2項）

## Step 3: デフォルト規定の確認

定款で別段の定めが可能な事項について、現行定款の定めが実務に適しているか確認:

### 取締役会の書面決議（会社法第370条）

```
□ 書面決議の定款条項があるか
□ 条項の文言が会社法第370条の要件を正確に反映しているか
  （取締役全員の同意 + 監査役の不異議）
□ 実務上のニーズに合致しているか
```

書面決議の条項がない場合（特に非上場会社）:
> 現在の定款には取締役会の書面決議（みなし決議）の条項がありません。会社法第370条に基づき、定款に定めることで取締役会を開催せずに決議と同一の効力を持つ書面決議が可能になります。取締役が地理的に分散している場合や緊急の決議が必要な場合に有用です。追加を検討されますか？

### 株式の譲渡制限（非公開会社の場合）

```
□ 譲渡制限の定めがあるか
□ 承認機関は適切か（取締役会 / 株主総会 / 代表取締役）
□ みなし承認の定め（2週間以内に通知しない場合に承認したものとみなす等）の有無
□ 相続人等に対する売渡請求の定め（会社法第174条）の有無
```

### 株主総会に関する定め

```
□ 基準日の定め（事業年度末日が通常）
□ 招集通知の発送時期（法定期限の確認）
□ 議決権行使の代理人資格の制限（株主に限る等）の有効性
□ 書面投票・電子投票の採用（株主1000人以上の場合は書面投票が義務 — 会社法第298条第2項）
```

### 剰余金の配当

```
□ 剰余金の配当に関する定め
□ 中間配当の定め（会社法第454条第5項 — 取締役会設置会社で定款に定めが必要）
□ 現物配当の定め（株主総会の特別決議要件の排除 — 会社法第454条第4項ただし書）
```

---

## Step 4: 種類株式の確認（該当する場合）

種類株式が発行されている場合のチェック:

```
□ 種類株式の内容が会社法第108条第1項各号に該当するか
□ 発行可能種類株式総数の定め
□ 種類株主総会の要否（会社法第322条）
□ 拒否権付種類株式（黄金株）の有無と内容
□ 取得条項付株式・取得請求権付株式の条件
□ 議決権制限株式の内容（公開会社の場合、発行済株式の1/2以下 — 会社法第115条）
```

**スタートアップ・ベンチャーの場合の追加チェック:**
- 優先株式（残余財産分配の優先、配当の優先）の設計
- 普通株式への転換条件
- 投資契約・株主間契約との整合性

---

## Step 5: 実務上の改善提案

法的整合性に問題がなくても、実務上の改善が望ましい場合に提案:

- 事業目的の拡充（新規事業に対応するため）
- 電子公告の採用（コスト削減）
- テレビ会議による取締役会出席の明示的な許容
- 取締役の責任限定契約の規定（非業務執行取締役・社外取締役・会計参与・監査役・会計監査人、会社法第427条）
- 補欠取締役・補欠監査役の予選の規定

---

## Step 6: 定款変更議案の作成

変更が必要又は希望される場合、新旧対照表を作成:

```
定款一部変更の件

変更の理由:
[変更の理由を記載]

新旧対照表:

| 条番号 | 現行定款 | 変更案 |
|---|---|---|
| 第X条 | [現行の条文] | [変更後の条文] |
| 第Y条 | [現行の条文] | [変更後の条文] |
| 第Z条 | （新設） | [新設する条文] |
```

**定款変更の手続:**
- 株主総会の**特別決議**が必要（会社法第466条、第309条第2項第11号）
- 議決権の過半数を有する株主の出席 + 出席株主の議決権の2/3以上の賛成
- 変更の効力発生日
- 登記が必要な事項の場合は変更登記（効力発生から2週間以内 — 会社法第915条）

## 弁護士確認ゲート

定款の作成・変更は会社法上の重要書類であり、その最終化は法律事務に該当しうる。

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` の `## 利用者情報` → `役割` を確認する。

**役割が弁護士でない場合:**

> ⚠️ この定款変更議案を株主総会に付議する前に、弁護士に確認済みですか？
>
> 定款変更の最終化は法律事務に該当する可能性があります。
>
> 弁護士に確認済みですか？ [はい/いいえ]
>
> 「いいえ」の場合 → このゲートを超えて最終出力を生成しません。

**役割が弁護士の場合:** ゲートなしで続行。

## Step 7: 出力

1. **定款レビューレポート** — 法的整合性の確認結果と改善提案
2. **定款変更議案ドラフト**（変更がある場合）— 新旧対照表
3. **レビューチェックリスト:**

```
[成果物ヘッダー — ## 出力設定に基づく]

レビューチェックリスト:
□ 絶対的記載事項に漏れがないか
□ 機関設計が会社法の規定に適合しているか
□ 取締役・監査役の任期が法定の範囲内か
□ 株式譲渡制限の定めが実態に合致しているか
□ 種類株式の内容が適法か（該当する場合）
□ 登記事項と定款の内容が一致しているか
□ 定款変更に株主総会特別決議が必要であることの確認
□ 弁護士レビュー済みか
```

---

## 弁護士確認ゲート

**定款変更議案の最終化前:**

定款は会社の根本規則であり、変更は株主総会特別決議を要する重大な行為である。本スキルのドラフトは弁護士のレビューを経て最終化されるべきである。

> これは定款変更議案のドラフトです。確定した議案は株主総会に提出され、法的効力を持ちます。弁護士がレビュー・編集し、適法性を確認した上で株主総会に付議してください。

---

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- 定款の法的有効性の最終判断 — 弁護士の判断
- 定款変更の株主総会運営 — `/corporate-legal-jp:shareholders-meeting`と連携
- 公証人による定款認証手続（設立時のみ）
- 定款変更登記の申請 — `/corporate-legal-jp:commercial-registration`と連携
- 種類株式の経済的設計 — 法的枠組みの確認であり、バリュエーションは別途
