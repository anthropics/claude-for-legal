# /entity-compliance（商業登記管理）

1. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## 登記・エンティティ管理`（法人テーブル、管轄法務局、司法書士）を読み込む。
2. 以下のモードにルーティング:
   - フラグなしまたは`--init`: Mode 1 — 法人テーブルからトラッカー初期化
   - `--report`: Mode 2 — 期限到来・期限超過の登記事項を表示
   - `--update`: Mode 3 — ステータス更新
   - `--audit`: Mode 4 — 登記健全性監査
   - `--export`: Mode 5 — CSV又はテーブル出力
3. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/entities/compliance-tracker.yaml`を読み書き。
4. 更新後: 変更のサマリーと次のアクションを表示。

---

## 目的

商業登記は、会社法上の義務として、登記事項に変更が生じた場合に2週間以内に変更登記を申請しなければならない（会社法第915条第1項）。登記懈怠には過料の制裁がある（会社法第976条第1号）。本スキルは、各法人の登記期限を追跡し、期限到来の通知と申請書ドラフトを提供する。

## 重要: 登記期限の注意事項

> 本スキルの登記期限参照表は、スキル作成時点の公開情報に基づいています。登記手続・必要書類・費用は変更される可能性があります。**登記申請に際しては、必ず司法書士又は管轄法務局に確認してください。**

---

## 主要な登記事項と期限

### 役員変更登記

- **登記期限:** 変更が生じた日から**2週間以内**（会社法第915条第1項）
- **対象:** 取締役・監査役・代表取締役・会計参与・会計監査人・執行役の就任・退任・辞任・解任・死亡・住所変更等
- **任期管理:**
  - 取締役の任期: 原則2年（会社法第332条第1項）、非公開会社は定款で最長10年まで伸長可（同条第2項）
  - 監査役の任期: 原則4年（会社法第336条第1項）、非公開会社は定款で最長10年まで伸長可（同条第2項）
  - 監査等委員の任期: 2年（会社法第332条第4項）
- **みなし退任（任期満了退任）:** 定時株主総会の終結時に任期満了となる場合、後任が選任されなければ権利義務取締役となるが（会社法第346条第1項）、登記上は任期満了退任の登記が必要

### 本店移転登記

- **登記期限:** 移転の日から2週間以内（会社法第915条第1項）
- **管轄法務局が変わる場合:** 旧管轄と新管轄の両方に申請（旧管轄経由で新管轄に送付）
- **取締役会決議が必要**（取締役会設置会社の場合）
- **定款変更が必要な場合:** 定款に具体的な住所を記載している場合は株主総会特別決議も必要

### 目的変更登記

- **登記期限:** 変更の効力発生日から2週間以内
- **株主総会特別決議が必要**（定款変更 — 会社法第466条）

### 増資（資本金の額の変更）

- **募集株式の発行:** 払込期日又は払込期間の末日から2週間以内
- **株式会社の場合:** 登録免許税は増加する資本金の額の0.7%（最低3万円）

### 定款変更に伴う登記

- 発行可能株式総数の変更
- 株式の譲渡制限の設定・変更・廃止
- 単元株式数の設定・変更・廃止

## Mode 1: トラッカーの初期化

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`の法人テーブルから各法人の登記情報を取得し、`compliance-tracker.yaml`を作成。

```yaml
companies:
  - name: "[法人名]"
    type: "株式会社"
    registry: "[管轄法務局]"
    capital: "[資本金]"
    directors:
      - name: "[氏名]"
        position: "代表取締役"
        appointed: "[就任日]"
        term_expires: "[任期満了日]"
    auditors:
      - name: "[氏名]"
        position: "監査役"
        appointed: "[就任日]"
        term_expires: "[任期満了日]"
    pending_registrations: []
    last_checked: "[日付]"
```

## Mode 3: ステータス更新

ユーザー又はエージェントからのステータス更新を受け取り、トラッカーを更新。

## Mode 4: 登記健全性監査

全法人の登記情報を確認し、以下をチェック:
- 任期満了が近い役員
- 未了の登記事項
- 登記と実態の不一致の可能性
- 定款と登記の整合性

## Mode 5: エクスポート

CSV又はテーブル形式で登記管理台帳を出力。

---

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- 登記申請書の法務局への提出 — 司法書士又はユーザーが行う
- 登記事項の法的有効性の判断 — フラグは立てるが判断は弁護士・司法書士
- 登記情報提供サービスへのリアルタイムアクセス（未接続の場合）— ユーザーが情報を提供
