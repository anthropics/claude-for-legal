# /license-permit-tracker（許認可トラッカー）

1. `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`を読み込む。
2. 以下のワークフローに従い、許認可の一覧管理、更新期限の追跡、M&Aにおける承継可否の確認を行う。

---

## コンテキストの読み込み

- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## 組織情報`（業種、事業内容）
- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## M&A・組織再編`（M&A時の承継確認の場合）

---

## 目的

日本の事業活動には多数の許認可が必要であり、その有効期限管理と更新手続の追跡は法務・総務の重要業務である。許認可の失効は事業の停止に直結し、M&Aにおいては許認可の承継可否がディール構造に直接影響する。

---

## Step 1: 許認可の一覧管理

### トラッカーの構造

```yaml
licenses:
  - id: "LIC-001"
    name: "[許認可名]"
    law: "[根拠法令]"
    authority: "[許認可権者（所管官庁）]"
    license_number: "[許可番号]"
    grant_date: "[YYYY-MM-DD]"
    expiry_date: "[YYYY-MM-DD]"
    renewal_period: "[N年]"
    renewal_deadline: "[有効期限のN日/ヶ月前]"
    status: "[有効 / 更新手続中 / 失効 / 未取得]"
    responsible: "[担当者]"
    notes: ""
    ma_succession: "[包括承継 / 個別承継 / 新規取得必要 / 要確認]"
```

## Step 2: 更新期限の追跡

### 更新アラートの管理

```
更新期限が近い許認可:

赤 — 更新期限まで30日以内（又は超過）:
  [LIC-XXX] [許認可名] — 更新期限: [日付]（残り[N]日）

黄 — 更新期限まで90日以内:
  [LIC-XXX] [許認可名] — 更新期限: [日付]（残り[N]日）

緑 — 更新期限まで90日超:
  [件数]件 — 次の更新: [許認可名] [日付]
```

### 更新手続に必要な準備

主な更新手続で共通する準備事項:
- 更新申請書の作成
- 添付書類の準備（登記事項証明書、決算書、役員の身分証明書、欠格事由の確認等）
- 手数料の納付
- 行政書士への委託（必要な場合）

---

## Step 3: M&Aにおける許認可の承継

### 承継の類型

| 組織再編の手法 | 承継の原則 | 必要な手続 |
|---|---|---|
| **合併（吸収合併・新設合併）** | **包括承継** — 原則として許認可は承継される | 変更届出が必要な場合あり。業法によっては事前届出・認可が必要 |
| **会社分割（吸収分割・新設分割）** | **包括承継** — 分割計画・分割契約に記載された権利義務は承継 | 変更届出。一部の業法では個別の認可が必要 |
| **事業譲渡** | **承継されない** — 許認可は個人（法人）に帰属 | **新規取得が必要。** 事業譲渡を理由とした承継手続はない |
| **株式譲渡** | **変更なし** — 許認可を保有する法人は変わらない | 役員変更届出。欠格事由の確認 |

### M&Aチェック（`--ma-check`）

ディールの類型に応じて、各許認可の承継可否を判定:

```
許認可承継可否チェック — [ディールコード]
ディール類型: [事業譲渡]

| 許認可 | 現在の保有者 | 承継可否 | 必要な手続 | 所要期間（目安） | リスク |
|---|---|---|---|---|---|
| 建設業許可 | [対象会社] | 新規取得必要 | 許可申請 | 約2-3ヶ月 | 赤 — クロージング前に取得困難な場合あり |
| 宅建業免許 | [対象会社] | 新規取得必要 | 免許申請 | 約1-2ヶ月 | 黄 |
| [等] | | | | | |
```

**事業譲渡の場合の特別な注意:**
> 事業譲渡では許認可は承継されません。事業継続に不可欠な許認可については、クロージング前又はクロージング直後に新規取得の手続を完了させる必要があります。取得に時間を要する許認可がある場合は、ディールスケジュールに影響する可能性があります。
>
> → `/corporate-legal-jp:closing-checklist`に許認可取得をブロッカーとして追加することを推奨。

---

## Step 4: 届出事項の変更管理

許認可自体の更新ではないが、届出事項（役員変更、本店移転、商号変更等）の変更届出も追跡:

```
□ 役員変更届出（許認可ごとに届出期限が異なる — 通常は変更後30日以内）
□ 商号変更届出
□ 本店移転届出
□ 営業所の新設・廃止届出
□ 資本金の変更届出
□ 欠格事由の該当可能性の確認（新役員について）
```

---

## Step 5: 出力

1. **許認可一覧レポート** — 全許認可のステータスと更新期限
2. **更新アラート** — 期限が近い許認可の一覧
3. **M&A承継可否チェック**（M&A時）— 各許認可の承継判定結果

---

## ハンドオフ

- **`closing-checklist`へ:** M&A時に取得・変更が必要な許認可をブロッカーとして供給
- **`diligence-issue-extraction`から:** DD中に発見された許認可の問題点
- **`integration-management`へ:** クロージング後の許認可変更届出タスク

---

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- 許認可申請書の作成 — 行政書士の領域
- 許認可取得の要件判定（欠格事由の該当性等）の最終判断 — 弁護士・行政書士の判断
- 行政機関との折衝・交渉
- 許認可に関する行政処分への対応 — 弁護士の領域
