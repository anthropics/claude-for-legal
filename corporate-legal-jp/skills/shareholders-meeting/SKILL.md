# 株主総会対応

## 目的

株主総会は株式会社の最高意思決定機関であり（会社法第295条）、その運営には厳格な法定手続が求められる。本スキルは、招集通知の作成から議事録の作成まで、株主総会の一連の手続を支援する。定時株主総会・臨時株主総会の双方に対応し、普通決議・特別決議・特殊決議の区別を含む。

## コンテキストの読み込み

- `~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` → `## 取締役会・株主総会`:
  - 定時株主総会の時期、基準日
  - 株主構成（株主数、主要株主、支配株主の有無）
  - 招集通知の発送時期
  - 書面投票・電子投票の採用
  - 議決権行使プラットフォーム
- ガバナンスモデル
- 上場/非上場の区別

---

## Step 1: 株主総会の特定

確認事項:
- **定時株主総会か臨時株主総会か？**
- **開催予定日**
- **議案の概要**

### 定時株主総会の場合

- 基準日から3ヶ月以内に開催（会社法第124条第2項）
- 事業年度終了後の計算書類承認等が主な議題

### 臨時株主総会の場合

- 必要に応じて随時開催可能
- 招集理由の確認

---

## Step 2: 招集通知の作成

### 招集通知の法定発送期限

- **非公開会社:** 株主総会の日の**1週間前**まで（会社法第299条第1項）
  - 書面投票・電子投票を採用する場合は**2週間前**まで
  - 定款で短縮可能（取締役会非設置会社で書面投票等を採用しない場合）
- **公開会社:** 株主総会の日の**2週間前**まで（会社法第299条第1項）
- **上場会社の実務:** **3週間前**以上（コーポレートガバナンス・コード補充原則1-2(2)）
  - 電子提供措置の場合: 3週間前に電子提供開始 + アクセス通知は株主総会の日の2週間前まで（会社法第325条の4）

### 招集通知の記載事項（会社法第298条・第299条）

```
株主総会招集ご通知

                              [年月日]

株主各位

                    [会社名]
                    代表取締役 [氏名]

  下記のとおり[第X回定時/臨時]株主総会を開催いたしますので、
ご出席くださいますようご通知申し上げます。

                    記

1. 日時    [年月日（曜日）午前/午後X時]
2. 場所    [住所・会場名]
3. 目的事項
   報告事項
     [第X期（自 年月日 至 年月日）事業報告の内容報告の件 等]
   決議事項
     第1号議案  [議案名]
     第2号議案  [議案名]
     [等]

[書面投票採用の場合]
4. 書面による議決権行使について
   同封の議決権行使書に賛否をご記入の上、[年月日]午後X時までに
   当社に到着するようご返送ください。

[電子投票採用の場合]
5. 電子的方法による議決権行使について
   [議決権行使サイトのURL等]

                              以上
```

## Step 3: 議案の整理

### 決議の種類の区別

**普通決議（会社法第309条第1項）:**
- 議決権の過半数を有する株主の出席（定款で排除・軽減可）
- 出席株主の議決権の過半数で成立
- 例: 取締役の選任（累積投票除く）、計算書類の承認、剰余金の配当

**特別決議（会社法第309条第2項）:**
- 議決権の過半数を有する株主の出席（定款で1/3まで軽減可）
- 出席株主の議決権の**2/3以上**で成立
- 例: 定款変更、事業譲渡、合併、会社分割、株式交換、株式移転、資本金の減少、自己株式の取得（特定の株主から）、募集株式の有利発行

**特殊決議（会社法第309条第3項・第4項）:**
- 第3項: 議決権を有する株主の半数以上であって議決権の2/3以上
  - 例: 非公開会社における募集株式の発行で株主に割当権を与える場合等
- 第4項: 総株主の半数以上であって総株主の議決権の3/4以上
  - 例: 全部取得条項付種類株式の取得に際し対価を変更する場合等

### 議案ごとの整理

各議案について:
- 議案名
- 決議の種類（普通 / 特別 / 特殊）
- 議案の内容（具体的な記載）
- 必要な定足数
- 関連する添付書類

## Step 4: 株主総会参考書類の作成（会社法施行規則第73条以下）

書面投票を採用する場合、株主総会参考書類の添付が必要（会社法第301条）。

### 参考書類の記載事項（施行規則第73条）

- 議案
- 提案の理由（取締役会が提案する場合）
- 議案について参考となるべき事項

### 議案別の記載事項

**取締役選任議案（施行規則第74条）:**
- 候補者の氏名、生年月日、略歴
- 候補者と会社の関係
- 社外取締役候補者の場合はその旨
- 就任承諾の有無

**監査役選任議案（施行規則第76条）:**
- 上記に加え、監査役会の同意（会社法第343条）
- 社外監査役候補者の場合はその旨

**計算書類承認議案:**
- 事業報告、計算書類、監査報告の要旨

**定款変更議案:**
- 変更の理由
- 変更の内容（新旧対照表）

## Step 5: 議事録の作成（会社法施行規則第72条）

### 議事録の記載事項

1. **株主総会が開催された日時及び場所**（当該場所に存しない取締役等が出席した場合の出席方法を含む）
2. **株主総会の議事の経過の要領及びその結果**
3. **監査役等が述べた意見又は発言の内容の概要**
4. **出席した取締役、執行役、会計参与、監査役、会計監査人の氏名又は名称**
5. **議長の氏名**
6. **議事録作成者の氏名**

### 議事録フォーマット

```
[第X回定時/臨時]株主総会議事録

1. 日時    [年月日（曜日）午前/午後X時X分]
2. 場所    [住所・会場名]
3. 株主の状況
   総株主の議決権の数    [N]個
   出席株主の議決権の数  [N]個（うち書面行使[N]個、電子行使[N]個を含む）
4. 出席した役員
   取締役  [氏名]、[氏名]、...
   監査役  [氏名]、[氏名]、...
5. 議長    [氏名]

議長は開会を宣し、上記のとおり定足数に足る株主の出席があったので、
本総会は適法に成立した旨を述べ、議事に入った。

[報告事項]
[議案名]
  [報告内容の要旨]

[決議事項]
第1号議案  [議案名]
  議長が[議案の内容]を説明し、その賛否を議場に諮ったところ、
  出席株主の議決権の過半数の賛成により原案どおり承認可決された。
  [可決 — 賛成[N]個、反対[N]個]

第2号議案  [議案名]
  [同様]

以上をもって本日の議事を終了し、議長は午前/午後X時X分閉会を宣した。

上記の議事の経過の要領及びその結果を明確にするため、この議事録を作成し、
議長及び出席取締役がこれに記名押印する。

  [年月日]

  議長  代表取締役  [氏名]  印
```

## Step 6: 書面投票・電子投票への対応

### 書面投票（会社法第311条）

- 議決権行使書面の作成
- 行使期限の設定（株主総会の日時の直前の営業時間の終了時、定款で別段の定め可）
- 賛否の記載がない場合の取扱い（会社法施行規則第66条第1項第2号）

### 電子投票（会社法第312条）

- 電磁的方法による議決権行使の方法
- 行使期限
- 書面投票と電子投票の双方で行使された場合の取扱い（施行規則第69条）

### 議決権行使プラットフォーム（機関投資家向け）

上場会社の場合、ICJ（Investor Communications Japan）等のプラットフォーム利用の有無を確認。

## 弁護士確認ゲート（株主総会関連書類）

株主総会の招集通知・議案・参考書類は会社法上の法定書類であり、その作成は法律事務に該当しうる。

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md` の `## 利用者情報` → `役割` を確認する。

**役割が弁護士でない場合:**

> ⚠️ この招集通知/議案を確定・発送する前に、弁護士に確認済みですか？
>
> 株主総会関連書類の最終化は法律事務に該当する可能性があります。
> このドラフトを弁護士にレビューしていただくことを強く推奨します。
>
> 弁護士に確認済みですか？ [はい/いいえ]
>
> 「いいえ」の場合 → このゲートを超えて最終出力を生成しません。

**役割が弁護士の場合:** ゲートなしで続行。

---

## 出力

1. **招集通知ドラフト** — 法定記載事項を満たした招集通知
2. **議案整理表** — 各議案の決議種類・定足数・必要賛成割合の一覧
3. **参考書類ドラフト**（書面投票採用の場合）
4. **議事録ドラフト**（総会終了後）
5. **レビューチェックリスト:**

```
[成果物ヘッダー — ## 出力設定に基づく]

レビューチェックリスト:
□ 招集通知の発送期限を満たしているか
□ 議案の決議種類（普通/特別/特殊）の分類は正しいか
□ 参考書類の法定記載事項に漏れがないか
□ 議決権行使書の記載は正しいか
□ 基準日と総会開催日の間隔は3ヶ月以内か
□ 上場会社の場合: 適時開示との整合性
□ 弁護士レビュー済みか
```

---

## 免責事項

本スキルの出力は法的助言に代わるものではありません。最終的な判断は必ず弁護士にご確認ください。

## このスキルが行わないこと

- 株主提案（会社法第303条-第305条）の対応方針の決定 — 弁護士の判断
- 議決権の代理行使の有効性判断 — 委任状の有効性は弁護士が確認
- 株主総会の開催・運営 — 本スキルは書類作成を支援するもの
- 適時開示の作成 — 上場会社の適時開示は別途対応が必要
