# /customize（カスタマイズ）

## 実行条件

ユーザーが `/corporate-legal-jp:customize` を入力した場合。プラクティスプロファイルの特定の項目を、cold-start-interview全体を再実行せずに変更する。

---

## 処理

### Step 1: 現在の設定を読み込む

`~/.claude/plugins/config/claude-for-legal/corporate-legal-jp/CLAUDE.md`を読み込む。

未設定の場合:
> まだセットアップが完了していません。`/corporate-legal-jp:cold-start-interview` を先に実行してください。カスタマイズは既存のプロファイルを調整する機能です。

### Step 2: カスタマイズ可能な項目を表示

```
カスタマイズ可能な項目:

- **組織情報** — 法人名、業種、法人形態、資本金、上場/非上場、ガバナンスモデル
  （company-profile.md と共有される項目は company-profile.md を更新）
- **利用者情報** — 役割、弁護士連絡先
- **有効モジュール** — M&A、取締役会・株主総会、上場会社、登記・エンティティ管理のオン/オフ
- **取締役会・株主総会** — 取締役構成、監査役構成、議事録フォーマット、書面決議の定款条項
- **M&A・組織再編** — 典型的な立場、重要性基準、イシューメモフォーマット
- **エスカレーション** — 稟議制度、決裁権限基準、外部弁護士相談基準
- **連携ツール** — 各ツールの接続ステータス
- **シードドキュメント** — テンプレートとして使用する先例の追加・変更

どの項目を変更しますか？
```

### Step 3: 変更の実行

該当セクションのみを更新し、他のセクションは維持。

### Step 4: 変更サマリー

```
変更内容:
- [セクション]: [項目] を [旧値] → [新値] に変更

他のセクションは変更なし。
```

---

## このスキルが行わないこと

- プラクティスプロファイルのフルリセット — `/corporate-legal-jp:cold-start-interview --redo` を使用
- 他のプラグインの設定変更
- company-profile.md の直接変更 — 共有項目は company-profile.md を手動で更新するか案内
